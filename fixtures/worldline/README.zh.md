# 世界线验收场景

[English](README.md) | 中文

这些来源夹具以真实文件来源项目验证当前世界线实现。运行时验收套件通过项目服务写入它们，编译并冻结世界蓝图，启动隔离的工作线程演算，提交投影出的合法行动，推进逻辑时间并检查保留记录。

- `twenty-five-person-town`：25 位独立播种 L2 记忆的 OC 居民；验收套件会推进完整的九十天夹具时长。
- `oc-hero-journey`：一个以角色为中心的旅程。
- `rural-life`：一个小型家庭与季节劳动场景。
- `alternate-history`：制度与政治归属场景。
- `nested-map`：世界 → 区域 → 城市 → 嵌套建筑 → 房间的包含关系。

夹具只描述当前唯一格式，不作为旧格式的兼容样本。
