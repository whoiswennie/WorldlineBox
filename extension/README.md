# WorldlineBox Chromium 扩展

## 内置浏览器：无需安装

WorldlineBox 左侧「浏览器」已内置本扩展的图片、视频采集能力，不需要构建或加载扩展。先在「资产管理」打开资源库，再点击浏览器地址栏「保存到资产库」，选择目标库与文件夹。网页图片或视频可通过原生右键菜单「保存到 WorldlineBox」保存，也可拖拽到原有树状菜单：最近目录、根目录与多级子目录均可选择，`›` / `‹` 切换层级，面板外松开或 `Esc` 取消。

采集侧栏可搜索目标文件夹，选择可用的链接文件夹，使用「采集本地图片」打开系统选图窗口，配置通知、保存后聚焦、资产定位和拖拽菜单四个持久化开关，并查看保存进度、错误或取消下载。开启资产定位后，保存完成会打开目标资源库中的资产；浏览器标签与页面继续保留。完整操作见[内置浏览器使用说明](../docs/user-guide/browser.md#保存到资产库)。

内置采集使用当前网页会话的 Cookie 和 Referer 下载 HTTP/HTTPS 图片、视频，再执行资产库导入与内容查重。远程媒体上限 500 MiB，本地图片上限 32 MiB；不支持 `blob:` / `data:`、分段流或 DRM 媒体。本地图片通过系统选图窗口采集，浏览器保持 HTTP/HTTPS 导航限制。没有新增网页扫描、批量采集或扩展弹出窗口。

## 外部 Chrome / Edge

该扩展支持在 Chrome、Edge 等 Chromium 浏览器中右键网页图片或视频，并将媒体保存到正在运行的 WorldlineBox 桌面应用。

媒体由**浏览器侧下载**（携带 Cookie 与页面 Referer），再上传到本机 WorldlineBox，可绕过多数防盗链限制。只要 WorldlineBox 在运行且已打开资源库，扩展即可连接（本机 127.0.0.1）。

## 构建

在 WorldlineBox 项目根目录运行：

```bash
npm run extension:build
```

可安装产物生成在 `dist/extension/`。该目录包含编译后的 JavaScript、Manifest 和 PNG 图标；不要直接加载源码目录 `extension/`。

## 手动安装

1. 先完成上述构建。
2. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
3. 开启“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择 `dist/extension/`。

## 使用

1. 启动 WorldlineBox 并打开一个资源库。
2. 扩展工具栏图标在已连接时会变为彩色；未连接时保持灰色。
3. 在网页图片或视频上右键，选择「保存到 WorldlineBox」，再选择「根目录」或目标文件夹。
4. **拖拽保存**：拖拽网页图片或视频时自动展开树状保存菜单——悬停有子目录的文件夹右侧 `›` 进入下一级，点击或悬停左侧 `‹` 返回上一级，在目标文件夹上松开即可保存；在面板外部松开或按 `Esc` 退出且不保存。菜单顶部优先展示最近使用的文件夹。

拖拽解析会优先使用浏览器提供的媒体元素与拖拽数据，再回退到坐标命中，因此链接、遮罩、懒加载容器和 CSS 背景图也能保存。要在 Chrome/Edge 中拖拽或右键保存本地 `file://` 图片，请在扩展详情页打开“允许访问文件网址”；本地图片会在页面内转换为 PNG 上传，不暴露本地绝对路径。
5. Pinterest、Behance、Google 图片等站点与常见网页相同，使用浏览器原生右键菜单中的「保存到 WorldlineBox」子菜单，拖拽时同样支持树状保存菜单。

扩展会提供保存反馈，明确提示保存请求已接收、WorldlineBox 未运行、浏览器下载失败，或桌面应用给出的具体拒绝原因。最近使用过的文件夹会排在菜单前列。WorldlineBox 客户端会对扩展保存执行与本地导入相同的内容查重。扩展不会自动启动桌面应用。

桌面应用内打开「设置 → 插件」或「设置 → 常规」可查看扩展相关信息。

扩展选项页（右键扩展图标 → 选项）可配置：系统通知提示、保存后聚焦 WorldlineBox 应用、保存后在资源库中定位该资产，以及是否开启拖拽时的树状保存菜单。
