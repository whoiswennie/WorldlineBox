# WorldlineBox 0.1.9 · Windows

下载并运行 `WorldlineBoxSetup.exe` 即可安装或覆盖升级，适用于 Windows 10 / 11 x64。下载页同时提供 SHA-256 校验文件。

- Windows 单文件离线安装包直接打开原生向导，省去准备动画和安装前的整包复制。重复打开安装包会回到已打开的向导。

- 在「设置 → 手机连接」可以给电脑命名。同一局域网里的手机能在「附近的电脑」找到它。首次连接时，电脑会显示手机名称和连接码，核对后可同意或拒绝。配对过的手机再次回到局域网时可自动重连。
- 伙伴聊天可以直接调用桌面采集。即使视频通话和桌宠窗口都已关闭，也能在聊天里请求伙伴截取电脑屏幕。
