# WorldlineBox 0.1.4 · Windows

下载并完整解压 `WorldlineBoxSetup.zip`，打开解压后的 `WorldlineBoxSetup.exe` 安装或覆盖升级。适用于 Windows 10 / 11 x64，同页提供 SHA-256 校验文件。

- **安装体验**。小型启动程序会先显示准备进度，再打开安装向导。连续双击只启动一次安装。
- **伙伴音乐**。点歌默认在对话或会面的音乐卡片播放。同一条回复中重复请求的播放队列只发一张卡片，历史卡片按需播放。在话题连接「音乐」后，伙伴可以读取全局播放器的歌曲、歌单、进度和播放状态，也可以按用户要求单独控制全局播放器。
- **音乐设置**。重新设计播放器与歌单管理，内置歌单「幻酱的作品集」。桌面歌词支持透明置顶、锁定、拖动以及横排和竖排。
- **桌宠**。简洁模式使用小头像，可在屏幕边缘摆放，保留对话与会面功能。改进浮窗内长错误提示的显示。
- **伙伴对话**。改进伙伴身份与交付路由，修复进入对话后未读状态未清除的问题。录音发送前可试听。
- **DeepSeek Harness**。内置版本固定为 `0.2.2-rc.5`。升级期间会拦截对被升级实例的操作，并提示升级状态。
