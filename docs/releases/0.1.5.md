# WorldlineBox 0.1.5 · Windows

下载并打开 `WorldlineBoxSetup.exe` 安装或覆盖升级。适用于 Windows 10 / 11 x64，同页提供 SHA-256 校验文件。

- **伙伴视频**。在话题的「应用」中连接视频，可请伙伴查找哔哩哔哩视频、UP 主、分区和排行榜。点击聊天卡片即可播放，支持全屏和返回原播放位置。访问会员内容取决于账号权益及官方播放器支持情况。
- **跨端应用**。与 Android 0.1.4 配对后，电脑和手机可在同一话题启用多个应用，添加和移除会同步到另一端。手机可直接在聊天中播放伙伴分享的音乐和视频。
- **历史卡片**。重新进入聊天时可点选旧卡片播放。新分享的卡片可随伙伴回复播放。
