# WorldlineBox 0.1.1 · Windows

Windows 10 / 11 x64 用户可以从下载区取得 `WorldlineBoxSetup.exe`。同页提供 `WorldlineBoxSetup.exe.sha256`。配合 [Android 0.1.1](https://github.com/whoiswennie/WorldlineBoxMobile/releases/tag/0.1.1) 使用可启用手机端逐页朗读。

## 伙伴、桌宠与语音

- 连续语音在伙伴朗读首段前先打开麦克风。检测到用户开口时，本地立即停播，同一次录音保留开口前约 250 毫秒，减少句首漏字。「打断并说话」也会先开始收音。
- 长对白按句子或短段分页，限制气泡高度。自动播放会等当前页语音结束再翻页。支持逐段浏览、重播、收起和查看完整对话。手机同步显示电脑端发布的分段和执行阶段。
- Live2D 衔接补充了待机、聆听、等待和说话时的动作变化。内置角色在正式发布包中可用头像会面，桌面角色卡支持按作者授权本地导入 Live2D 原版 ZIP。公开包使用随项目分发的铃声素材。
- 修复最大化的伙伴页在退出桌宠后可能重复显示「聊天摘要」的问题。原生关闭桌宠窗口会返回会面，记忆和聊天记录窗口在会面退出后恢复。记忆窗口在重新取得焦点时保留日记编辑草稿。
- 后台互动日记等待索引的时间分成短轮确认。未完成的索引保留作业和写入回执，稍后继续核实。同一伙伴的新一轮检索可以在两次确认之间执行，等待后台任务时界面显示实际准备阶段。

## 启动器与伙伴应用

- Windows 安装包内置 DeepSeek Harness 0.2.2-rc.3 和运行依赖。启动器会准备可用作共享执行器的「WorldlineBox DSH」兜底实例。已有独立实例可继续使用。在线模型仍需对应账号和网络。
- 在伙伴聊天中可为当前话题启用「小屋世界」。伙伴按轮读取屋内位置、天气和近期活动，同一伙伴在不同话题保有同一个住户。关闭或断开话题应用后，小屋存档可以继续使用。
- Windows 打包会校验内置 DSH 与小屋资源，安装器保留独立的 SHA-256 校验文件。

## 资产管理

- 检查器加入标签框选、复制与粘贴，可在资产之间迁移选中的标签。键盘操作会让位给正在编辑的文本输入框。
- 评分星标支持悬停预览并在点击后保存。改进筛选保留、文件夹重命名和预览区的点击判定。
- 改进 RAW 预览的亮度和色调匹配，使用小尺寸亮度分布对齐可用的参考预览。

## 升级

从下载区运行新安装器即可覆盖升级。Windows 安装器沿用项目现有的未签名分发方式，系统可能提示确认来源。手机与电脑需要同步升级才能获得新的语音分页行为。Live2D 原画、模型和本地导入见[素材与授权说明](https://github.com/whoiswennie/WorldlineBox/blob/main/public/companion-call/NOTICE.md)。
