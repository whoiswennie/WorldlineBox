# WorldlineBox 0.1.10 · Windows

下载并运行 `WorldlineBoxSetup.exe` 即可安装或覆盖升级，适用于 Windows 10 / 11 x64。下载页同时提供 SHA-256 校验文件。

- 伙伴聊天内置 VCP RiverMemo V5，使用随应用提供的 768 维向量模型。普通对话会自动带入相关日记；和同一伙伴另开话题时，也可以接上近期聊过的原话。记忆功能无需另装服务或配置专用密钥。
- 在「记忆」里可以按伙伴和会话管理日记，试查自动召回结果，或按关键词找回带有来源的聊天原话。
- 伙伴可以在空闲时整理日记，关闭软件后可在下次打开时继续。你可以查看整理依据，逐项决定是否采纳梦境中的感悟、合并和归档建议。
- 从开发版升级时，应用会退役旧版试验记忆，保留已有的可见聊天记录。
