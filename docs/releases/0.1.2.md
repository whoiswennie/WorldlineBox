# WorldlineBox 0.1.2 · Windows

适用于 Windows 10 / 11 x64。使用 `WorldlineBoxSetup.exe` 安装或覆盖升级，下载后可用同页的 `WorldlineBoxSetup.exe.sha256` 校验。

## 伙伴、Live2D 与桌宠

- 内置大肥鱼（DeepSeek-chan）的 Live2D 模型、贴图、表情和动作。感谢神宫凉子提供原画及拆分，霓虹猫_NeonNeko 提供 Live2D 建模，模型使用须知随包提供。
- 新增伙伴「月见八千代」及角色设定，随包提供雪熊企划授权的八千代 Live2D 模型、贴图、表情及头像。进入月见八千代的视频会面或桌宠即可使用。 [随包分发许可](https://github.com/whoiswennie/WorldlineBox/blob/0.1.2/public/companion-call/yachiyo/MODEL-LICENSE.txt) · [雪熊企划](https://booth.pm/ja/items/8034348)
- 角色卡支持从文件夹或 ZIP 导入 Live2D。导入模型可以自动取景，也可以手动调整位置和缩放。设置按模型保存，重启后继续使用。
- 改进高 DPI 显示和 Live2D 渲染开销，在桌宠、视频会面与窗口缩放时兼顾清晰度和流畅度。改善动作、表情和待机切换时逐渐掉帧的问题。
- 将等待模型、思考和调用工具等状态移到正文之外。桌宠长对白支持自动滚动，仍可暂停、逐段浏览和重播。

## 陪伴模式

- 视频会面和桌宠新增陪伴模式。精力值有持续录屏、平衡采集和只截图三档。录像覆盖整个心跳等待间隔并同步收录电脑声音，截图在等待期间随机采样，到点补一张。
- 等待阶段自动用 FFmpeg 提取关键帧并在本机转写系统音轨。每次有效心跳将整批素材的关键帧、带时间戳的字幕和本机资源路径交给当前话题的原生 DSH 会话。回复可调用台词、表情和动作工具在桌宠或会面舞台呈现。
- 上一轮结束后才启动下一轮倒计时。支持手动中断，单轮处理达到 150 秒会取消。暂未完成的素材留在本次运行的待处理队列。
- 每次完成观察后，视频会面和桌宠都会显示一句伙伴台词。DSH 优先通过表演工具给出新台词，空回包或重复台词会用简短的处理结果补位。HUD 显示执行、等待与中断状态，下一轮仍按正常间隔运行。
- 观察缓存可查看、播放并清理采集记录。已归档记录最多保留 50 条，超过上限时淘汰最旧记录。「清空归档」保留待处理和处理中的素材。

## 聊天、日程和语音

- 伙伴私聊、视频会面与桌宠沿用相同的原生 DSH 话题。日程反馈可以在当前会面或桌宠呈现，并同步进入聊天记录。新增执行一次的日程，完成后自动停用。
- 伙伴可以在当前用户请求中按需截图、录制屏幕和系统声音，或只听系统音轨。采集和处理状态与执行进度并排显示。
- 普通聊天、会面及桌宠可通过桥接器调用本机 SenseVoice 转写已分享的音视频，语音识别以分段方式处理长文件。音频卡片支持在播放器下方展开、滚动和收起转写结果。
- 改善聊天与会面的表演片段顺序和逐段朗读，避免后续陪伴回应用同一片段标识被误跳过。
