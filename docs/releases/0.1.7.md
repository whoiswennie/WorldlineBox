# WorldlineBox 0.1.7 · Windows

下载并运行 `WorldlineBoxSetup.exe` 即可安装或覆盖升级，适用于 Windows 10 / 11 x64。下载页同时提供 SHA-256 校验文件。

- 在伙伴聊天中打开附件即可查看文档、图片、视频和音频。图片支持按原尺寸查看、旋转和导出 PNG，文本支持查找、编辑和另存副本，音视频支持选取片段并导出。
- 在外观设置中选择「超时空辉夜姬！」即可使用九段内置动态视频壁纸，安装后可离线使用。壁纸声音默认开启，可在外观设置中关闭，重新启动后会保留选择。
