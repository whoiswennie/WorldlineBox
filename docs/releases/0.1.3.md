# 世界线盒子 0.1.3 · Windows

下载 `WorldlineBoxSetup.exe` 即可安装或覆盖升级，适用于 Windows 10 / 11 x64。同页提供 SHA-256 校验文件。

本版安装包已更新。Windows 任务栏和快捷方式使用程序内嵌的世界线盒子图标。若升级后旧的固定项仍显示白纸，可取消固定，从开始菜单打开「世界线盒子」并重新固定。

- **手机配对**。打开「设置 → 手机连接」显示二维码。配对后，电脑和手机回到同一局域网时可以自动重连。异地使用时，若临时远程地址已更换，重新扫描这台电脑的二维码即可更新地址，并保留局域网配对。
- **消息推送**。「已配对设备」显示手机在线状态，可为指定设备开启信息推送。伙伴聊天显示未读提醒，桌面应用在后台时可收到带发件人和消息摘要的 Windows 通知。打开桌宠后，由桌宠呈现回复，系统通知随之静音。
- **回复与朗读**。桌宠和视频会面可呈现伙伴的普通文字回复。伙伴调用表演工具时沿用其台词、表情和动作。长对白按完整句子分页并朗读。
- **远程交付**。手机单个附件最高支持 4 GiB，网速波动时可以调整分段大小并从已确认的位置续传。
- **DSH 启动期间的消息**。电脑和手机会立即看到未发送的原因。等待共享 DSH 就绪后可手动重发。撤掉尚未交给 DSH 的回复会立即生效。
