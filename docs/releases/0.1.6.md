# WorldlineBox 0.1.6 · Windows

下载并打开 `WorldlineBoxSetup.exe` 安装或覆盖升级。适用于 Windows 10 / 11 x64，同页提供 SHA-256 校验文件。

- 在伙伴回复下方点「在 DSH 工作台查看会话」即可查看生成这条回复的原始实例和会话。复制和朗读仍在原位置，消息引用入口已移除。
- 聊天中的应用开关跨话题保存。与 Android 0.1.5 配对后，在任一端修改都会同步。关闭应用会停止新的工具调用，历史音乐和视频卡片会提示重新启用。
- 在「设置 → 手机连接」查看和管理多部手机。「清理失效连接」可批量移除已解除的配对并清理过期远程地址，保留仍可重连的局域网配对。
