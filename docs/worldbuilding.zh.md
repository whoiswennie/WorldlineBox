# 世界线、素与幻

[English](worldbuilding.md) | 简体中文

世界线：幻想不绑定某一个固定舞台。它是一道入口，让原创世界、角色、历史与可能的未来能够被观测、被记录并彼此连接。这些世界共享的创作基础，是**“素”体系**。

## 素

素是世界得以形成的底层基质，可以通过两个不可分离的侧面理解：

- 作为物质可能性，它近似粒子：能够聚集、分化并形成结构。
- 作为意识与关系，它近似波：能够共振、干涉、留下记忆并被观测。

观测不只是整理一份已经完成的现实，也会帮助可能性形成秩序。因此，一个世界可以被理解为广阔可能性之海中的暂时稳定形态；变化、同化与演化始终是世界存在的一部分。

这是一套创作模型，不是对现实物理学的主张。它为不同故事提供共同语法，却不要求它们拥有相同的类型、时代、宇宙结构或结局。

## 幻

幻是原创角色，也是串联世界线的关键观测者。她代表可能性、变化，以及道路尚未唯一确定的时刻。她不会支配每一个故事，也不会把所有世界改造成同一种剧情；她可以见证、穿行、记录，有时也会影响某个世界，同时让其中的人与后果保持自身的意义。

与幻相关的白色与黑暗形态表达一组相对运动：可能性可以展开，已经成形的事物也可以解离并回归素海。这两种运动都不是简单的善恶标签。

> 每一个世界都有其故事，每一个故事都值得被观测。——幻

## 与软件的关系

叙事层与技术层彼此呼应，但不会混为一谈：

- 运行时 **Profile** 是进入某一种能力世界线的方式。
- **插件**在不重写整个系统的前提下加入一项边界清晰的可能性。
- 可重放的**会话事件日志**保存观测结果和状态变化过程。
- Host/Client 边界让同一个世界可以通过不同界面投影。
- 幻赋予项目身份，Cordis 则提供组合纪律，使众多可能性仍然保持一致。

未来的世界线内容应当保持原创、与“素”的基础相容，同时为拥有不同审美和规则的故事保留空间。设计过程中的参考资料仅作为灵感来源；本项目不会把其他作品或世界设定宣称为自身正史的一部分。
