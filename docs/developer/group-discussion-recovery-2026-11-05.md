# 群聊调度、主脑恢复与会面字幕稳定性

## 群聊

同一个群聊或伙伴私聊一次只租用一个发言轮次，不影响其他会话并行处理。下一位在开始时捕获实际已发布消息的水位，将此前伙伴的新回复纳入上下文；首次原生派发后，重试仍恢复原始输入和 VCP preparation，避免重组上下文导致重复执行。

智能参与每次最多考虑 12 位候选，候选按轮次轮换，由一次共享判断选择最多 3 位发言。未选候选直接完成隐藏事件，不启动其记忆或主脑。千人群不会创建千个自动判断/记忆任务；成员和联系人目录仅提供有界预览，完整公开目录可用 `agent_state` 回查。明确点名、全员模式和“每人一份”仍遵循对应接收者，排队容量继续受现有背压约束。

默认交付回复不启动互相点评。只有用户邀请自由讨论且判断器明确允许时，才允许自动接话；同一源活动自动回复总预算为 6 条、每位最多 2 条、时限 120 秒，并保留原有因果深度和活动预算。待处理接收者不会再次被分配同源接话，新用户消息会中止旧自动接话。群聊增加“停止讨论”，保留未发送草稿；明确停止会取消当前及排队回复。取消一个候选不影响其他候选，但全体停止后连共享参与判断也取消，提供方不响应信号时仍能释放调度槽。

## 记忆与主脑

`memory_write` 在 DailyNote 文件和原始操作日志落盘后返回真实 `pending` 回执，明确 `durable:true,indexed:false`。索引由耐久后台作业继续核验，每次观察最多占用约一秒并有延迟重试，不把索引等待放在聊天关键路径上。自动互动记忆也分别安排索引作业，保持原有编码来源和幂等键。

新增原始写入回执查询，可由操作日志、原内容散列和已存在的唯一日记文件恢复丢失回执，不再次执行写入。向量索引尚未完成不能当作写入未发生，也不能宣称已经可召回。索引启动/排空本身挂起时，观察者同样受截止时间约束。

App 主脑在接纳新输入前核验遗留轮次。已证明的回执提交到原调用；证明未派发的步骤保留明确未执行结果。真正无法确认的副作用进入隔离状态，原参数、调用标识和记录保留；相同写工具暂不再派发，无关聊天和查询可继续。后续核验获得证明时可解除隔离。不会靠修改数据库伪造取消或重发未知写入。未知结果恢复和通道忙等待均有次数/时间边界。

取消恢复和保留窗口也识别隔离回执：它是明确的 `failed + quarantined`，不是工具取消成功。只解除旧轮次的接纳关卡，不计为已提交上下文、不把它选作交接边界。未知写工具的防重发覆盖同一逻辑通道的后续 epoch；读旧回执仍使用原事件绑定的 epoch，避免切换上下文后失去核验能力。

保留窗口交接与撤回产生的换代分别处理：只有已记录的保留交接允许核验旧 epoch 的回执；撤回会抬高 `native-recovery-floor`，继续阻止旧授权的读写恢复。没有该证据的历史换代采取保守隔离。手动“记住”同样安排独立索引作业，保存成功不冒充已经可检索。

调度器、App 模型请求、插件调用及任务取消均有外层可中断边界，避免底层忽略信号或错过已发出的停止事件而永久占槽。主脑同一通道的接纳过程也被串行保护，恢复期间不会并发接纳两个请求。

运行时依赖链接使用 `lstat` 识别失效链接。安装路径改变或跨电脑复制后重新连接当前安装目录；只移除旧链接本身。已有实体依赖目录保留在同一运行时下的唯一备份目录，再建立正确链接；失败时尽可能回退，不删除日记、聊天或旧依赖内容。

## 会面字幕

字幕容器保持整行固定宽度，避免文字长度改变容器宽度、容器宽度改变分页、分页又改变文字长度的反馈循环。实际播放轮次携带冻结的原始字幕，媒体时钟仅推进揭示前缀；旧草稿快照不替换正在播放的原文。播放控制回调身份保持稳定，后续消息继续排队。

## DSH 版本与资料交接

移除伙伴启动选择器中的固定 DSH 版本范围，桥接包允许包括 alpha、rc 在内的版本；继续校验实际运行环境、已安装包内容和必要接口。新版不再仅因版本号而被拒绝。伙伴界面显示默认实例缺失、未启动、启动中、失败及恢复操作。

官方 `0.2.2-rc.1` 在独立测试环境完成协议验收：真实 DSH Host、768 维本地向量模型、记忆保存/索引/召回、自动记忆、委派文件任务、Host 重启和上下文交接全部通过。语言模型为确定性协议测试服务，不将此结果描述为真实模型质量评测。

另使用已有本机登录凭据在隔离 profile 完成真实模型生态测试：两位伙伴分别调用本地插件与技能、返回实际工具结果；验证插件启停一致性、完整 Host 重启后的会话恢复，以及备份/恢复后继续读取原会话。未修改来源实例的配置和聊天。运行结果位于本地 `artifacts/dsh-0.2.2-rc.1-ecosystem`；复现可设置 `WORLDLINEBOX_DSH_ACCEPTANCE_PROGRAM` 指向已安装的官方版本。

原生 lane 专项验证 rc.1 的 presentation 事件结构、Agent 本地工具与全局工具限制，以及 PiAiAdapter 的附件/文件服务注入。真实 `read_image` 通过官方 serializer 进入模型请求的图片块；正文不包含图片 Base64。独立的普通 preset 会话在 Host 重启后、任何 bot turn 之前恢复成功，同时覆盖无桥接 token 的官方 CLI 启动注册路径。

主脑获得同一受众、当前已发布水位以内所有授权文件的绝对路径。交接默认继承完整附件集，并核验任务私有副本；任务正文仅保留用户原文、相关聊天上下文、伙伴目标/指导、资料绝对路径。调度标识、队列状态和 grant 等记账信息保留在 Main。长原文和完整上下文可从任务中的实际绝对路径读取；来源撤回继续使关联任务失效。

## 附件与界面

聊天附件提供图片缩略图与音视频原位播放，支持专门的大窗预览。播放器不自动播放且不预加载完整媒体，打开大窗时卸载对应原位播放器，避免双重音源。自动图片缩略图受 8 MiB／20 MP 限制；显式打开原图不受该自动处理阈值影响，原有大文件系统打开策略保留。

普通聊天和会面内的原输入框共用文件粘贴意图识别，支持文件、截图和拖放；Explorer 没有提供浏览器 File item 时读取原生文件剪贴板的元数据，普通文字仍由输入框正常粘贴。剪贴板图片只在 Main 读取并持久保存，不从 renderer 接收伪造路径。文件列表超过附件数量上限时整批报错，不静默只取首个。
