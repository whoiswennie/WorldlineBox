# 桌面截图与录屏覆盖层

日期：2026-10-19。保留 WorldlineBox 品牌、独立版本、浏览器采集、资产库保存和临时问答协议，增量调整全局屏幕工具的交互。

## 使用方式

- 截图默认 `Ctrl+Alt+Shift+S`，录屏默认 `Ctrl+Alt+Shift+R`；侧栏、浏览器工具栏和设置中的入口使用同一套屏幕工具，快捷键可在设置中修改。
- 在真实桌面上单击可选择原生窗口，拖动可自由框选；滚轮或 Tab 切换鼠标下的窗口、工作区与整屏候选。“不含任务栏”和“使用整个屏幕”提供明确入口。
- 截图选区保留原位置，可移动、调整八个方向的边界，直接绘制矩形、椭圆、箭头、画笔、荧光笔、文字、遮盖和马赛克。浮动工具栏根据选区和屏幕边缘重新定位。
- 截图使用细蓝色边线、角点及选区外遮罩提示范围。屏幕区域录制开始后仍显示 2 物理像素的柔和蓝色边界线，提示条在实际裁剪矩形外，鼠标可穿透，停止/取消/失败后清除；这些边线不进入导出视频。靠显示器边沿且没有外侧像素的一边不画线；整台显示器的录制范围就是屏幕四周，不改变原始录制尺寸。
- “复制并完成”或 Enter 复制后退出；Ctrl+C 同样完成复制，Ctrl+S 保存到下载目录。普通复制、保存到资产库、撤销/重做和滚动截图仍可使用。右键先取消选区，再次右键退出；Esc 退出。
- 图片问答在浮动面板中进行，发送当前已编辑的像素，支持临时多轮、取消和清空。关闭即清除对话，不写入聊天历史或配置。
- 录屏同样直接点选或框选。选区旁提供 MP4 / WebM / GIF、原始分辨率 / 1080p / 720p、系统声音、麦克风和开始按钮；按选区比例缩放，不放大小画面。默认原始分辨率、系统声音开启、麦克风关闭。
- 录制中显示单行计时、声音开关、暂停/继续、停止保存及取消。已有音轨可随时静音/恢复；麦克风需要在开始前开启。控制条固定在输出区域外，不能被拖进画面。
- 所有截图、录屏及兼容工作台窗口使用无系统标题栏的窗口。工具栏以图标呈现，悬停显示说明，并保留辅助名称、键盘焦点和选中状态；格式、画质、分辨率及计时保留文字。录屏来源选择按需展开，录制中的控制条宽度为 320 DIP，空间有限时最低 280 DIP。旧工作台的自定义标题可拖动，关闭按钮始终保留。
- 优先在选区外或任务栏空余条带放置控制条；另一台显示器有空间时也可使用。单显示器整屏录制无法提供画面外位置，控制条会隐藏，通过再次按录屏快捷键或托盘“停止录屏并保存”结束。开始前工具栏的信息图标提供此行为及录制时长的说明。
- 视频最长两小时；GIF 最长 60 秒，导出 12 fps、最长边不超过 960 像素且没有音轨。文件仍默认保存在系统下载目录下的 WorldlineBox 文件夹。原有 16 GiB 文件上限及失败后保留可恢复 WebM 的规则继续生效。

## 实现与可靠性

`DesktopScreenshotOverlay` 复用已有标注绘制、像素导出和临时问答协议，桌面编辑不再进入缩小的工作台容器。显式网页/原生窗口图像及拼接结果仍保留原有工作台兼容入口。

Windows 在 Main 中使用 koffi 读取窗口 z-order、DWM 可见边界、隐藏/最小化状态、原生显示器和工作区物理矩形。目标窗口按当前显示器裁剪，支持负坐标；其他平台仍提供工作区/全屏和自由框选。窗口吸附只识别原生窗口，不宣称识别网页内部控件或图片。

录制边界使用独立的透明、无框、鼠标穿透覆盖层，在透明 Canvas 上按物理像素绘制四条范围线；其余像素保持透明。Windows/Chromium 会把极窄窗口放大到宿主的最小尺寸，因此不以窄小实色窗口绘制边界，避免粗色框及灰白底框残留。边界层没有 preload 或外部页面，内容和 CSP 由 Main 生成。

150% 缩放下，Electron 取整后的 1707×1067 DIP 不能直接当作 2560×1600 的物理像素尺寸。截图改用 `GetMonitorInfoW` 的实际尺寸；原生覆盖窗口先解除固定尺寸约束，再按物理像素定位。界面仍是无边框、无原生缩放边框、不可移动的覆盖层。区域转换对原生像素整数的浮点误差作精确取整，避免多截一行任务栏。

旧实现给工具窗口调用 `setContentProtection(true)`，Windows 会设置 `WDA_EXCLUDEFROMCAPTURE`，因此远程屏幕采集可能看不到界面。截图、录屏、划词工具均改为可采集的 `false`；拍摄背景前隐藏工具本身。录屏通过把控制条放到真实裁剪区域外解决自录，不用防采集标志或伪造背景遮盖视频。

原画质、1080p、720p 的 MP4 编码目标分别为 16 / 8 / 4 Mbps；实时采集按输出尺寸选择 4–16 Mbps，30 fps。后台计时和画布绘制不因控制条隐藏而被 Chromium 限速。帧率和实际码率仍取决于系统与编码器，原画质表示保留源分辨率，不表示无损编码。

托盘停止也覆盖等待媒体权限/媒体流的准备阶段，迟到的流会清理，不能在用户停止后继续开录。切回屏幕来源会重新进入桌面选择器。MainFrame 授权、独立最小预加载桥、一次性媒体授权、分块顺序与大小限制、恢复文件和自动隐藏/恢复主窗口均保留。
