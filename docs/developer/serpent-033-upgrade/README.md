# Serpent 0.3.3 资产管理增量升级

WorldlineBox 基于本机 `C:/Users/hp/Desktop/project/new/Serpent` 的 0.3.3 发布源码，按上游 0.3.2 `7e86e1b0` → 0.3.3 `dbf4c27b` 的差异逐区块整合。未替换整个上游目录或业务文件；有本项目扩展的文件通过共同基线对照、上下文补丁和冲突处手动适配处理。

## 同步内容

| 功能 | 实现及适配 |
| --- | --- |
| 模型双面 | 工具栏切换；PBR、灰模、网格均支持；关闭时恢复模型材质原有的面设置；加载完成后重新应用显示偏好。 |
| 模型信息记忆 | 默认关闭；双面、信息面板、显示模式保存在原有 `worldlinebox.viewer3d.preferences` 中，旧设置读取时补默认值。 |
| Alpha 贴图 | FBX 基础颜色 Alpha 裁切；不改变已经开启混合或裁切的材质；TGA 等非浏览器格式解码为 RGBA，与网格一起缓存。查看器和卡片共用加载路径。FBX 转换缓存版本更新到 `ufbx-wasm-3`。 |
| 路径快捷键 | 资产与文件夹支持默认 Ctrl+Shift+C / Option+Command+C；沿用本项目自定义键盘和鼠标绑定系统；Main 转发实际按键组合，查看器内也可复制文件路径；编辑框、设置对话框继续拥有输入。 |
| 筛选成员更新 | 喜欢、评分、手动标签、源链接及尺寸变更后即时移除明确不匹配的可见条目；涉及 AI 合并值等不确定数据时重新查询；虚拟列表同步更新并保留布局。 |
| 链接资产删除 | 从磁盘删除快捷键与菜单共用定义，包含链接资产及多选；保留本项目普通 Delete 不删除链接文件的既有规则与危险操作确认。 |
| 后台预览 | 可见窗口任务完成后由独立后台范围继续处理持久队列；失败按退避重试；关闭资源库时取消后续唤醒；小图原文件预览带 revision 和路由回传，避免旧事件覆盖新版本。 |
| 卡片 | 说明区减轻，布局高度与 CSS 同步；恢复选中轮廓；仅修正整数取整造成的细缝，保留真实纵横比。自定义卡片颜色作用于预览区域。 |
| 菜单及设置 | 统一主题下拉菜单；窗口边缘自动翻转/限制位置；字体菜单随主题；设置输入框和按钮描边统一；缩短删除和权限说明。 |

## 自有功能边界

- `package.json`、锁文件、应用名称、独立版本、安装器和应用 ID 保持不变，用户数据目录仍为 WorldlineBox。
- 保留内置多模态向量模型、设备能力检测、全局模型服务、索引与语义搜索。上游 `SemanticSearchSettings.tsx` 只改其默认模型下拉框；本项目早已用内置模型管理流程替代该控件，因此保留本项目整个流程，不重新引入上游模型选择/下载页。
- `LibraryEmbeddingSettings.tsx` 仅替换下拉控件，保留本项目“继承全局模型/关闭”两项，不引入上游其他模型与外部服务选项。
- 保留资产模块与启动器/浏览器的隔离、快捷键自定义、伙伴、采集、网络与运行环境逻辑。
- 资源 URL 仍使用 `worldlinebox://`，数据库目录仍为 `.worldlinebox`。RGBA GLB 内的 `serpentRgbaTextures` 等内部字段沿用上游格式，属于缓存协议字段，不是产品名称。
- 数据库 schema 无变化。测试使用独立临时资源库和 profile，不打开用户资源库。

## 本项目补充

合入时同时处理了主题下拉框关闭后的焦点返回、字体菜单键盘初始焦点/输入法 Escape、浮层宽度限制、RGBA 缓存块损坏时的容错和 Windows 贴图解码工具隐藏窗口。模型卡片缓存版本从 `offscreen-webgl-1` 升至 `offscreen-webgl-2`，使已经生成的旧黑底缩略图沿既有可见窗口任务机制按需更新，无需清库。新增真实窗口回归验证模型偏好、查看器复制路径、可修改路径快捷键和筛选即时移除。

文件夹路径快捷键按当前焦点分派：侧栏文件夹聚焦时优先处理该文件夹，避免残留的资产选择导致同一默认组合键无人处理。无文件夹焦点时继续保留资产优先规则。

旧 E2E 脚本按本项目启动器入口更新；保留本项目真实内置模型的 SQLite 生命周期测试，不替换成上游外部语义接口夹具。
