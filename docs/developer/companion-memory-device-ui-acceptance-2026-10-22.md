# 伙伴记忆工作台与设备能力补充验收

日期：2026-10-22，Windows x64。本次补充覆盖伙伴资产库创建、真实角色归属、记忆处理可见性、文档规模和设备能力门控。原有三伙伴持续生活与内容质量验收见[伙伴系统闭环验收](companion-system-acceptance.md)；本文件不把旧安装包的验收结果冒充为新源码的发布验证。

## 角色身份与记忆处理

- 日记投递、上下文视图、月度时间线与摘要都绑定稳定伙伴 ID 和当前姓名。身份/姓名变化参与视图与投影签名；缺少身份签名的旧时间线、其他角色或旧姓名的投影不再直接显示为有效内容。修订、来源与模型校验在发布前重新执行。
- 原版月报文件中的月末归档日期不是事件发生日期。角色的虚拟世界日期与文件实际创建/修改时间分别保留，不把过去的约定写成已经完成的经历。
- 使用真实全局聊天模型与内置 Gemma，分别生成小肥鱼/大肥鱼的月报与摘要，9 项内容断言通过；小肥鱼的串门约定、大肥鱼的阅读书签互不串线，来源正文未被月报改写。原文与回执位于 `artifacts/vcp-validation/timeline-identity-real.json`。它是小样本归属验证，不是长期人格质量的结论。
- 处理记录从持久 capture/outbox/TagMaster 任务及真实运行中的时间线任务读取。时间来自真实数据库记录/触发器；旧任务缺少时间时显示未知，重启前时间线阶段不补造历史。筛选与数量按伙伴及状态在服务端计算，列表有界，来源预览需再次验证归属与当前来源。
- 记忆是伙伴内部真正的子页，不以全屏对话框遮挡二级导航。消息、联系人、世界与社交入口始终可用；切换页面保留目录、选中文档及未保存草稿，隐藏时暂停订阅与轮询。聊天的处理入口进入同一子页并选择实际伙伴。
- 处理工作台采用状态目录、任务列表、选中详情；按容器宽度切换列表/详情，窄窗口保留返回入口。规则说明默认折叠在工具栏信息入口。来源检查、正文保存、自动标签、进入索引分别呈现，不把任一步骤完成称为“已学会”。聊天手帐和行动记录只显示当前伙伴，延迟回包与迟到的重试不覆盖另一位伙伴。
- 同会话的时间线只重试最新任务；已失效的旧版本不永久挂起。复测模型时先同步进入检测状态，再等待旧模型完全释放；单个资产请求取消只取消自身等待，不取消其他伙伴共享的设备检测。

## 文档查阅与规模

创建/修改时间、体验发生时间分别显示。列表默认按最近修改排序，也可按创建时间排序、日期区间、标签、全文或语义检索。语义检索保持相关度顺序，不将整个伙伴目录数量冒充命中数量。

列表每页最多 64 条；后台 SQL 使用稳定时间与路径游标，前端不再按类别重新打乱排序。目录增量扫描跳过未变化正文。只读取选中文档，有关它的正文版本未变化时，后台其他变化不反复传输整篇正文。单文档读取上限仍为 2,000,000 字符，阅读视图每段最多 16,384 字符，上一段/下一段切换不累积 DOM。原文件内容完整保留；分段边界处复杂 Markdown 的跨段格式仍是边界。

本机合成十万条元数据分页、三千真实文件增量目录测试通过；这些测试不证明十万篇真实模型全量向量化的首建耗时。初次扫描与向量建设仍需时间。

## 常规设备检测与功能门控

- 打开设置只读文件、硬件及缓存状态，不加载模型。首次实际向量请求或手动检测执行同一短测：3 个固定中英文短文本和一张 224×224 小图，检查完整性、有限归一化的 768 维向量和耗时。检测结束、取消或超时均等待临时原生进程释放。
- CPU/GPU 使用同一预算，不按显卡品牌拒绝。模型加载前至少保留 3 GiB 当前可用内存；检测中低于 512 MiB 停止。启动预算 45 秒，短文本中位数 2 秒，小图 10 秒，总检测 60 秒。这些是本软件的安全/交互预算，不是模型精度排名，也不保证大型媒体吞吐量。
- 通过的 CPU/GPU 与设备编号用于实际模型启动。已测 GPU 随后启动失败时要求复测，不直接换成未经短测的 CPU。设备/模型/运行组件与检测版本参与缓存指纹，最长复用 7 天；当前内存压力仍重新检查。受限时禁止新模型会话，不使用旧无向量记忆替代，普通资产管理、全文搜索、聊天和已有文档查阅仍可使用。
- 资产语义搜索独立且默认关闭；设备受限时不能由关闭切为开启，已开启仍可关闭。伙伴记忆不受资产开关控制。
- 3D 仅检查真实 WebGL 2 小上下文、上下文状态与内存预算，立即释放检测画布。已知总内存小于 4 GiB 时暂停 3D；未知内存不被当作不足。正式场景渲染前也进行检查；图形上下文丢失时释放场景并允许复测恢复，生活数据继续保留。基础检测不承诺实际场景帧率。

本机独立真实短测约 4 秒：RTX 5070 Laptop 启动约 2.8 秒，短文本中位约 10 毫秒，小图约 75 毫秒。报告 `artifacts/vcp-validation/embedding-device-real.json` 记录的是这台设备、小输入与当时系统可用内存，不是模型 RSS 或其他设备的性能保证。
