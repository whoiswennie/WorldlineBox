# 伙伴任务循环验收

初次验收日期：2026-10-13；此前功能已提交远程 main。后续回归记录见下方。

## 2026-10-23：工具结果、社交续接与交付校验

用户反馈中的重复“我先去查”并非查询没有返回：原聊天固定消息游标被错误用于复验本循环刚生成的世界观察，导致有效工具结果在下一次推理中被撤去。现将原会话近期消息、实际工具来源和派生话题摘要分别复验；来源撤回仍清除证据，但新的合法观察不会因为晚于原请求而丢失。任意 JSON 中同名字段不再作为来源凭据。

持续社交目标从真实 outbox 保存完整原委托、已经执行的步骤及明确的群/话题端口。短暂忙碌时保存已授权动作，相关新回信改变已读集合时重新规划；无关私聊不影响。重启后同来源 Main 与后台任务不会抢跑，原聊天自身的初次移动仍可执行。多路回信只取本目标真实邀约派生的社交链，不取各私聊的任意旧历史。原聊天可得到实时回信进度，不能把未读正文理解成没有回复或没有人同意。

最终社交汇报在正式提交前由独立调用核验宿主事实，失败的草稿回到同一循环修正。该核验只使用相关任务进度、出站元数据、当前端口与必要人物名称映射，不带其他私聊正文；普通聊天及非社交任务跳过。通信状态只表示可达性，不能远程读取对方身体作息；内部 ID 与自然称呼通过宿主映射绑定。

实际模型验收入口为 `tests/worker/companion-social-initiation-content-acceptance.test.ts`。设置 `WORLDLINEBOX_SOCIAL_INITIATION_ACCEPTANCE=1` 后，使用应用当前聊天连接、隔离 SQLite 与实际调度器，输入原句“你去找你妹妹还有别的伙伴玩狼人杀”。模型自行选择查询、认识、邀请、建群及话题，不由夹具选择动作。验收要求原循环结束、真实群建立、首轮实际收件人作业及组织者总结完成，至少两位伙伴独立回应，并以实际消息和各次可见快照另行判断身份、人数与事实报告。持续目标可以继续后续游戏，不能把未来全部作业空闲作为首轮完成条件。

这项在线验收仅覆盖认识伙伴、组局和首轮交流，不能证明完整狼人杀对局、暗牌分配或任意模型语义永不出错。失败尝试与后来修复的证据均保存在本机忽略目录 `.tools/test-output/`，不随源码提交。SQLite 回归另覆盖撤回、重启、取消、延期、读集竞争与玩家可见群的端口保持。

界面已移除聊天区额外话题工具栏，顶部使用同款纯图标打开管理；休眠提示移入输入框辅助行。亮暗和宽窄四种真实 Electron 截图及激活行为已检查。记忆库 400 份文档的实测目录 API 为202ms、首屏351ms；保留一项并发运行测试时2656ms的超标记录，不能将受控结果解释为任意系统负载的绝对保证。

## 2026-10-14 并发消息隔离与轻量过程入口

当前回复明确绑定源消息，启动时保存基础上下文，之后只追加本循环工具结果和明确引导。真实 SQLite 和服务调度回归中，天气能力保持运行时发送时间问题，时间能力先返回；两个回复气泡、工具结果和源消息分别对应，基础上下文在后续步骤保持一致。另一个场景在原消息之后写入150条新记录并重启，恢复仍使用原上下文。模型与执行器在这两项回归中使用 fixture，不作为真实天气数据或模型行为评估。

气泡内按实际步骤保留正文与轻量能力入口，完整日志和停止、恢复、结束进程操作在任务窗口。桌面 fixture 验证并行入口打开指定任务、较早任务不被第一页选择覆盖、引用跳转以及短任务名不被截断；同时保留角色分页、FIFO重启、群聊恢复和独立模型连接回归。运行 `node scripts/run-e2e.mjs tests/e2e/companions.test.ts` 可重新生成 `verified-capability-entries.png` 和 `verified-linked-task.png`，输出到本地忽略目录 `.tools/test-output/companions/`，不含用户实际消息或模型凭据。历史截图和原始回执不随源码分发。

## 真实执行与自动化的边界

十章写作、修订和时间查询使用应用已保存的全局 DeepSeek 连接、真实 DSH CLI 与已安装官方 0.2.1-alpha.2 SDK。角色主脑只有 dsh 工具，任务内文件读取、PowerShell、写入与编辑来自原生 agent。测试者只建立共同任务说明并汇编完成的章节，没有代写章节正文。

自动化 UI/模型协议测试使用明确的模型或历史数据 fixture。它们验证展示和持久化，不冒充真实模型完成任务；原生启动与工具集探测不会调用付费模型。

## 表现与实际局限

首稿达到了文件数量、作者分工和长度要求，但小肥鱼把 2056 写成 2063，且后五章与第05章会议时间不一致。随后通过真实完整任务要求她阅读全部十章，仅修订自己的五章并更新验收报告。年份和会议时间已修正；01–05 的前后 SHA-256 一致，证明未修改姐姐章节。

这次修订约 583 秒，包含较多细粒度编辑，说明持续执行与错误修正已通，但规划和编辑效率仍有优化空间。小说不等于经过专业出版编辑：班次口径、早年人物年龄和部分信件描述仍有细节张力，报告已保留，不将模型的「全部通过」直接当作文学一致性证明。

早期真实测试还暴露了原生 setup 回调必须返回 void，以及同一实例并发准备 CLI profile 的竞争；已分别修复，再完整重跑两角色并发验收。

## 时间、过程与历史

「大肥鱼看看现在几点了」直接启动实际工具任务并成功读取 Get-Date / Get-TimeZone。验收记录为 2026-10-13 19:47:51，China Standard Time，UTC+08:00；它是读取当时的结果。观察到公开文本 token 快照和工具参数草稿，前端可展开或在任务弹窗切换查看，不展示原始思考链。

任务历史在 SQLite 按创建时间和 ID 倒序游标分页，按角色筛选。125 条真实数据库记录覆盖多页完整性、最近100条之外的直接详情、角色隔离与重启。桌面端用45条离线 fixture 验证20条一页、上一/下一页、角色计数、毫秒时间、时区和过程内容。时间保存 UTC，按本机时区显示；旧记录不伪造缺失的开始时间。

当前进度窗口保留每任务最近150个合并事件，Broker保留最多1000个事件；原生完整 session 由 DSH 保存。应用退出会中断正在运行任务，不自动重放外部影响。运行权限是启动时固定的 Launcher 统一配置，默认完全访问。

关闭应用发生在工具任务完成、角色汇报尚未结束的边界也已覆盖：已保存的 succeeded/failed 与结束时间保持终态，不再因汇报被取消而误改为 interrupted。回归测试使用真实 SQLite 并重新打开验证。

本机真实执行的原始回执不随源码分发，避免把私人桌面内容、模型凭据或实际聊天带入仓库。界面自动回归使用隔离 fixture，当前截图输出到 `.tools/test-output/companions/`；任务代码、数据协议和说明为本项目独立实现，没有搬运 DeepSeek-Bot 或 Harness loop 源码。

## 中断恢复验收

真实 DSH SDK 与已保存的全局 DeepSeek 连接在独立执行目录完成两阶段测试：先写 PHASE1，再通过 PowerShell 等待测试者解锁。在等待工具运行时结束该 CLI 进程树，并在中断前送入排队检查要求。随后重开同一原生会话，继续 PHASE2，再完成排队检查。

实测恢复前后 session ID 相同；`恢复验收.txt` 中 PHASE1、PHASE2 各一行，`queue-report.txt` 中 QUEUE_OK 一行，没有重复第一阶段或排队动作。这些文件与原始回执属于历史本地实测输出，不随源码分发。测试只在内存中使用全局凭据，未加载或修改真实聊天库。

另有真实 SDK 零模型调用的跨进程恢复探测；真实 SQLite 调度测试验证恢复原权限、同一任务身份、普通群聊未完成发言和退出边界。桌面 fixture 实测软件重开后继续妹妹回复，姐姐已提交的消息只出现一次；CLI 进程测试验证结束选中进程树时无关进程保持存活。

## 统一主脑循环与持久队列验证

使用已配置的官方 DeepSeek 连接真实执行「小肥鱼查两条 AI 新闻」：主脑第一步仅调用 dsh，标准 DSH 实际调用 web_search / web_fetch 等31次工具，公开正文及工具参数都有流式事件；能力返回后主脑第二步生成最终 Markdown 回复。完整原始收据保存在忽略目录 standard-main-loop.json，不随源码发布。
