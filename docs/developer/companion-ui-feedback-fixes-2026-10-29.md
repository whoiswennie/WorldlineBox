# 伙伴界面反馈修复

本轮按实际截图修复四组问题。仅使用短时定向检查和隔离浏览器预览，没有再次运行长测、真实模型或编码器，也没有访问用户资产库。

| 问题 | 根因与修改 |
| --- | --- |
| 分组管理拥挤、原生下拉框突兀 | `.sr-only` 没有定义，原本隐藏的标签和表单挤在侧栏。改为集中管理弹窗：分组列表、成员选择、清晰的新建／重命名区域、主题分组菜单和批量移动。侧栏保持普通联系人列表；关闭后回到原焦点，隐藏模块移除弹窗和菜单，不复活旧界面。 |
| 自动同步提示跨页残留、无法关闭 | 资产页被Activity隐藏时暂停了计时器与订阅，但body Portal绕过了模块隐藏。现在由模块布局生命周期移除提示宿主，清理瞬时通知；返回不复活旧提示，之后的新同步仍正常提示、关闭和超时，全局设置通知仍可用。 |
| 报告预览透明、Markdown混成原文 | 旧背景引用不存在的token，面板透明；文本一律使用pre。现在使用实底阅读器，Markdown复用已有GFM／公式／代码／Mermaid渲染；保留阅读与原文切换。普通文本仍字面显示，外链仅点击后打开，图表失败局部显示源码。 |
| 记忆首屏慢、旧导航拖垮整页、反复加载 | 原首屏串行核对64篇，列表中一个旧导航就整页失败；无关全局变化还会清空档案。现在首批12篇，其余后台继续，准确持久索引可复用，独立文件最多4路校验；过期导航退出当前目录而不影响有效笔记，直接读旧导航仍拒绝。档案保留已核验画面并合并后台刷新，非文档页面停止文档轮询。 |
