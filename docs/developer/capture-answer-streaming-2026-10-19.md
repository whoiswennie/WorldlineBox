# 临时问答的流式输出与 Markdown

划词助手和桌面原位截图问答，原先等待完整回复后才显示普通文字。现在接收主进程的实时累计快照，逐步渲染正文；接口实际返回的公开思考内容另放在默认折叠的「思考过程」中。未返回思考的模型只展示正文，不生成替代分析。

旧的容器式截图工作台组件与专属样式已删除，不再保留网页截图的另一套编辑界面。所有截图入口，包括遗留的 `source: 'browser'` 请求，统一取得真实桌面，直接框选和原位编辑。问答仍在选区旁的轻量浮层中。拼接长图和显式窗口快照也使用同一浮层，自动选中整图并保持宽高比；缩放窗口后，图片、选区和标注坐标保持一致。

默认模型保留 `deepseek-flash`，两个工具沿用设置中的全局模型，本次没有切换或覆写用户的模型配置。

## 使用与界面

- 正文和思考均支持 Markdown/GFM：标题、强调、列表、引用、表格及代码块。横向表格、代码和较长思考分别滚动，不撑开浮层。原始 HTML 不执行，模型图片不会自动联网加载；只有用户主动点击的无凭据 HTTP(S) 链接可交给系统浏览器。
- 截图问答使用自动增高的紧凑输入框，范围 44–128px，去掉原生拖拽角；发送、停止使用带可访问名称的图标。Enter 发送、Shift+Enter 换行，Ctrl/Cmd+Enter 仍可发送。截图浮层背景完全不透明，桌面问答使用局部浅色主题变量，避免深色主题造成浅底浅字。
- 划词助手保留轻量浮窗、可展开原文引用和独立对话滚动区。所有入口保留临时多轮、停止、清空和关闭行为；停止会还原待发问题及上一轮已完成对话。链接启动失败在当前面板提示，保留回答。

## 传输与生命周期

五种现有接口格式均使用真实 SSE：OpenAI Chat、OpenAI Responses、Anthropic、Gemini 原生和 DashScope 原生。服务忽略 stream 参数而返回 JSON 时仍能完成问答。DeepSeek 不再被这些临时问答请求强制关闭思考；已知模型按官方参数请求公开思考或摘要，未知兼容模型保持自己的默认参数。DashScope 按模型使用明确的增量或累计模式，不凭文本前缀猜测增量以免丢失重复词。

正文和思考在主进程分开解析，排除签名、加密思考、工具调用等内部数据。SSE 总量限制 1MiB、单事件 128KiB，JSON 256KiB；可见正文最多 16KiB、公开思考最多 32KiB，按 UTF-8 边界截断。保留既有超时、取消、鉴权与限流提示、图片能力检查；图片问答不去掉像素重试，也不自动重发失败请求。API 密钥在跨事件拆分时也先保留未确定前缀，避免将密钥片段提前显示。

进度只发送给发起请求的独立工具主 frame，通过请求 ID、递增序号、AbortController 和窗口身份过滤。主窗口、普通网页和 iframe 不接收对话数据。主进程每约 40ms 合并更新并在结束前补发最终快照；渲染器先订阅再调用，取消、关闭、重选、卸载及窗口替换会阻止迟到输出。

多轮请求仅包含用户文字和已完成的助手正文，思考只保留在当前窗口的内存展示中。正文、思考与临时原文不进入应用聊天历史、localStorage、sessionStorage、应用日志或其他持久化记录。这里描述的是本项目本地行为，不替模型服务商承诺其服务端数据保留政策。
