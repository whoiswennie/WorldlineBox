# 伙伴的有限环境感知

伙伴知道自己亲自观察到的事。世界全局状态属于物理宿主和玩家的上帝视角，不能整份塞进主脑上下文，再期待一句“不要作弊”的提示词消除全知信息。

纯采样模块是 `src/shared/companion-world-perception.ts`。它不访问数据库、不写日志、不推进世界，也不决定行为。宿主提供当前真实场景、身体位置和环境，模块返回一个有边界、带来源时间的主观观察；模型、记忆和自主决策消费这个结果。

## 采样与持久化

`COMPANION_WORLD_PERCEPTION_INTERVAL_MS` 为 1000 毫秒，按现实采样间隔计算。加速世界改变世界中的时间流速，不把 1 秒感知扩大成每个渲染帧一次，也不会因为打开多个观测窗口而重复采样。离线补算期间只恢复身体生活，接续到当前时刻后再观察；不能事后替伙伴编造她沿未被观察的离线路线看到了什么。

采样是确定性的本地计算，不触发 LLM 或模型 API 调用。采样结果可以每秒更新当前知觉和最后看见时间。持久事件另外节流：有意义的变化按最多约 10 秒一条合并写入，场景变化和入睡/醒来可以立即记录。节流比较的是尚未发布的知觉变化，不能因一次变化恰好出现在冷却期内而永久丢掉它。事件保存摘要、可见 ID 集和环境，不在每条事件中重复整份有界认知图；主脑后续需要行动或对话时再读取最近知觉。

`companionWorldPerceptionSignature()` 忽略观察时钟、微小位移和没有变化的最后看见时间，包含以下内容：

- 自己所在场景、2 格空间分区、活动和清醒状态。
- 当前可见物体及其静态外形、当前可见伙伴的活动和 2 格位置分区。
- 已知对象 ID 集变化，包括观察到旧位置为空后的负证据。
- 天气及其来源、昼夜、四分之一亮度分档、2°C 温度分档。

`revision` 只在这种有意义的认知变化发生时递增。它是当前认知的变更计数，不是多套版本化行为逻辑。

## 感知范围与遮挡

基础最大半径为 10 格，以角色实际位置为圆心。可见半径为 `4 + 6 × localLight`，其中局部亮度限制在 0 到 1。黑暗中最低为 4 格，室内提供最低 0.65 的环境亮度。夜间只使用实际存在的路灯，9 格内按距离平滑增加局部光照；树木、建筑等实体可以遮挡路灯贡献，白天不启用路灯补光。

伙伴和家具只能从相同的 `sceneId` 观察。即使另一个房间具有相同局部坐标，或伙伴站在门口，也不能透视其他场景。家具按最近的真实占地边界计算距离，不能用一个恰好靠近角色的交互锚点把远处家具判定为可见。

视线在最大 10 格附近构造有限网格。建筑、树、厨房高柜和喷泉主体的实体占地按保守的二维遮挡处理；书桌、床、沙发等低矮家具阻挡行走，但不当作遮住眼睛的整面高墙。因此站在实际电脑锚点可以看见桌面上的电脑，也能越过低床和沙发观察。检查目标家具时排除它自身的遮挡，避免所有实体家具因为“挡住自己”而无法识别。对角交界采用保守 supercover 检查，不能从两个紧邻高实体的角缝中偷看。当前采用家具种类的眼高语义近似，不声称已有窗玻璃、精细高度网格、透明材质或三维射线系统。

## 当前可见与过去知道

`CompanionWorldPerception` 包括 `companionId`、`sceneId`、`position`、`activity`、`radius`、`awake`、`observedAtReal`、`observedAtVirtual`、`environment`、可见 ID 集，以及有界的 `objects/people`。

`objects` 最多保留 256 项，每项保存所属场景、真实对象 ID、种类/名字、占地、交互锚点、是否实体，以及 `firstObservedAt/lastObservedAt/visible`。这里不保存预约人、占用人、电脑工作内容或其他隐藏实时状态。`people` 最多保留 64 项，只保存实际见到的伙伴 ID、场景、位置、外在活动、最后观察时间和可见标志；不复制他人的精力、PAD、任务、路线、情绪内心或未来计划。

两类记录里的 `firstObservedAt/lastObservedAt` 是世界时间 ISO。当前可见记录优先保留，剩余容量保存最近见过的记录，最终按稳定 ID 排序。输入顺序不会改变结果，也不会在伙伴数量或地图家具增长时无限扩张热状态。

`visible=true` 且列入当前可见 ID 集，才表示本次确实看见。离开范围或被遮挡后，记录变为 `visible=false`，原位置、活动、名称和最后观察时间保持不变。宿主知道她已经去了另一个家，不意味着原观察者也自动知道；远程收到一句话也不会刷新对方现场坐标。

负证据同样有边界：旧家具所在占地现在确实处于可见范围、视线可达，但家具已经消失或移走时，删除这个失效的旧位置认知。这个过程不透露物品的新隐藏位置。旧位置在远处、被遮挡，或伙伴睡着时，保留带旧时间戳的见闻。

入睡停止新的视觉观察，清空当前可见 ID 集，把已有记录标为不可见。睡眠期间不刷新任何家具/伙伴的视觉事实。时间、局部光照与温度仍作为生理钟和当地环境感受更新，并通过 `awake=false` 明确区分；这不表示睡梦中看见了别人。

## 时间、温度和天气来源

`environment.time` 使用当前世界时间。温度采用所在室内或户外的真实环境值；光照是经过室内底光或实际路灯影响后的局部值。

天气不会默认为晴天。清醒时在户外可以直接感受天气；室内只有靠近真实房门 3 格内且视线可达时，才更新门外天气。目前没有窗户实体，因此不能以绘制在墙上的窗户装饰获得穿墙观察能力。

`weather` 可缺省，缺省就是尚不知道。已观察天气同时带 `weatherObservedAtVirtual`、`weatherObservedAtReal` 和 `weatherSource: outdoors|door`。回到室内深处或入睡后可以记得旧天气，但保留原来源和原观察时间；不能把世界宿主刚生成的新天气偷偷替换进去。上下文必须告诉模型这个区别，旧天气不证明现在仍在下雨。

当加速世界切回较早的日期，或世界时间因设置发生回退时，来源世界时间晚于当前时刻的旧天气失效为未知；比较只允许 1 毫秒的换算舍入误差。不能让“未来才看到的雨”永久压制当前日常机会，也不能把失效的雨改写成晴天。静态家具的历史空间认知仍保留自己的旧观察时间，不因天气失效而清空。

公园机会只按感知到的天气调整，不在室内读取全局实时户外天气。旧证据的新鲜度采用 `freshness = exp(-elapsedVirtual / 1800000)`，其中虚拟流逝时间从真实观察时间跨世界时钟分段累计，30个虚拟分钟是指数衰减时间尺度；不能用一次模式切换后两条世界时间直接相减。最终天气机会乘数为 `freshness × observedM + (1 - freshness) × 0.4 × unknownM`，两类乘数仍受本人精力、当前活动等条件限制。刚看见的雨会强烈抑制出门，旧雨则逐渐退为谨慎尝试，不会永久归零，也不表示已经晴朗。真正走到户外后才更新天气并执行恶劣天气返家。

## 模型上下文与公开地址簿

玩家可以看到全部伙伴和全地图，伙伴模型的 `world.observe` 及后续工具结果必须经过有限感知投影。模型侧只使用知觉中的物体和人物记录构建环境资料，不从全局 actor、家具表、工作表或旧工具 checkpoint 补回被移除的信息。

公开地址簿可以包含伙伴姓名及家所在的公开场景，用来计划询问、联络和寻路。知道某人的住址，不等于知道她现在在家、正在睡觉、与谁聊天或家中电脑空闲。家庭内的家具也不因地址公开而自动成为所有人的已知布局。历史观察、实际对话、消息来源和地图地址是不同证据，必须保留各自的来源与时效。

新模型边界还会移除被目击者的私有行为目的地与内部原因：看到她开始走路，只能证明这个外在动作，不能顺便得知她计划去哪个私房电脑。完整原始事件仍由物理宿主保存；角色得到的目击资料只保留本人witness标记，不公开其他伙伴在当时看见了什么。
