## 本项目功能边界

- 产品仍为 **WorldlineBox**。应用 ID、协议 `worldlinebox://`、资源目录 `.worldlinebox`、配置键、安装器、包名和独立版本保持本项目身份；没有导入上游 `package.json` 或锁文件。
- 内置多模态向量模型、全局模型服务、设备检测、768 维 SQLite 语义索引及自然语言/找相似流程保留。没有恢复上游外部模型选择或下载页。
- Worker 恢复会释放旧进程所属的语义会话内存，后续状态轮询用新会话读取原有向量。全局模型安装和其他模块使用的服务保持原有管理流程。
- 文本保存即使不创建新历史修订，也会为该资产更新语义内容代次并使旧向量/任务失效；旧编码任务不得回写。内容代次保存在既有语义侧库的 `index_meta` 中，不改模型身份或向量维度；未编辑资产继续复用原向量。未建立语义库时不额外创建侧库，未来版本侧库先只读探测并拒绝改写。
- React Activity 隐藏资产模块会暂停订阅。本项目新增 Preload 恢复状态回放及序号去重，保证跨模块返回后收到最新状态；恢复失败的活动资源库按现有关闭流程清理界面。
- 修正“仅排除标签”首次筛选未触发资产查询的问题；保留侧栏已有的文件夹自拖放保护。
- 保留启动器、浏览器、伙伴、采集、网络及运行环境扩展，以及当前工作区其他未提交改动。没有恢复已退役的伙伴文件或用户已删除的测试文件。
- 上游发布工作流、GitHub 模板、内部资料与基准实验脚本不覆盖本项目工程管理。打包校验只兼容上游更宽松的 API 版本读取方式，保留本项目公开 API 声明检查。
