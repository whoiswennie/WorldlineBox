## 本次额外修复

- 显式停止语义编码；关闭全局开关、切换模型或库绑定、关闭/删除/替换库时，按库等待本机与 HTTP 索引释放。准备内容后再次检查会话代际，避免关闭后继续发出请求。
- legacy 语义缓存读取失败时等待流关闭；ZIP 导出失败/取消时先关闭 archive 与输出流，再清理自己创建的文件。
- 新 Linux 来源元数据加入后，旧 Windows 媒体 ZIP 按目标平台验证完整信任元数据，继续保留 ZIP 和 manifest 哈希验证。
- 新主题弹窗遵守本项目的背景点击不关闭约定；保留旧布局工具栏高度。
- 插件社区保留内部 WorldlineBox 字段和用户配置，同时兼容真实上游目录 URL 与外部 `minSerpent` 字段。

## 内置浏览器资产采集

保留现有浏览器、多标签、独立持久会话和按需创建网页进程，在其上接入原扩展的采集实现。原 `extension/content-script` 与拖拽树菜单随应用构建，通过受限的 sandbox preload 兼容桥运行；主进程提供原生右键菜单、目标库查询、下载和导入。网页端只取得采集所需能力，不开放通用 Electron 或文件系统接口。

地址栏「保存到资产库」使用现有浏览器侧栏机制。侧栏展开时重算原生 `WebContentsView` 边界，网页与采集控件各占自己的区域。宿主状态通知更新库、目标、选项和任务；不通过持续轮询唤醒网页进程。

| 能力 | 实现与边界 |
| --- | --- |
| 保存目标 | 已打开且可写的资源库、根目录、普通及可用链接文件夹；保留最近保存/浏览目录与多级目录树 |
| 网页操作 | 原生图片/视频右键菜单；复用原扩展拖拽菜单的最近目录、根目录、逐层进入/返回、菜单外松开与 Esc 取消 |
| 传输与导入 | 使用原网页会话的 Cookie、页面 Referer 和应用网络配置下载 HTTP/HTTPS 媒体；流式暂存、大小限制及失败清理，再进入原资产导入与内容查重链路 |
| 本地图片 | 可信宿主 API 打开系统选图窗口，读取所选图片后走相同导入链；不向网页暴露绝对路径，继续限制浏览器导航为 HTTP/HTTPS |
| 保存选项 | 通知、保存后聚焦、资产定位、拖拽菜单四项开关持久化，默认全部开启 |
| 反馈与定位 | 显示任务、下载进度、取消和具体错误；按目标库所属窗口聚焦并定位资产，保留原浏览器模块状态 |

目录菜单为同名普通目录与链接目录分配不同的显示路径，保留真实 folderId 和实际导入位置。导入继续遵守本项目 IMPORT-007：目标同名时保留两份；目标名称空闲且库内已有相同内容时复用已有资产。

网页只在隔离世界中运行兼容桥；主页面、跨域 iframe 均保持 `sandbox: true`、`contextIsolation: true`、`nodeIntegration: false`。真实拖拽手势才可查询目录，真实松开才授予一次保存；网页合成事件不能查询私有目录或发起采集。主进程另校验所属 WebContents/frame、请求结构、目标库与目录，并在下载完成后再次确认目标可写。关闭页面/资源库时取消未导入的下载，退出时等待已接受的 Worker 导入结束。

严格 `style-src 'none'` 的站点会拒绝普通内联样式；内置模式因此为扩展自身的 shadow root 使用 constructable stylesheet，保持菜单布局且不放宽站点 CSP。外部 Chrome 扩展继续使用原有样式插入方式。

后续浏览器健壮性修复将内置采集初始化范围与浏览器导航规则统一为 HTTP/HTTPS：`about:blank`、`about:srcdoc`、`data:`、错误页及 `file:` 文档均跳过兼容桥，不再发送无意义的设置请求。主进程对无权访问、请求无效、页面关闭或跳转返回带错误码的响应，兼容桥按原 Chrome 回调的 `runtime.lastError` 语义处理，避免正常拒绝被 Electron 打印为主进程处理器异常；异步请求结束时再次核对页面归属及存活状态。真实沙盒回归现覆盖主页面、跨域 iframe 三次鼠标保存，以及不适用文档零初始化、导航/关闭期间的请求、分离 iframe 和非所属窗口拒绝；早期本地文件页面测试属于当时的受控适配器验证，本地图片仍通过原生选图入口采集，外部 Chrome 扩展的文件网址授权流程保持不变。

远程媒体单项上限 500 MiB，本地图片上限 32 MiB。`blob:` / `data:`、HLS/DASH 等分段流、MSE 与 DRM 内容不在支持范围，登录状态不保证网站允许下载。未新增网页扫描、批量采集或扩展弹出窗口；外部浏览器扩展的构建与安装流程继续保留。用户步骤见[浏览器使用说明](../user-guide/browser.md#保存到资产库)。

## 广泛测试的限制

没有将组合复核结果称为一次全绿的全量测试。Node 全量单测的 117 项原生 ABI 失败已在 Electron 中复核通过；两项 SDK 探针超时在串行复核通过；仅明确的 Windows 文件符号链接 EPERM 跳过。调整后的已核实状态为 5,341 项通过、31 项跳过，仍有本机缓存 DSH `0.2.1-alpha.3` 的启动就绪失败及两项未能归属的中断状态。同一 DSH 实际任务用已验证的 `alpha.2` 和原有环境覆盖入口可通过，未修改生产版本选择绕过失败。

Worker 全量运行的 ZIP 失败清理问题已修复并专项复核。默认 20,000 资产 soak 超过原有 600 秒限时，并导致后续断言失败；保持默认规模和阈值不变，另用既有配置入口执行 2,000 资产 soak，三项通过。Linux/macOS 实机、真实模型权重下载与模型质量不在 Windows 本次验收范围。
