## 功能与修复

| 项目 | 接入与适配 |
| --- | --- |

| 标签编辑 | 标签条件输入、光标词项补全、右键排除、语法提示和简单选择模式转换。无法无损转换的复杂条件需要明确选择是否清空；无效输入保留上次有效结果。历史标签选择转换保留 AND/OR、排除项与 AI 标签开关。 |

| 语义搜索 | 保留内置模型、全局模型服务、关键词与向量混合排序、分页及找相似功能。标签表达式传入既有语义候选筛选。自然语言中的未闭合标点可按原文参与语义搜索，关键词模式仍严格校验条件语法。 |

| 同步 | 传输期间保存设置立即回应；合并手动传输期间的自动同步需求。同一目标保存不重复传输，改绑目标在传输结束后跟进；旧目标完成不覆盖新目标设置。连接探测只读，有独立网络期限；传输中的库设置延后探测。 |

## 保留边界

- 应用仍为 **WorldlineBox**；包名、产品名、独立版本、应用 ID、`worldlinebox://`、`.worldlinebox` 路径和配置键不改。没有导入上游 package 或 lock 文件。
- 核心数据库仍为 schema 60，无新增迁移。没有重建语义侧库或向量，也没有改模型 ID、768 维向量身份、模型安装与设备选择逻辑。
- 既有智能集合 `clauses` / `groups` 查询仍按原含义执行；新查询使用独立的 version 1 表达式，协议禁止两种查询结构混合。
- 表达式解析阶段检查空白词项与树结构预算，和 IPC 校验边界一致，避免看似有效的条件直到发送后才被拒绝。
- 不接入上游开发启动中的模块再次注入和独立 mount 轮询：本项目已有懒加载、StartupBoundary、RendererReady 和启动握手。保留当前导航失败重试、现代 Electron 日志事件、按本项目进程路径清理以及独立 E2E 构建，避免重复初始化或覆盖开发构建。
- 不接入上游手工真实 WebDAV 测试的用户凭据复制流程；本次使用临时库及本地 WebDAV 测试服务器验证传输与保存，不访问真实同步目录。
- 不删除上游移除的内部图片，不接入发行版本号或内部工单资料。保留 Serpent 作者与贡献者的版权和来源声明。
- 没有改动伙伴模块及其未提交工作；按协作约定不独立提交、推送或制作安装包。
