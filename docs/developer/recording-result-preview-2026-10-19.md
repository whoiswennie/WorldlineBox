# 录屏结果预览修复

原结束页一直显示 `sources.list` 的 360×220 屏幕缩略图，将其放大为整块画面，同时保留来源、区域、格式和声音设置。该图并非保存的视频，因此既模糊，也不能播放。用户报告的实际 MP4 经本机只读核验为 2372×1334、H.264/AAC、4.938 秒，解码文字与图标明显比旧缩略图清楚；未修改或覆盖该原文件。

结束页改为独立结果预览：直接播放保存的 MP4/WebM，使用原生播放、暂停、拖动进度、声音和全屏控件；GIF 显示实际动画。顶部只保留文件名、保存状态、定位文件、再次录制和关闭，底部显示实际解码分辨率、时长、格式及文件大小。来源与录制配置仅在下一次录制时出现。错误和取消也使用简洁结果页，可恢复文件仍可定位和尝试预览。

默认适应窗口，同时限制到录制文件的原始像素尺寸；100% 模式允许滚动查看大画面。尺寸计算包含系统 DPI/窗口缩放，150% 显示缩放下一个录制像素仍对应一个物理显示像素。没有用插值放大缩略图冒充高清，也没有无依据地更改编码器。

播放使用隔离工具 Session 的 `worldlinebox-capture://recording/<随机令牌>` 协议。Main 只授权当前已生成的录制或失败后保留的 WebM，不接受任意文件路径。按需读取文件，支持 HEAD、单段 Range、206/416 和取消，不将两小时文件整体读取为 Blob/base64。预览能力在重新选区、关闭窗口、下一次录制和退出时撤销；读取前核对文件身份与尺寸，防止旧地址读取已被替换的文件。仅当前录制结果的工具主页面可申请全屏，截图选区、录制中、主窗口和子框架均不获得此权限。播放失败时保留定位文件与系统播放器入口；外部播放器或目录打开失败仅显示独立提示，不卸载正常播放的视频、不丢失播放进度。

WebM 在有捆绑 FFmpeg 时使用 `-c copy` 完成封装，补齐有限时长和定位索引，不重新编码；缺少 FFmpeg 时继续保留原有 WebM 保存能力。MP4 原有原分辨率采集、按比例画质档位、音轨、自动隐藏主窗口、画面外控制条与透明细边界均保留。
