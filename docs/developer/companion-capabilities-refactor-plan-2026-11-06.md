# 多伙伴能力重构目标与验收计划

状态：进行中。开始日期：2026-11-06。

目标是保留 Router 统筹、Worker 执行的职责，原生使用 DSH 的插件生态，并让用户在世界线盒子中管理伙伴的能力与运行状态。本文是实施清单，不把设计或受控测试冒充已完成产品能力。

## 调研依据与架构选择

源码证据见 [Super Agent 契约](superagent-task-contract-2026-11-06.md) 与 [插件隔离设计](companion-plugin-isolation-design-2026-11-06.md)。本地研究原型自述为研究与参考实现，不是官方产品兼容承诺。

- 一份不可变 DSH 版本供多个环境引用；每个私有环境有稳定身份和独立 Home、agents、工作区、浏览器登录态。普通伙伴继续共享默认环境，装备私有插件时自动建立环境。
- 工具过滤不等于原生插件配置隔离。拥有进程内服务、定时器、独立账号的插件应使用独立 Host；无需复制程序版本或常驻所有进程。
- Router 每轮只接收当前环境与配置版本的小卡。能力由真实原生注册表查询：概览 → 搜索和分页目录 → 工具参数／技能分段说明。插件资料属于参考数据，不扩张授权。
- 环境生命周期和业务任务状态分开。空闲回收保留配置和会话；工作台、任务、问题、后台作业与保活插件阻止自动回收。共享默认环境不能因关闭一位伙伴而被杀死。
- 旧任务沿其原生环境绑定恢复，不因伙伴装备改变而迁移或重放。升级保留同一环境身份，先完整快照，空闲时切换版本并探测；失败恢复旧版本及数据。

## 测试边界

受控本地模型服务用于验证传输、事件、工具执行和持久性，不代表付费模型的回答质量。内存占用只在取得所测进程的实际数据时报告，不按伙伴数量猜测。插件依旧以用户权限运行，独立配置目录不是 OS 沙箱；硬编码公共目录或外部账号共享状态的插件需要单独审核。

每个阶段保留可重复的测试命令和验收回执；所有必需实现、测试、打包和远端核对完成前，长期目标保持进行中。
