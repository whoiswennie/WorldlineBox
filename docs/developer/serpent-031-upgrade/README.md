## 工作方式

1. 固定上游提交并生成逐路径清单。
2. 快捷键、侧栏、传输/磁盘、安装/跨平台分别对照；共享的大入口文件按区块合并。
3. 先做相关单元/Worker 检查，再运行隔离真实应用；通过后验证 BAT 和打包版。
4. 将已证实的结论、限制和证据记录到本目录。完成状态以当前源码与实际结果为准。

运行日志和图片/安装包等大体积证据保存在本机 `artifacts/serpent-031-*`、`.tools/test-output/` 和 `out/`，不随源码提交。
