## 前一轮现场与原因（21:58 前）

用户使用 Clash Verge 系统代理 `127.0.0.1:7897`，安装 `DSH 0.2.1-rc.2` 时长期停在 20%。只读检查该次安装的 npm 日志，发现相同 `zod-4.4.3.tgz` 出现约 150 次请求，部分归档请求超过 5 分钟。原实现为每次安装创建并删除 npm 缓存，无法在版本或重试间复用；所有依赖解析、传输和本地安装共用同一个阶段，速度没有空闲采样。

系统代理并非完全未生效。真实 Electron 隔离安装解析到 `http://127.0.0.1:7897`；真实固定 Node/npm 的本地 HTTPS CONNECT 测试也证明子进程经过所选代理。原安装环境删除了 `npm_config_*`，但 npm 仍可读取 HTTPS_PROXY；这次将明确的 npm 代理参数也补齐，并清除旧的大小写代理及 NO_PROXY 配置。

同机同一时段下载相同的 759,588 字节 zod 包，官方源经代理耗时 19.47 秒、官方直连 7.83 秒、npmmirror 经代理 3.98 秒。它们是当时线路表现，不能承诺任意时间都保持该带宽。自动择优始终保留用户选择的代理，按官方依赖锁的完整性摘要校验归档。

## 实现

- 固定官方版本、官方入口包 SRI；先解析锁，再按平台和归档去重，以 8 路并发预取，最后执行 npm ci 和生命周期脚本。
- 在应用的 `npm-cache/_cacache` 复用经过 SRI 校验的内容，配置与临时用户目录仍隔离；不接触用户全局 npm 缓存、账号或真实 DSH 存档。
- 官方注册表下默认比较官方和 npmmirror 的相同归档，失败回退；可选择只用所填注册表，自定义注册表保持原线路。
- 普通、独占的临时安装目录经所有权、符号链接和硬链接检查后，直接移动到待封存目录。链接或 Windows 移动占用时才回退到 16 路有界复制，仍检查目标不存在、限制路径并执行逐文件 SHA-256 封存。
- 在异步保存进度前就监听子进程退出，修复缓存辅助进程退出过快导致永久等待的竞态；重放累计字节，避免丢失过早报告。
- 界面按解析、按包计数的下载、本地安装、封存与兼容性检查展示；无总量时显示活动进度，空闲速度归零。
