# 会面字幕、口型与皮肤强度修复

会面开启自动朗读时，从新回复的第一个生成帧起由语音字幕管理展示；生成中和合成等待阶段只显示状态，文字随真实媒体时钟出现一次。连接前的历史回复直接可读；关闭朗读时已经显示的生成内容不会在重新开启后被清空重播。中断会同时释放当前、排队及尚未完成的旧回复，旧生成结束后不再补播。只有新回复或用户主动重试才重新进入播放队列。

当前回应按字素安全的短页展示，优先在自然语句边界换页，保持约两至三行。播放时跟随实际文字进度换页，结束后停留末页。手动向前翻页会暂停自动跟随，提供“跟随语音”恢复入口。“查看完整回复”打开原聊天记录并定位原消息，保留完整 Markdown 和附件，不创建或复制消息。

口型直接使用真实音频能量，中性情绪不再把最大张口限制为约 18%。播放暂停、静音和结束时回到闭口；不会为了放大效果而在无音频或只监听麦克风时虚构说话动作。本机真实晓伊 MP3 与 Live2D 验证的张口范围约为 0 至 0.976，结束后接近 0。

外观中的皮肤卡片下新增明显的不透明度滑块。内置皮肤独立保存强度，默认 40%；个人图片保留原有显式选择。只改变背景画面的强度，文字、按钮和前景控件不会整体变淡。

语音识别 ONNX、内嵌向量 GGUF、Live2D MOC3 与贴图纳入 Git LFS；词表、模型 JSON、授权、声音和测试用中文样本保留在普通 Git。新环境执行 `git lfs pull` 后可还原运行资源。`resources/speech-models/tokens.txt` 与 Live2D 运行资源禁止自动换行符转换，避免破坏校验及模型文件。

验证覆盖：语音展示归属、开关与中断、字素分页、手动浏览和恢复跟随、真实音频暂停与口型、真实 Electron 生成至播放全过程、长回复及历史定位、默认皮肤强度和持久化。验收使用隔离资料目录、受控本地消息和留存音频，不发起付费模型调用。
