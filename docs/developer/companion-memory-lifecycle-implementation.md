## 新增的文件权威要求（2026-10-26）

用户明确要求所有伙伴资料、记忆、知识、提示词归入资产管理器中对应伙伴目录；软件编辑必须真实修改文件。内置伙伴模板保持不可变，仅首次初始化使用。

正在落实的标准：

- `<伙伴目录>/profile.md` 保存名称、简介、完整人格及非密钥的外观/联系偏好；软件保存采用实际文件内容哈希 CAS，外部编辑在下一次上下文读取生效。
- `<伙伴目录>/提示词/manifest.json` 明确登记共同模块和各类用途模块；普通回复、记忆编码、反思、整合、联想、学习、社交、世界行动、AIMemo、标签及原生时间线提示均由目录文件提供。首次复制的原版模板保留完整字节，后续不从内置模板悄悄修复文件。
- `<伙伴目录>/日记|资料|自我认识|世界经历|时间线` 的正文由真实文件读取，SQLite 保留权限、不可变修订和事务凭证，原生索引属于派生视图。外部尚未登记的编辑、删除或不安全路径立即停止引用，经过授权核验后再登记新正文。
- `<伙伴目录>/.认知索引/` 保存该伙伴的热图、冷知识、候选包、管理索引和视图缓存；公共编码器模型可以共享，伙伴认知资料不能借用另一伙伴目录。
- `<伙伴目录>/形象/` 保存该伙伴运行时实际读取的头像/设定图。初始化后文件缺失时明确不可用，不反复从内置图片恢复。
- 固定合法任务可以继续使用可追溯的旧正文；文件外部改动和来源撤销仍有精确验证。模型权限、来源 ACL、工具合同和输出结构由宿主核验，编辑提示词文件不能扩大执行权限。

这些新要求已通过主进程、实际文件和UI验收；旧认知目录的物理清理仍受上述工具拒绝限制，不能假定旧文件已经不存在。

## 当前实际触发与目录标准

| 环节 | 生产触发 | 防止反复运行的边界 |
| --- | --- | --- |
| 原始经历入账 | 正式发送、完成的行动和经授权的实际阅读进入来源及投递日志 | 草稿、失败发送、虚构材料不能成为新的现实来源 |
| 日记编码 | 连续交流静默60秒；累计12条正式来源或首条等待5分钟则处理稳定前缀；明确更正等重要事件可提前 | 模型可返回空；来源覆盖、操作幂等、同事件append/correct及精确已读版本 |
| 深度维护 | 每伙伴独立的有效来源欠账；3个新片段、重要冲突或最旧欠账满24小时可获准入 | 普通成功决策间隔6小时，defer也结算；失败单独退避；纯标签或同源改写不产生新欠账 |
| 反思和整合 | 维护会话中reflection、real分别提交 | 后阶段失败不重付已完成阶段；没有新认识或可整合输入则不产出 |
| 梦境或清醒联想 | 合格会话持久抽签一次，初值0.6；清醒时表述为演练 | 成功后8小时冷却，叙述最多3次尝试；不影响必要整理；不开机不伪造离线梦 |
| 回忆和时间线 | 合法作用域实时文件快照进入原版VCP；固定候选后锁外聚焦 | 普通新增/注释不打断合法旧任务；遗忘/权限撤回和外部文件变更有独立核验 |

这些数字是当前默认准入参数，不代表完成期限，也不表示每条输入都值得保存。模型行为来自伙伴文件，宿主继续强制来源权限、输出结构、资源准入与事务规则。

内置角色资料和提示词是不可变的初始化模板。软件中的“编辑伙伴”和“提示词文件”编辑当前伙伴的副本，不能修改仓库或ASAR中的模板。各项职能（包含学习、社交及独立聚焦指导）的具体行为均在首次初始化时写入用途文件；实际提供方请求按当前manifest组装，不将代码默认行为再次叠加到文件内容上。

当前可读正文从伙伴文件读取；SQLite保存归属、权限、事务、不可变历史修订、租约及初始化凭证，不作为文件缺失时的正文或设定回退。来源撤销的文件投递可在伙伴休眠或资料损坏时继续。持久初始化凭证位于宿主账本，整个伙伴目录意外丢失后也不能以初始模板静默重建。形象另有每伙伴、每角色的耐久初始化凭证，删除整个形象目录也不会自动从内置图片补回；软件中的明确重新选择或恢复操作才可重新写入。明确重置只清除该伙伴的凭证。

派生`.认知索引`、宿主sidecar与UUID发布临时文件保存在对应伙伴目录，但不进入资产正文索引或触发反复扫描。profile、提示词、日记、资料和原始来源仍作为真实资产同步；这项规则只作用于当前资产库的固定伙伴根目录。
