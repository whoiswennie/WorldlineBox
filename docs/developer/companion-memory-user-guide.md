# 伙伴记忆系统运行指南

伙伴的记忆围绕真实经历逐步形成：先保留来源，再决定值得怎样记，随后持续整理，并在需要时回忆。
每位伙伴有自己的资料、记忆、提示词、维护节律和权限；计算资源由宿主统一分配。
本文说明当前实现，依据生产代码提交 `75d6fbf5e89810a878af8bcfea384f71c451871c`。详细设计见[架构方案](companion-memory-lifecycle-architecture.md)，调研对照见[VCP调研](companion-memory-upstream-research-2026-10-26.md)，实际通过项、失败和规模及两小时结果见[实施台账](companion-memory-lifecycle-implementation.md)。
本次已交付范围与未完成项汇总见[交付报告](companion-memory-lifecycle-delivery.md)。

## 从一条消息到一篇日记

1. **正式接收。** 正式发送的消息、真实任务结果和授权阅读先进入来源记录，不等待日记模型或向量索引。
2. **组成事件片段。** 同一来源域内的连续交流先合批，保留来源、作者、时间和未处理范围。
3. **判断是否值得记录。** 编码时同时查看相关旧记忆及同源已存内容，决定不写、新建、补充或纠正。
4. **提交正文。** 有效内容通过来源、证据、权限、禁记和版本检查后，登记到统一记忆账本并发布伙伴正文文件。
5. **收录检索。** 后台把已提交内容交给 VCP 建立向量与检索资产，成功确认后才算完成收录。

因此，“消息已接收”“日记已写入”“已能通过向量检索找到”是三个不同状态。
尚未收录不等于原始消息丢失；可以回查合法来源，但不能保证每条原文都会自动注入每次回复。
没有持久价值时允许不新增日记；“处理完成但没有新笔记”是正常结果。

## 默认什么时候开始整理

新初始化伙伴默认使用“均衡型”。以下是准入条件，不是固定完成时间。

| 环节 | 均衡型默认值 | 实际含义 |
| --- | --- | --- |
| 普通对话编码 | 静默 60 秒 | 连续交流先聚合，暂时停下来后再处理 |
| 持续交流批次 | 12 条正式来源 | 到达批量边界后处理稳定前缀，后续内容留在尾段 |
| 最长等待 | 首条未处理来源等待 5 分钟 | 即使一直交流，也能分段推进 |
| 深维护事件门槛 | 3 个有效新事件片段 | 分成三篇笔记不等于发生三件新事 |
| 深维护决策间隔 | 通常至少 6 小时 | 成功的“没有新认识”也会结算，避免反复付费判断 |
| 最旧维护欠账 | 24 小时 | 已有欠账足够久后可获得受控后台服务资格 |
| 梦或清醒联想 | 合格会话抽签概率 0.6 | 不表示每个会话一定产生梦 |
| 梦成功后的冷却 | 8 小时 | 不反复讲同一组素材 |
| 梦叙述尝试 | 最多 3 次 | 失败不会回滚已成功的必要整理 |

宿主能核实的首次身份、明确纠正、约定和实际结果等可以提前进入处理。
这不是“出现某个关键词就必写”；自然语言理解仍由模型参与，不能保证任意说法都得到完全相同的判断。
主动记忆工具已经完整记录的来源，会与后台捕获核对覆盖，避免再付一次相同提取。
只记录了一部分事实时，不能把整条消息标成“全部记住”；同源遗漏仍允许补入。

## 每位伙伴可以有不同的节律

当前伙伴目录中的 `记忆策略.json` 决定该伙伴的实际参数，软件策略编辑会修改这份文件。
预设用于首次初始化或用户明确选择；运行时读取的是伙伴副本，不是每轮套回内置默认。
目前策略可以通过软件中的JSON文件编辑器调整；实际生效的是capture、deep、dream各数值，仅修改mode名称不会自动重置其他参数。

| 初始模式 | 静默 / 最长等待 / 批量 | 深维护间隔 / 最旧欠账 / 新事件 | 梦概率 / 冷却 / 尝试 |
| --- | --- | --- | --- |
| 安静型 | 120 秒 / 10 分钟 / 12 条 | 12 小时 / 48 小时 / 5 个 | 0.3 / 16 小时 / 2 次 |
| 均衡型 | 60 秒 / 5 分钟 / 12 条 | 6 小时 / 24 小时 / 3 个 | 0.6 / 8 小时 / 3 次 |
| 学习型 | 30 秒 / 3 分钟 / 8 条 | 3 小时 / 12 小时 / 2 个 | 0.6 / 8 小时 / 3 次 |

参数必须符合宿主范围限制；提示词或自由文字不能关闭证据核验、扩大资料授权或绕过预算。
新领取的工作读取当前策略；已经开始的维护会话固定自己的策略回执，避免处理中途改变规则。
策略文件缺失或损坏时暂停该伙伴的相应维护，保留来源与队列，不偷偷补默认或丢掉欠账。

## 日记、反思、整合和梦分别在做什么

**日记**记录真实发生或真实读到的内容，保留人物归属、数量、否定、更正、条件及未完成事项。
同一件事有新阶段时可以延续旧篇，也可以形成有关联的新记录；最终如何表达仍由模型选择。
证据引文存在，并不自动证明笔记已经完整表达全部事实。

**整合**处理真实重复、补充或同事件进展；新摘要尚未完成收录与校验前，不先撤掉原文。
不同事件、不同来源域或需要独立验证的方法，不应该为了“更整齐”被强行合成一篇。
**反思**尝试从经历中形成有条件的新认识；只是换种说法、改标签或跨了一天，不应制造新经历欠账。
同一来源谱系和问题没有新证据时，不会因为轮询或重启就无限再反思一次。

**梦与联想**使用合法素材进行明确标注的虚构组合，睡眠时可称梦，清醒时是联想演练。
它们不证明相关事情真实发生，也不能把自己的叙述再次当成新的现实证据。
梦失败时，已经完成的反思和真实整理仍保留；重试只继续尚未完成的阶段。

## 梦后核查与方法成长

梦可以留下待核查的问题和假设，这些问题与真实经历分开保存。
已有自主学习授权时，后续学习可以参考这些问题选材；不会自动扩大授权或替换用户的明确目标。
实际读取的文件会留下阅读凭证，再据此记录“读到了”或“未读到”相应内容。
当前原句核查只证明材料中是否出现那句话；出现不等于假设成立，没出现也不等于假设为假。

记下一个做法，最初只是**未验证的方法候选**。
只有真实任务明确读过该方法，并有符合客观交付条件的实际产物回执，宿主才增加实践验证。
失败保留为反例；方法正文改动需要重新验证，实践来源撤回也会使对应验证失效。
一次执行器退出码为 0、自称成功，或者模型自测答对，都不能单独证明已经掌握方法。
这里的自我学习是有来源的记忆、方法与策略改进，不是在本地自动训练模型权重。

## 授权资料怎样进入知识与记忆

伙伴只能读取已授权资产库和目录中的资料；不会因为“想学习”就扫描其他目录。
阅读、理解、认可、自测和实际成功使用是不同阶段，记录不能把它们混为一谈。
资料作者的观点、第三方主张、游戏剧情和待验证假设应保留性质，不能直接当作现实事实。
自己的提示词、记忆历史、来源副本和索引目录不会因为全库学习授权而反复学回自己。

资料被移出授权目录、修订、删除或撤销授权后，原阅读凭证、派生记忆与冷知识入口会一起重核。
暂时连接不上资产库时停止使用无法核验的资料，但不凭一次临时错误永久删除合法知识。
文件恢复或重新授权后，需要新的实际读取；不会把已撤权的旧凭证直接复活。

## 为什么任务没结束，后台也能整理

任务使用自己开始时实际读到的正文、来源和文件凭证，后台维护可以同时生成后续版本。
普通新增、标签调整或合法后台整理，不要求当前任务反复重做整套回忆。
新任务可以读取更新后的记忆；旧任务能否继续，取决于它固定的历史仍是否合法、可核验。

明确遗忘、来源撤回、停止要求和授权失效是硬边界，任务快照不能绕过。
外部尚未登记的文件编辑、删除或不安全路径也会阻止继续引用未核验正文。
模型调用和后台工作由共享资源调度，每伙伴分别保留队列与欠账；前台忙碌不等于维护永久停摆。
资源不足时可以等待，而不是靠取消所有后台工作或截掉原任务要求来“提速”。

## 伙伴怎样回忆，找不到时意味着什么

普通回复可以先用 VCP 准备相关候选，再聚焦成当前话题的上下文。
准备完成的候选和任务上下文可以复用；普通工具续接不必每轮重新跑完整被动回忆。
需要完整回顾、阶段或关键条件缺失时，伙伴可以自主调用记忆搜索和读取，继续查原记录与来源。
语义结果是有限的排序候选，不代表已经查遍全库；第一次没返回不等于从未发生。
已有标签或日期线索时，空查询也可按这些条件分页浏览日记目录；一页结束不代表之前所有页都读过。
模型并非每次都会正确补查，所以复杂回顾仍应保留“不确定”和缺失部分，避免把未召回说成不存在。
尚待索引的新版本不会被旧索引冒充为完整结果；初次普通来信可以明确携带回忆等待状态继续处理当前输入。

## 文件在哪里，哪些可以改

以下路径均相对于资产管理器中**此伙伴自己的目录**，不是安装目录或另一伙伴的目录。

| 文件或目录 | 用途与编辑边界 |
| --- | --- |
| `profile.md` | 名称、简介、人格等角色资料；软件“编辑伙伴”保存这份副本 |
| `提示词/manifest.json` | 指定共同模块及各用途需要读取哪些文件 |
| `提示词/共同.md`、`对话.md` | 共同行为和交流指导；实际以 manifest 登记为准 |
| `提示词/记忆编码.md`、`真实反思.md`、`记忆整合.md` | 记录与维护偏好；可能还包含初始化的职能用途文件 |
| `提示词/梦境与联想.md`、`资料学习.md` | 联想与学习行为；不能替代权限或真实凭证 |
| `提示词/记忆聚焦指导.md`及原生模板 | 当前话题聚焦、标签与时间线的用途提示，按 manifest 读取 |
| `记忆策略.json` | 该伙伴的实际合批与深维护参数 |
| `日记/`、`资料/`、`自我认识/`、`世界经历/`、`时间线/` | 可读正文及导航；软件修改会写真实文件，外部编辑在核验后登记 |
| `记忆历史/` | 不可变旧正文及依赖凭证；用于合法历史任务，不作为普通新资料重学 |
| `来源/` | 可回查的只读原始材料副本；编辑它不能伪造用户发言或阅读授权 |
| `形象/` | 运行时读取的头像与设定图副本 |
| `.认知索引/` | 此伙伴的派生检索图、冷知识与缓存；不当作学习正文 |

内置模板只负责首次复制；UI 改的是当前伙伴文件，不能修改仓库或 ASAR 内模板。
已有文件不会被新版本默认提示词覆盖；作者化的 manifest 也不会被偷偷追加默认行为。
初始化之后缺文件会明确报不可用，不反复从模板恢复；不要把删除目录当作安全的记忆重置方法。
文件是模型读取正文的权威，但 SQLite 仍保存事务、权限、发布暂存和不可变副本；这不表示物理上只有一份字节。

## 怎样理解等待、预算和遗忘

“待整理”表示来源已保留；“待收录”表示正文已提交，但检索尚未确认；“已处理”不保证一定新增了日记。
本地预算、模型未配置、文件准备或资源容量不足时，作业会明确延期，不把轮询当成八次真实模型失败。
已经成功保存的推理阶段可在输入仍合法时复用；来源、角色文件或目标改变后，旧结果可能需要重新核验或重算。
共享 `模型资源预算.json` 通过软件保存后可唤醒本地延期；实际发送前仍会重读预算，日统计按 UTC 口径。
共享预算位于资产库的`.worldlinebox/companions/模型资源预算.json`，属于宿主运行配置；伙伴正文和人格仍在各自目录。
已发送后的网络错误、提供方拒绝或结果未知，与尚未发送的本地等待不同；请求预留也不是远端实际账单。
缺失/损坏的正文、提示词、策略或预算文件应先修复；系统不会用 SQL 或 builtin 偷补模型正文。
想撤回知识时使用明确遗忘或撤销授权；来源选择只撤相应证据，整条遗忘会撤销该笔记所有历史。
遗忘和权限收回即使在任务运行或伙伴停用时也必须生效，后台旧结果不能把它恢复回来。

## 时间和目前的真实边界

虚拟世界跟随现实时间，但关闭软件期间没有本地思考或模型执行，不会补造“昨晚做过的梦”。
下次启动恢复的是实际未结队列，白天短时开机也能逐步维护，不要求电脑通宵等到夜间。
代码机制、合成模型夹具、真实提供方内容质量、真实编码器和长期稳定性是不同验证层次，不能互相替代。
当前仍存在首次被动召回漏片段、模型未主动补查或概括遗漏的真实局限；成功小样本不代表“完美真人记忆”。
万条批量首次建库未在既定阶段时限内完成，十万级完整规模未通过既定磁盘门；没有万条热查询延迟结论。
完整两小时持续运行测试按用户要求取消，未启动，不能宣称该项通过。
旧认知导出的物理删除曾被执行工具自动审批拒绝，不能宣称旧磁盘文件已清空；新系统不会靠迁移旧导出来恢复记忆。
