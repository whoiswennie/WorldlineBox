# 两套动态背景

当前只接入用户指定的 `whale-fantasy`（鲸鱼娘 · 未至之境）与
`shuimo-danqing`（鲸鱼娘 · 水墨丹青）。参考仓库克隆到
`C:\Users\hp\Desktop\project\new\test`，没有运行或引入它的插件。

应用设置 → 外观中选择对应主题。两套都保留独立的亮暗配色；深色模式接近原皮肤，
浅色模式使用 WorldlineBox 适配的浅色控件和阅读遮罩。选择主题不改变用户的亮暗模式。
背景视频原文件不转码、不重定时。个人背景图片优先；移除个人图片后恢复主题视频。
背景不透明度默认 70%，设置中的滑块即时调整并保存；只调背景层，不改变文字和按钮的不透明度。

`AnimatedBackground` 是可复用组件，接受 `src`、`poster`、`playing`、`active`、`fit`。
`ThemeBackground` 由应用根节点统一持有，放在 `.application-root` 内、`ApplicationShell`
和各模块的 React `Activity` 边界之外。启动器、资产页与以后添加的模块共享同一层背景，
切换模块不会重新挂载视频、重设来源或清零播放进度。模块中不要各自创建背景组件。
个人壁纸也由这一层统一绘制，应用栏与模块表面透出同一张图，而非分别铺图。
可复用组件的 `active` 只用于独立预览等局部场景，应用全局背景始终保持 active。

- 静音、循环、行内播放，等比铺满或拉伸；没有视频播放工具栏。
- 设置中可以关闭动画，以视频抽帧封面代替；只保存布尔开关，不将视频塞进 localStorage。
- 窗口隐藏、最小化或失焦时暂停（使用现有原生聚焦桥）；系统要求减少动态效果时不加载视频，显示封面。
- 解码错误显示封面；移除组件时停止播放、清除来源并释放媒体资源。
- 应用根层只播放一份视频。主题选择器和设置预览使用静态封面。
- 背景层不接收指针事件；标题、侧栏与启动器卡片保留轻量的主题色底以保证可读性。
- 上游 DSH 选择器没有迁入；保留 WorldlineBox 的布局、协议和主题设置。

来源、校验和及上游说明见 `assets/backgrounds/sources.json` 与同目录 `attribution/`。
素材声明独立于主项目 MIT 许可证；原声明如实保留。

`tests/unit/animated-background.test.tsx` 检查模块切换后的节点、来源和播放位置保持。
桌面验证 `tests/e2e/animated-background.test.ts` 从默认启动器打开设置，检查两套媒体实际
解码、跨模块同一视频且不重新加载、失焦暂停、动画开关、透明度与个人图片的全局显示。
