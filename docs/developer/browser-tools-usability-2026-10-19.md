# 浏览器与全局工具易用性修复

本次沿用 WorldlineBox 的模块、资料和独立产品版本，增量修改浏览器侧栏、下载记录、划词助手与全局工具快捷键设置。

## 行为与界面

- 下载记录支持单条移除、批量选择移除和清理已结束记录。搜索、状态筛选和分页保留；文件不会随记录删除，进行中、暂停及仍有 DownloadItem 的下载受到后端保护。清理后新下载及重启后的记录仍正常保存。
- “更多操作”改为分组图标行，固定、静音会反映实际状态，缩放支持递增、递减与重置。按用户要求移除重复的全局网络设置入口，统一使用左侧栏。顺带修复附件下载结束后地址栏误留下载链接，以及 Electron 首次查找参数取反导致页面查找无结果的问题。
- 划词助手使用约 420×520 DIP 的无边框小窗口，靠近鼠标并限制在工作区，可调整大小；默认不置顶，只有用户主动固定时才保持在前。原文默认单行引用条，可展开编辑，问答可连续追问、取消、复制和清空；关闭即结束临时会话，不写入聊天历史。输入区自动增高并限制最大高度，移除原生文本框拖拽角。消息移除重复的可视角色标题，复制按钮不再占整行；自动滚动只改变对话区的 scrollTop，不滚动外层，避免原文卡片压住首条消息。
- Windows 全局划词通过 UI Automation 读取前台控件及其所属文字容器的选中范围，支持有界祖先查找与短暂重试。没有全文读取兜底，不自动模拟复制、不自动读写剪贴板；拒绝密码框，无选区或不支持的控件提供手动输入/显式粘贴。Linux/macOS 保留手动输入与显式粘贴，未宣称实现原生取词。
- 全局工具快捷键改为按键胶囊与真实按键录入，松键完成、Esc 取消，支持单项清除/重置、重复及系统保留组合提示，显式保存后生效。录入期间只暂停本项目的工具快捷键，离焦、关闭、重载、渲染器崩溃或销毁时恢复。跨组件卸载/重挂载使用同 API 共用队列，防止旧页面的迟到清理打断新页面录入。

原生外部取词验收窗口是测试结束自动关闭的独立 WPF 样本，不属于产品界面；产品面板由实际应用渲染器绘制。
