# 伙伴世界动作素材

实现所有者：`src/shared/companion-world-art.ts`、`src/shared/companion-world-art-data.json`、`scripts/companion-world-art.mjs` 与 `public/companion-world/characters/`。

## 文件与替换

每个角色的每组动作只有一张独立图片，稳定路径为 `companion-world/characters/{avatar}/actions/{action}.webp`。一张图只含同一角色同一动作的三个前向帧。禁止先生成多组动作共用的大图再切成假独立文件；禁止给别的动作复制或倒序播放一个文件来冒充新制作的动作。帧索引仅用于播放当前文件。

图片为三列一行，运行规格 1152×384，每帧 384×384，真实透明通道。原图可以更高分辨率；整体等比规范化与透明通道保留属于导入步骤，不能借导入拼出没有绘制过的姿态。单个动作可以直接替换图片并同步该动作的尺寸、SHA-256、边界、接触点与制作来源，不必重新发布包含全部动作的 atlas。

角色包括大肥鱼、小肥鱼、黑白幻及现有联系人角色。小肥鱼独立制作，保留其蓝色长发、黑色连裤袜、服装与鲸鳍耳，不能直接借用姐姐的白袜鲸尾皮肤。自定义联系人没有匹配的角色动作时显示其实际头像标识；不能把另一位伙伴的身体假装成已为它完成的美术。

## 制作和审查

用户授权参考的废弃项目已具有单动作三帧、固定斜侧视角、透明通道和姿态接触点规范。本次从中选择可用图组，以稳定名称导入；旧项目的候选目录和版本选择不进入运行时逻辑。新增与修正使用内置 `image_gen`，每张独立调用，完整提示词保存在对应动作的 `source.prompt`；复用图保留原角色、动作及源图摘要。

通用生成规范：

```text
制作该角色的一组独立三帧动作图。参考只确定身份、服装、比例和画风。
单张图中仅一个角色、一个动作、三个连续时刻，单行三个等大的方格。
固定三分之四斜侧视角，面朝画面左侧；各帧画布与身体比例固定。
全身、头发、尾巴及动作所需随身物件完全留在各自方格内。
每格保留透明边距，不跨帧、不裁掉轮廓。真实alpha透明背景。
不画场景、地板、投影、椅子或床；这些由三维场景负责。
不画文字、帧号、格线、水印或其他动作。明确写出该动作三个有序阶段。
```

动作语义、身份、服装、手势和坐/躺姿态要亲自查看。检查三帧非空、透明背景、轮廓不越界、接触点与物件相符；失败图重新制作，不通过放宽校验掩盖。QA 联系图只是审查用的缩略汇总，不作为运行素材，也不是生成后切分不同动作的来源。

## 比例和接触

持续站姿按整组固定的地面 origin 对齐，角色的 idle 比例是公共基准。新增站姿表情图可声明经审查的整组 `defaultOrigin` 与 `neutralHeightPixels` 来消除生成画布边距的差异；不能逐帧按最低像素缩放。行走、跑步、坐姿和躺姿继续使用角色基准，避免把弯腰、腾空或躺卧错误拉高。跑步腾空帧允许脚离地，不能把脚尖每帧强压到地面。坐姿以人工复核的 seat/pelvis 对齐实际椅面；躺卧以 bed/back 对齐床面。动作切换不改变身体尺寸，也不能把头发最低点当脚底。

画面中左右镜像只适配实际方向；依据权威 facing 在当前相机中的投影决定。转动镜头不能使人物倒着走。坐下、站起、躺下和醒来的顺序由各自独立图组给出，不镜像或倒放另一动作代替。

宿主决定动作开始、过渡完成和家具占用；渲染器根据同一开始时刻与时长播放三个帧。精力恢复与真正的睡眠窗口从过渡完成后开始，不能先播放站姿却已按睡眠恢复。当前动作缺失时必须显示缺图状态，不能用 idle 假装已画出睡眠或工作。

## 资源与验证

按可见角色当前动作加载图片，不预加载全部角色的全部动作。场景退出释放纹理、材质和几何；动作帧共用原图，通过单角色 UV 更新，不能让一个角色的帧改变另一个角色。动漫平滑线条采用线性过滤；像素尺寸、DPR 与透明轮廓一并进行实机检查。

运行素材检查：

```powershell
node scripts/companion-world-art.mjs verify
```

新制作或替换图组可以用 `node scripts/companion-world-art.mjs register <actions.json>` 导入。JSON 为动作数组，每项含 `avatar`、`action`、原图 `input`、完整 `prompt`，可选 `durationMs`、`playback`，坐/躺姿另需逐帧 `postures` 和人工复核的 `contacts`。整批通过三帧比例、透明边缘、独立来源、时序和接触点校验后才替换生产文件与清单。`inspect` 可检查尚在制作中的完整性，正式验收用 `verify`，缺动作会失败。

检查摘要包含角色数、独立图片数、实际帧数、总字节数与透明通道结果。尺寸和散列通过只是技术条件；最终仍需在床、餐桌、电脑与街区实际播放时查看姿态、比例和表情。

本次交付为 15 位内置角色各 31 个独立文件：站立、走路、跑步、转身、跟随、阅读、站立阅读、坐下、坐着、起身、躺下、睡眠、醒来、休息、交流、工作、用餐、思考、疲倦、开心、烦恼、拿取，以及站/坐姿的打字与电话、惊讶、难过、生气、锻炼和烹饪。共 465 张 WebP、1395 帧、45,832,900 字节。348 张来自已审查的旧项目，117 张独立新制作或修正；黑白幻的坐姿阅读已替换为实际持书翻页。完整制作来源和生成提示词随生产清单保存，不依赖本机临时图片目录才能运行。
