# 0.1.0 首版验证记录

验证日期：2026-10-12。环境：Windows x64、Node.js 24.15.0、Electron 43.1.0。

## 已完成

- 中英文 README 与产品简报已按角色、世界、资产和执行生态的中枢定位重写。当前实现与未来计划分别说明。
- 项目、协议、环境变量、插件清单、脚本扩展名、数据及缓存路径、数据库目录、安装器和文档采用 WorldlineBox 名称。
- 上游 MIT 的原始版权通知保留在 LICENSE；该处原项目名称属于版权归属，不是运行时命名。
- 图标使用维护者提供的 PNG / ICO，并更新应用、Dock、浏览器扩展和 README Logo。
- Windows 环境准备及开发启动已实际执行。开发 profile 使用项目内 `.tools/dev-user-data`。
- 资源中的 ufbx 导出符号和诊断路径已更新；真实二进制 FBX 解析通过。
- Windows 媒体工具的编译诊断路径在非执行数据区内更新，保持 PE 布局及执行指令不变；清单、归属记录及 SHA-256 校验通过。
- Windows 应用打包与包完整性校验通过。安装包使用独立产品标识、维护者署名和仓库内的中文翻译文件。

## 检查结果

| 检查 | 结果 |
| --- | --- |
| TypeScript 主应用与浏览器扩展 | 通过 |
| ESLint | 0 错误、7 条现有 React Hook 警告 |
| 核心检查：协议、MCP、更新源、媒体诊断改名、数据库恢复、迁移校验和数据库服务 | 101 项通过、1 项跳过；单 Worker 复跑退出正常 |
| 全量单元 / Worker 测试 | 712 个测试文件；5,554 项通过、31 项失败、31 项跳过 |
| 打包应用的真实 Worker 导入 | 通过：启动、创建资源库、导入文件、验证渲染器隔离 |
| 打包应用的 FTS5 搜索与筛选 | 通过：实际导入资产后检索与过滤 |

全量套件并非全绿。失败包括 Windows 符号链接权限、部分文件操作/取消行为，以及已有的格式分组、AI 同步、元数据与媒体相关断言。未将全部失败归因为操作系统，也未把未核实的失败标记为已解决。

对改名前的原始项目副本抽查了 `desktop-ingestion`、`format-filter-presets`、`import-planning` 和 `sync-metadata` 四个测试文件：原版同样出现 6 项失败、72 项通过、1 项跳过。其中包括符号链接权限和文档格式分组断言。这说明至少这些失败不是品牌修改引入；其余失败仍需后续逐项处理。

一次并行核心测试在全部断言通过后出现 Windows 原生句柄收尾错误；单 Worker 复跑正常，打包应用的两项 UI 验证也正常退出。此记录不等于对所有并发关闭情形的完整验证。

角色脑、世界状态、DSH 多版本、整合包与游戏运行器适配尚未实现，本次没有将这些未来能力标记为已测试。
