## 配置文件

应用用户目录保持 `%APPDATA%\WorldlineBox`（Windows）。`ai-profiles.json` 保存连接元数据和启用状态，`ai-profile-keys/<id>.bin` 保存各配置的 safeStorage 加密密钥，`ai-analysis-settings.json` 保存分析偏好。`ai-profile-migration.json` 记录迁移完成，`ai-profile-transaction.json` 只用于未完成事务恢复。

旧 `ai-config.json` / `ai-key.enc` 在迁移及核验成功后清理；失败时保留旧来源。资源库数据库升级沿用已有迁移及备份机制。

## 验证

实际检查和边界见 [验收记录](acceptance.md)。本次验证使用临时资源库和独立用户目录，不使用用户的真实模型密钥或资源库。性能检查以索引查询计划、目录扫描次数及行为回归为依据，不将其描述为未经实测的速度倍数。
