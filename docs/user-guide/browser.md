# 内置浏览器与全局网络

应用栏的「浏览器」提供独立的 Chromium 网页环境，默认主页和新标签为纯空白页。收藏快捷栏预置哔哩哔哩、Pixiv、GitHub、Bing 搜索，点击后才加载网站。首次打开浏览器才创建网页进程；切到启动器或伙伴后，已有页面保留，不会重新进入主页。

## 标签、收藏和记录

- 地址栏支持网址和搜索，可在设置中选择 Bing、百度或 DuckDuckGo。
- 支持前进、后退、刷新、停止、主页、多标签、恢复已关闭标签、固定、静音、缩放和页内查找。网页弹出的 HTTP/HTTPS 页面会打开到新标签；链接、网页脚本和表单打开的新页面保留原登录会话、来源关系及提交内容，后台打开的标签不会抢走当前页面。
- 地址栏下方的收藏快捷栏可以直接访问网站；星标打开管理侧栏，按名称、域名搜索或按文件夹筛选，点击添加或编辑时才展开表单。预置收藏可以自由修改、移除，重启不会重新添加已移除的项目。
- 历史记录支持搜索，每页 50 条，显示匹配总数与页码。下载记录每页 20 条，可搜索文件名、网址、错误或状态，也可按状态筛选；显示实际字节进度，支持暂停、继续、取消、重试、打开和查看文件位置。清理记录后页码自动调整，不会停在空白尾页。
- 默认恢复上次的标签、导航历史、收藏、缩放和静音设置。Cookie、LocalStorage 等站点数据存入专属持久分区，不随页面切换清空。网站主动使登录过期时仍需重新登录。
- 视频可以使用网页自身的全屏按钮；Esc 退出网页全屏，F11 切换窗口全屏。

常用快捷键：Ctrl+L 地址栏，Ctrl+T 新标签，Ctrl+W 关闭标签，Ctrl+Shift+T 恢复标签，Ctrl+Tab 切换标签，Ctrl+F 查找，Ctrl+R 刷新，Ctrl+加/减/0 缩放，Alt+左/右 前进后退。

下载默认保存到系统「下载」目录下的 `WorldlineBox` 文件夹，同名文件自动编号，不覆盖已有文件。可在浏览器设置勾选每次询问保存位置。网页是否提供可下载的内容取决于网站；此功能不绕过站点的付费、DRM 或下载限制。

## 保存到资产库

内置浏览器已经自带网页图片、视频采集，无需安装浏览器扩展。先在「资产管理」打开资源库，再点击浏览器地址栏的「保存到资产库」打开采集侧栏。

1. 选择「目标资源库」和默认保存位置。可保存到根目录、普通文件夹或可用的链接文件夹；不可用的链接目录不能选择。文件夹按树状层级展示，也可搜索完整路径或选择「最近使用」。
2. 在网页图片或视频上右键，选择「保存到 WorldlineBox」，再从原生菜单选择根目录或目标文件夹。右键菜单与拖拽菜单可为本次保存选择其他文件夹。
3. 拖拽图片或视频会展开树状保存菜单。顶部显示最近目录；悬停右侧 `›` 进入子目录，左侧 `‹` 返回，在目标目录上松开保存。在菜单外松开或按 `Esc` 取消。
4. 本地图片使用侧栏的「采集本地图片」，在系统选图窗口中选择文件，保存到当前默认位置。此操作不要求网页访问本地文件，也不会把本地绝对路径交给网站。

「保存选项」包含四个会记住的开关，默认全部开启：显示系统通知、保存后聚焦 WorldlineBox、保存后在资产管理中定位、拖拽时显示文件夹保存菜单。开启资产定位后，保存完成会切换到对应资源库并选中资产；原浏览器标签与页面保留。也可随时点击「打开资产管理」。

「最近采集」显示保存结果、下载字节进度与具体错误；仍在保存的任务可以取消。导入执行与本地导入相同的内容查重。没有打开可写资源库时，先打开资源库再采集。

网页采集在 HTTP/HTTPS 页面启用。新建空白页、内嵌空白文档或浏览器错误页不会启动采集；若保存期间页面已经关闭或跳转，按提示在页面加载完成后重新操作。本地图片继续使用系统选图入口。

采集使用内置浏览器当前会话的 Cookie 与页面 Referer 请求 HTTP/HTTPS 图片、视频，登录状态与访问权限仍由网站决定。单个远程媒体上限为 **500 MiB**，本地图片上限为 **32 MiB**。不支持 `blob:` / `data:` 地址、HLS/DASH 等分段播放流、MSE 或 DRM 媒体；视频需提供可直接下载的媒体 URL。当前提供逐项右键、拖拽和本地选图，没有网页扫描、批量采集或扩展弹出窗口。

外部 Chrome/Edge 等浏览器仍需单独安装扩展，见[浏览器扩展](browser-extension.md)。

## Cookie 与缓存清理

浏览器设置提供当前缓存大小和「所有网站 / 当前网站」范围，分别选择网页缓存、Cookie 与站点数据、浏览历史、下载记录。默认只勾选缓存，保留登录数据。清理下载记录保留文件和正在下载的记录；勾选 Cookie 和站点数据可能退出登录。

浏览器与 DSH 工作台使用不同的持久分区，清理浏览器不会清除 DSH 账户、伙伴记录或资产库。摄像头、麦克风、位置等敏感权限由站点逐项申请，可选择是否记住。

## 哪些网络配置正在生效

从最左侧主侧边栏选择「全局网络」，也可从浏览器的「更多操作 / 设置 → 全局网络设置」进入。该页面独立于启动器。顶部「当前生效」始终展示已应用配置；修改表单但未保存时显示草稿提示。

常用代理与来源方案可以新增、编辑、移除。点击「添加并启用」或「保存并启用」会立即保存本页并更新实际网络。保存多个代理不代表同时使用多个代理；每类来源也只有一个当前配置。移除收藏方案不会擅自切换正在使用的地址。

「当前生效」中的代理开关可以立即关闭代理并改为直连，再次开启会恢复原来的系统或自定义代理配置。常用本机端口提供 `7897`、`7890`、`7896`、`7898`、`10809`、`8080`，选择后立即启用；请使用代理软件实际监听的 HTTP/混合端口。端口选择不会替你启动代理软件，其他未保存的编辑仍保留为草稿。

代理统一用于内置浏览器、伙伴与模型、资产 AI 与语义服务、同步、插件、音乐、更新、安装下载和应用托管的执行命令，不改操作系统代理。系统模式由系统规则决定实际路线；自定义全局代理使用不含账户密码的 HTTP/HTTPS 地址，例如 Clash 的 HTTP 或混合端口。修改后新请求使用新配置，运行中的托管命令也会更新代理线路；原有连接会断开，失败的请求需要重试。本机服务仍通过回环地址直连。独立从系统终端启动的导出 CLI 在下次执行时读取保存的配置。

npm、Python 和 GitHub 镜像各有用途，不会把普通网页改写成镜像地址。npm 自动择优会显示本次实际选中的注册表；GitHub 显示官方与回退线路。「测试连接」分别列出三类来源的真实地址、代理、HTTP 状态、耗时和失败原因。可连接不等于任意时刻都有固定下载带宽。

npm 提供官方、npmmirror 和华为云预设；Python 提供官方、TUNA、USTC、阿里云和华为云预设，也可保存自定义来源。选择预设会立即应用该类来源；明确选择 npm 源时会使用所选注册表，其余草稿不会一并保存。

镜像切换用于后续下载及新启动的命令；要让已经开始的安装使用另一个来源，请取消后重试。

「最近的网络失败」按站点、错误码与资源类型聚合同一类失败，最多保留本次运行的 40 类记录，每页 10 条，支持搜索和清空。记录只保存站点来源，不保存 URL 路径、查询参数或账户信息。主页面与子资源分别标记。`net_error -100` 表示连接关闭；若同时出现 TLS 握手失败，可检查代理端口和规则后重试。低层预连接或 WebRTC 日志未必对应这里的 HTTP 请求。

网页打不开时，错误页会区分域名解析、断网、超时、安全连接或代理问题，提供「重新加载」和「全局网络设置」，技术详情可展开查看。先检查网络或当前代理，再重试；更改设置不会忽略网站证书错误。网站播放器自己的提示与部分子资源连接日志仍取决于站点及当前网络。

为控制资源使用，最多保留 50 个标签，最多 8 个活跃网页；较久未使用且没有播放声音的页面会休眠，再选择时恢复。重启时只加载当前标签，其余按需恢复。当前支持的保留上限为 1000 项收藏、2000 条历史和 200 条下载记录。此版本不包含 Chrome 扩展商店、密码管理和跨设备账户同步。
