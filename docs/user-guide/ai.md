# 全局模型与 AI 分析

WorldlineBox 的 AI 分析使用已配置的全局 AI 服务。文本资产可用纯文字模型；图片、视频画面、3D 视图及文档首页需要支持图像输入的模型。请准备对应服务的 API Key，并确认其费用。

## 配置

从最左侧应用栏底部的 `设置 → 全局模型` 打开，Windows 与 macOS 使用相同入口。连接配置由应用全局保存，不依赖当前资源库；资产分析选项单独折叠在下方。

首次使用预设为 DeepSeek 官方 `OpenAI Chat Completions`、`https://api.deepseek.com`、`deepseek-flash`。内置模型候选无需密钥即可选择；真正调用仍需要自己的 API Key。已经保存的其他服务商和自定义模型不会被预设覆盖。接口和模型名称参考 [DeepSeek 官方 API 文档](https://api-docs.deepseek.com/zh-cn/)。

Windows 开发版和安装版均使用 `%APPDATA%\WorldlineBox\ai-config.json`，密钥单独保存到 `ai-key.enc` 并通过 Electron safeStorage 加密。文件不在资源库或源码目录。DSH 原生账号与模型配置由启动器共享存档管理，这份应用模型配置不会自动覆盖它们。

### 连接服务

- `API 格式` 选择服务商的接口类型，可选 `DashScope Multimodal (native)`、`OpenAI Chat Completions`、`OpenAI Responses`、`Anthropic Messages`、`Gemini Native`。使用中转站时按中转站的接口说明选择。
- `请求地址` 通常可以留空；使用中转站或自建网关时，填写服务商提供的地址。DashScope 原生接口使用 `/api/v1`。
- `API Key` 粘贴服务商生成的密钥。眼睛图标可以暂时查看；保存后不会显示完整密钥，需要更换时重新输入。
- `模型` 填写服务商提供的模型名称；需要分析图片时选择支持视觉的模型。输入有效密钥后可以读取模型列表，读取失败时直接手动填写。
- `语言` 是单选项，可选中文、English、日本語或 한국어；描述和标签会使用所选语言。
- 点击 `测试连接`，成功后点击 `保存配置`。

不要把 API Key 写入脚本、插件、截图、问题反馈或 MCP 配置。

### AI 写入开关

- `描述`：概括实际文本内容，或说明画面内容、风格和氛围。
- `标签`：生成类型、主题、用途或视觉特点关键词。
- `AI 评分`：按照评分标准生成 1–5 分的参考评分。
- `强制使用已有标签`：只从当前已有标签中选择，不新增标签。

AI 内容与人工内容分开保存，人工描述、标签和评分不会被覆盖。

### 高级设置

- `并发分析上限`：默认 16，范围 1–32；遇到服务商限流时调低。
- `分析图像最大边长`：默认 2048 px，范围 512–4096；只会缩小，不会放大。
- `最大标签数`：默认 8，范围 1–32。
- `中文描述上限`：默认 100 字，范围 20–500。
- `英文描述上限`：默认 60 词，范围 10–200。
- `输出风格`：`正常`、`精简`、`严谨`。
- `评分标准`：说明 1–5 分分别代表什么。
- `自定义描述提示词`：补充描述重点，例如“重点说明构图和光线”。
- `自定义标签提示词`：约束标签分类。不要在提示词中写密钥或其他秘密。

### 自动分析

接受免责声明并打开 `新增资产自动进行 AI 分析` 后，新导入的可分析资产会进入后台队列；该开关默认关闭，关闭它不会删除已有 AI 内容。

## 支持的资产

- 图像和 RAW：发送缩放后的图像。
- 视频：发送带时间标记的联系表，不上传原始视频。
- 3D 模型：发送四视图图像。
- 可读文本：TXT、Markdown、JSON、CSV、常见代码及配置格式，复用文本预览的编码识别与二进制校验。最多发送开头 **64 KiB UTF-8**；超出时明确标注为截断片段，不会执行代码。纯文字模型即可分析。
- PDF / Illustrator AI：复用已有的**首页图像预览**，需要视觉模型；只分析可见首页，当前不提取全文或读取其他页面。
- 音频、Office 文档、HTML 和其他暂无内容提取器的格式：当前不能分析，不会只凭文件名生成结果。音频预览、Office 文件导入不等于具备转写或全文理解能力。

## 手动分析和结果

在资产右键菜单选择 `AI 分析`，也可以对多选资产使用批量操作。`AI 分析未分析项` 会跳过已有结果；需要重新分析时使用普通的 `AI 分析`。

![从资产右键菜单启动 AI 分析](../assets/ui/AI-analyze-menu.png)

结果显示在资产 Inspector 的 AI 区域。重新分析成功后会替换当前 AI 结果，不保留旧版本；清除 AI 内容不会删除人工内容或标签实体。

## 任务和失败处理

从 `窗口 → 后台任务` 查看排队、运行、暂停、失败和已完成的 AI 任务，可暂停、继续、取消和重试失败项。网络、限流和超时通常可以直接重试；配置、权限、额度或文件格式问题需要先修正。

视频联系表或缩略图未就绪时，先在后台任务中重试媒体生成，再重试 AI。失败提示会显示简短原因。

文本为空、包含二进制或无法读取时会提示检查文件；模型不支持图像时会提示改用视觉模型，文本仍可使用原模型。鉴权、权限、额度、限流、网络、超时和无效输出分别显示原因。临时失败沿用设置中的有界队列重试，不会无休止地调用服务，也不会偷偷换模型或把图片降级成无图分析。

## 隐私和费用

WorldlineBox 不上传整个资源库，也不提供 AI 搜索。只有明确提交的可分析资产才会发送给所选服务商；启用前请确认服务商的隐私条款和费用。
