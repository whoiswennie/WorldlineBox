# 设置中的网易云音乐播放器

打开左下角「设置 → 音乐」。默认歌单 ID 为 `18322613388`，与 worldline-harness 的播放器一致；首次打开不播放。播放器的音频保留在应用层，关闭设置、切换启动器和资产管理页不会停止或重建音频。

可以播放、暂停、切换歌曲、快进或快退十秒、拖动进度、调整音量，以及选择列表循环、单曲循环和随机播放。搜索框筛选当前歌单；「词」显示同步歌词，点击歌词行会跳转到对应时间。

展开「网易云音乐歌单」可以保存并命名多个公开歌单、切换或删除自定义歌单、恢复默认歌单。默认歌单保留；每个歌单分别记住上次选中的歌曲和进度。

设置保存在当前用户数据目录的 `music-player.json`，Windows 正常开发版和安装版均为 `%APPDATA%\WorldlineBox\music-player.json`。保存歌曲、进度、音量、播放模式和歌单列表。重启恢复进度，默认仍暂停；只有主动勾选「启动时自动播放」才会自动播放。歌词和歌单通过官方公开接口读取，歌单元数据可在离线时使用缓存，不保存网易云登录信息。

播放地址使用网易云公开链接。付费、版权或地区限制导致不可用的歌曲会跳过；未开始播放时跳过也不会擅自开始播放。持续无法访问时，可以刷新或切换歌单。
