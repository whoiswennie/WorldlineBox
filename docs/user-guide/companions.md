# 伙伴与消息

在应用侧边栏的「启动器」与「资产管理」之间打开「伙伴」。二级导航提供「消息」「联系人」「记忆」「生活」「世界」和「社交」。首次进入会自动弹出「创建伙伴资产库」，名称默认是「伙伴资产库」；点击「选择位置并创建」，选好保存位置后即可直接进入伙伴页面，无需先去资产管理创建。也可以在弹窗中点击「使用已有资产库」，选择已经打开的库，或打开其他已有的 WorldlineBox 资产库。全部伙伴的日记、聊天与世界存档统一放在所选库中，各自的记忆存放在各自的子目录。以后可通过页面顶部「更换资产库」重新选择。聊天以长期联系人和群聊为单位，无需为每个话题新建会话。

可阅读的正文位于资产库的 `伙伴记忆/<伙伴 ID>/`；聊天、世界状态与记忆来源账本位于 `.worldlinebox/companions/messages.sqlite`，VCP 数据库、向量、标签关系及上下文缓存也位于 `.worldlinebox/companions/` 中。资产语义搜索的索引位于同一资产库的 `.worldlinebox/semantic/index.sqlite`。这些随使用增长的数据跟随你选择的保存位置；用户数据目录只为伙伴库保留 `companion-library.json` 位置记录。应用的通用设置、日志和浏览器缓存仍按应用原有方式保存，内置向量模型在应用安装目录中共用一份。备份时请复制整个资产库，包括隐藏的 `.worldlinebox` 文件夹。

## 用户信息与公开形象

「设置」第一项「用户信息」可以填写姓名、公开自述，上传头像与一张包含正面、侧面、背面的正交三视图。保存后，聊天中的姓名和头像立即更新；玩家身份始终是同一个 `user`，改名不会创建新玩家或把你变成另一位伙伴。用户资料默认公开给与你交互的伙伴，请在这里填写希望她们知道的信息。

在「联系人 → 编辑资料」也可以为每位伙伴设置公开三视图；联系人资料里可预览整张设定板。三视图是标准对外形象，头像是聊天头像，二者分开保留。清除姐妹的自定义三视图会恢复她的内置设定板；更换聊天头像不会改变她的默认三视图。上传时会保存应用管理的图片副本，移动原文件不会使设定失效。

用户与伙伴上传头像都会先打开圆形校准编辑器：拖动图片选择位置，滚轮或滑块缩放，也可旋转、重置，并同时查看大小头像预览。确认裁剪后返回资料页，再保存资料即正式应用；取消不会改变原来的头像。保存的是实际裁剪的 512 像素图片，聊天显示与伙伴可读取的头像文件保持一致，原始图片不被修改。

编辑器适配明暗主题，分别预览资料页、聊天与联系人中的头像效果。辅助网格可开关，方向键微调，按住 Shift 可快速移动；窄窗口也保留预览，底部确认按钮始终可用。

每次聊天都提供双方最新的公开介绍、头像与三视图的真实文件绝对路径，包括伙伴自己的头像。支持视觉的模型还会收到实际图片像素，优先提供当前双方的三视图；群聊其他成员保留公开资料与可读取路径。伙伴之间的私聊不会混入玩家资料。资料图片只说明公开设定，不证明现实身份或私人关系。

模型不支持视觉或服务明确拒绝图片时，同一模型继续使用文字资料和路径，并明确没有看过图像；不会把知道路径说成已经看到内容，也不会偷偷更换所选模型。

## 添加与管理联系人

内置联系人包含大肥鱼姐姐、小肥鱼妹妹、白幻、黑幻、Gemini、GPT、Grok、Kimi、MiniMax、Qwen、咕咕嘎嘎、咕嘎、Doro、菲比啾比和弗糯糯，共 15 位。升级时会补入缺少的新伙伴并恢复内置联系人入口，已有资料保留。新用户的消息列表为空，内置联系人不会自动创建聊天或发送预设欢迎消息。

本次开发已按要求直接清空本机旧群聊、私聊、消息、记忆及关联任务记录，保留联系人资料和模型配置。代码只维护当前数据结构。此后新产生的正式记录正常持久保存，重启会继续未完成的记忆整理。

在「联系人 → 添加联系人」中，可以选择内置角色，也可以填写名字、个性签名、人设与形象创建自定义角色。打开联系人资料可以编辑设定、配置模型连接、开启或关闭主动联系。内置伙伴提供完整重置，自定义联系人可以移除，移除保留已有聊天历史。两种操作都会先停止这位伙伴的回复、后台整理、日程和所属 DSH 任务进程树；无法确认停止时会提示错误，保留记录供重试。

内置角色库支持搜索名字、性格和兴趣，以及「AI 拟人」「原创角色」「社区伙伴」分类。新增角色使用保留旧项目身份特征的新绘头像；在编辑资料中可以选择任一内置头像或上传自己的图片。群聊创建时自行勾选成员。

## 激活与休眠

默认只有小肥鱼激活，其他内置伙伴与新建联系人均休眠。在联系人资料的「伙伴生活」中手动激活或休眠。休眠会停止回复、后台认知、日程与工作，释放虚拟世界人物和三维资源；存档与聊天保留。打开聊天、查看小屋或收到来信不会自动激活。激活与「允许她主动联系我」是两个独立设置。

联系人与聊天标题用紧凑的彩色圆点和文字标记就绪、处理与休眠状态。手动休眠与生活中的睡觉是不同状态：已经激活的伙伴即使正在工作、学习、用餐或睡觉，也可独立回应玩家与其他已激活伙伴的消息。不同消息保留各自的回复、过程与回忆依据；真实移动、面对面交流和电脑资源仍受实际位置与容量限制。

聊天标题栏显示虚拟世界的实际日期、时间和天气，按照世界设置的流速走时；空间充足时也显示室外温度。它与世界窗口使用同一份模拟环境。伙伴只能依据自己的当前观察描述天气，不会把旧天气或室内温度当作当前室外情况。右上角的交流入口在有交互时显示对象和简短状态，悬停可查看等待原因，点击可打开对应伙伴的交流记录；空闲时只保留图标。

## 设备能力检测

在「设置 → 全局模型」或「语义搜索」的「设备能力」中，可以分别检测内置多模态向量模型和 3D 世界。打开设置只读取设备信息和已有结果；点击向量检测会短暂运行 3 个固定中英文短文本和一张小图，结束或取消后释放临时模型进程。首次实际请求向量能力时，尚未检测的设备也会先执行同一检查。CPU 或 GPU 都可以通过，不以显卡品牌作为条件。

向量检测前需要至少 3 GiB 当前可用内存，这是本软件给模型及运行缓冲保留的安全预算。检测同时检查向量格式、模型完整性和短输入耗时。内存不足、速度超过预算或检测失败时，依赖向量的记忆索引、召回与资产语义搜索不能启动模型；普通资产管理、全文搜索、聊天和已有记忆文档查阅仍可使用。恢复资源或修复问题后可以重新检测。通过结果按设备、模型与检测版本保存，最长复用 7 天；大型图片、音视频与大量文档仍需按需排队，短测通过不代表所有输入都能实时完成。

3D 检测仅创建并立即释放一个很小的 WebGL 2 上下文；已知总内存小于 4 GiB 时会按本软件的安全预算暂停 3D 画面，内存信息未知时不会假定为不足。基础检查不保证大型场景的帧率。3D 不可用或运行中图形上下文中断时，会显示原因与重新检测入口，世界生活数据及聊天继续保留。

## LLM 连接

所有角色默认完整继承「设置 → 全局模型」中的 API 格式、地址、密钥和模型。角色名称与实际服务无关；大肥鱼、小肥鱼以及叫 GPT 的角色都可以使用同一个模型。

也可以在角色编辑中选择「为此伙伴单独配置」，设置连接方式、API URL、API Key 和模型。支持 OpenAI Chat Completions、OpenAI Responses、Anthropic Messages、Gemini 原生 API 与 DashScope 原生 API。角色专属连接不会修改全局设置或其他角色；切回全局后跟随当前全局配置。已有专属密钥不回显，编辑时留空保留。

伙伴专属密钥由 Electron safeStorage 加密后保存在所选资产库的隐藏运行目录中，不进入消息 SQLite 数据库或聊天事件。没有可用连接时仍能保存用户消息，服务错误会明确显示，可以配置后重试。

## 持续聊天与群聊

- 消息页右上角「＋」打开「发起聊天」，选择一位已有联系人开始私聊，勾选多位伙伴可以创建群聊。联系人页的「＋」打开「添加联系人」。也可以在联系人资料点击「发消息」。再次选择同一人会进入原来的私聊。Enter 发送，Shift+Enter 换行，中文输入法选词不会误发送。
- 可以选择表情、发送文件和图片、引用消息、搜索聊天记录以及加载更早的记录。单个附件上限 20 MB，每次最多 10 个。
- 在联系人页创建群聊并选择成员。默认按成员显示，例如「我、大肥鱼和小肥鱼的群聊」；群资料可改名，名称留空恢复自动命名。成员名字变化时自动群名随之更新，自定义群名保留。相同成员只对应一个群，已有重复群的消息与任务会合并保留。使用 `@名字` 优先邀请对应伙伴回复。
- 群成员各自运行回复循环，按全局与角色并发上限调度，每位参与者对同一条用户消息使用一个持续更新的气泡。
- 消息列表保留未读、置顶与静音状态。切换到其他模块不会停止正在生成的回复。
- 输入框采用居中的浮动圆角设计，随内容增高。支持 Markdown 标题、引用、GFM 表格、任务列表、删除线、脚注、数学公式、语法高亮与可复制代码，以及 Mermaid 流程图、时序图等图表；原始 HTML 不执行，外部链接只在点击后打开。

## 历史浏览与查找

打开聊天只读取最新 50 条消息。向上滚动到顶部时自动读取更早的记录，也可以点击「查看更早的消息」。聊天页保留不超过 200 条消息，并限制正文缓存大小；继续向前翻会回收另一端的旧页面，滚动阅读位置保持衔接。历史模式可向下读取后续记录。离开底部后可以点击浮动的「回到最新消息」，直接读取最新一页，不逐页重放中间记录。

双方消息采用随内容收缩的圆角气泡，长正文限制阅读宽度；搜索定位仅强调气泡边缘。浏览历史时新消息不会强行把页面拖到底部，回到底部后才清除对应未读提示。

聊天右上角的搜索按钮查找当前聊天，消息列表「最近联系」旁的搜索按钮查找全部聊天。支持关键词和附件文件名、发送者、开始与结束日期、图片、文件和链接筛选；多个关键词用空格分隔，按同时包含这些关键词查找。搜索结果每页 30 条，最新在前，显示毫秒精度的本地时间，悬停可查看时区。点击结果定位到原消息并显示前后文；点击「刷新」回到最新搜索结果。

未完成的消息索引在后台按批次建立，搜索窗口会显示索引状态并自动补全结果。关闭后继续上次索引进度，不重复处理已完成的批次。

## 删除聊天与解散群聊

聊天右上角的垃圾桶按钮「删除聊天」从消息列表移除该聊天，保留消息、附件引用与任务记录；重新发起私聊或同成员群聊可以找回。隐藏后收到新消息也会再次显示。

在「管理群聊」点击「解散群聊」，确认后停止该群正在运行和排队的回复及能力任务。重启后不会继续该群；原记录保存在本地数据库中，不进入普通聊天列表与搜索。原联系人与共同记忆保留，相同成员可以建立一个新群。删除或解散不会删除用户电脑上的原文件。

## 共同记忆与主动联系

正常聊天时，伙伴会从已发送的消息中形成有来源的自然文本日记、偏好、经历与约定，回复前由 VCP 的标签图、向量和检索模块寻找相关记忆。资产搜索、伙伴记忆和知识资料共用内置的 EmbeddingGemma 2 多模态向量模型，无需安装模型或填写向量接口。聊天理解、自动标签和反思仍使用已配置的聊天模型。

点击二级导航「记忆」，或从手帐「共同记忆」进入「伙伴记忆库」。它是伙伴模块内的一个子页，消息、联系人、世界与社交导航始终保留；切换后返回会保留选中文档和编辑草稿，隐藏时暂停页面刷新。每位伙伴有自己的日记本目录；左侧选择伙伴与目录，中间分页查看文件，右侧阅读 Markdown 正文，也可以编辑、改名、移动、调整标签、查看真实来源及当前修订号。支持关键词全文搜索、多个标签同时筛选，以及原版 VCP 语义搜索。列表默认按最近修改排序，也可以选择最近或最早创建；高级筛选可按创建或修改日期缩小范围。语义搜索保持相关性排序，结果数不会冒充全部文档数。

列表每页最多64篇，目录树按可见区域绘制，打开一篇才读取其正文；长正文每次渲染最多16,384字符，使用「上一段／下一段」阅读，不会把整篇长时间线一次铺进界面。单篇读取上限仍为200万字符；首次批量导入时显示后台目录索引状态，结果完整后才开启翻页。目录索引和 VCP 向量收录分别推进，首次处理大量资料需要时间。

正文上方分别显示创建、修改与可追溯的经历时间。日记创建时间来自原始记忆账本，普通外部文件使用文件系统记录并注明「文件创建」，缺少创建信息时显示未记录。时间线保留来源经历的日期，可能是虚拟世界日期；它与现实文件写入时间不同。月度整理和日记作者绑定真实伙伴身份，改名或升级前的旧身份投影会撤回并重新整理，原始日记保留。

实际文件位于所选库的「伙伴记忆/<伙伴ID>/」；每位伙伴含日记、资料、自我认识、世界经历和时间线，也可以创建子目录。可以使用普通文本编辑器新增或修改 Markdown、TXT 文件。后台会分批核对文件、记录来源并更新 VCP；检测到并发修改时保留正文并报告冲突。稳定人格与自动时间线只供查阅；人格在伙伴资料中修改，需要内化的时间线内容可另存为资料。普通改名和移动保留身份、来源与版本，不制造新的生活经历。

聊天生成日记时会同时产生标签。手工新建或导入的资料没有标签时，后台使用全局聊天模型和 VCP 原版 TagMaster 提示词补充标签，用户填写的标签及明确的正文 Tag 行优先保留；可以查看状态、重试或取消自动标签。没有可用聊天模型时正文仍保存，标签任务显示等待配置，不会凭关键词凑出标签。标签会同步到原版 VCP 的索引和标签图。

在记忆库左下角或当前伙伴手帐中点击「记忆整理」，进入记忆子页的「记忆处理进度」。左侧按状态筛选，中间显示该伙伴的来源整理、向量索引、自动标签和时间线整理任务，选中后在详情中查看当前阶段、真实处理时间、尝试次数、失败原因与任务凭证，并可重试失败处理。窄窗口中列表与详情分别显示，详情提供返回入口；处理规则收在工具栏的信息按钮中，按需展开。伙伴导航始终可用。历史任务没有记录的时间会明确标为未知；时间线运行阶段的历史只覆盖本次应用运行，不补造重启前记录。每次展示有界的最近任务，可按待处理、失败或已处理筛选。

每篇正文还会独立显示保存、标签和向量索引状态。「正文已保存」不等于已经进入召回；「已处理」也不等于学会了一项能力。来源整理可能判断无需写日记，标签与向量索引可以独立推进，索引就绪后才有资格参与相关话题的回忆。这里的学习是有来源的记忆整理、检索与反思，不是重新训练聊天模型，也不会自动覆盖稳定人格。模型故障保留待处理队列；原版 VCP 检索失败时会明确提示，不切换到旧无向量记忆方案。

待处理任务会显示后续执行安排：已登记后台检查时显示「下次检查」，冷却中显示「最早可重试」，其他情况说明需要等待的模型、资料规则、伙伴启用状态或同一范围的前序任务。选中任务可以查看触发规则；检查和重试资格均不承诺具体开始或完成时间。达到自动尝试上限的任务需要手动重试，正在运行且租约有效的任务不会被重试按钮重新启动。应用关闭期间不处理队列，重新打开后继续检查。

当前伙伴的手帐还提供「记忆与学习」：分别列出授权资料学习、日记与记忆整理、睡眠整合和概率梦境。现实时间的检查或重试资格，与世界时间的作息窗口分别标注；行程窗口表示有机会满足条件，不表示一定执行。未授权学习会显示未安排来源，已授权但未开启自主学习时仍需手动开始。日记根据真实来源事件检查，不是每天固定写一篇。睡眠整合要等实际入睡、有待整合的已收录记忆且没有工作占用；梦境还需通过该睡眠阶段的概率与冷却条件。

日记不是逐句聊天备份。新的具体约定、偏好变化、实际结果、可追溯的学习或有背景的新认识，才会经过选择性整理；普通寒暄、附和和重复确认可以不记。用户与伙伴、伙伴之间的正式私聊或群聊，以及实际发生的世界事件，都可以成为来源。计划不会被写成已完成，小说、玩笑和梦境不会被写成现实事实。

在记忆库打开「学习与成长」，用自然语言写下长期学习目标，可以选择本地文本文件、明确的公开网页或已授权的资产库资料，也可以单独允许伙伴为该目标探索公开网页。每个目标都有现实时间的间隔、星期与时段；进入候选时间后仍需激活与作息条件满足，页面会显示等待原因。无材料且未允许网页探索时等待补充材料，不调用模型假装学习。工作、聊天与学习可以独立推进，开始新阶段遇到睡眠或用餐时顺延。目标不会因运行两轮或自评分数较高自动结束，可随时暂停、恢复、调整或结束。

每轮记录实际计划、读过的原文与版本、逐字依据、记忆的新建/复用/修订、自测答案、依据与下一轮改进。先完成同一套本地模型与 VCP 向量收录，再从真实回忆回答自测；回答步骤不会拿到刚读过的整份教材。自测属于模型自评，不能当作客观考试正确率或已经掌握。没有回答的问题不会算作答对。目标列表与轮次按页读取，原文按需展开；结束学习会保留记录，撤回或遗忘的来源不会继续通过旧轮次正文送入模型。

「学习与成长 → 材料授权」管理当前伙伴对资产库或指定目录的读取范围。一个伙伴可以有多个来源，多位伙伴也可以共享同一份资料。仍可手动「读一轮」或开启原有的周期资料核对。当前本地阅读支持纯文本、Markdown 与文本代码文件，编码为 UTF-8 或带 BOM 的 UTF-16，单文件不超过 2 MiB；公开网页读取有大小和超时限制，其他格式或读取失败不会被伪称已经学习。

「最近阅读」显示实际读过的原文片段及出处，读过不等于已经学会。后台继续按内容价值整理到资料、日记或自我认识，后续回忆仍核对来源。相同文件版本和片段不会重复采集。伙伴的私有记忆目录与应用运行文件不作为资料来源；移除来源会停止读取并撤回由其形成的记忆，不删除资产文件。资产库语义搜索开关独立控制资产搜索，默认关闭；关闭它不影响伙伴记忆或已经授权的资料学习。

编辑保存会校验文件及宿主修订号，遇到并发变化需重新读取。来源面板显示真实引用和当前版本；当前不提供旧版全文回滚。点击遗忘并确认后，日记及其历史来源不再参与回忆和再次采集，聊天原文保留。如果希望今后也不记录某类信息，可以在聊天中明确说明或在规则中管理持续限制。仅遗忘旧事不会自动禁止用户以后提供的新信息。

每位伙伴拥有跨私聊、群聊、伙伴通信和虚拟世界连续的个人记忆。消息按入口保存并保留发言者、时间和来源；值得保留的内容经筛选形成日记，完成向量索引后由同一套 VCP 被动召回和主动回忆工具检索。不会把所有会话历史一次性塞入模型上下文，也不会把另一位伙伴的私人记忆直接共享过来。只有本人实际见过并仍获权的来源可参与召回，明确的保密、遗忘与重置要求继续生效。人类管理员可查阅该伙伴的完整文本空间。实际散步完成、到访和真实阅读学习会依据凭证形成经历；看书动作、计划或权限提示本身不算已经读懂的知识。睡眠反思保留来源与主观性质，不直接覆盖稳定人格。完整消息仍在所选库的 SQLite 中分页保存，不会因为累计长度自动重置会话。自动形成的记忆可能遗漏或误解，可通过来源核查。

在记忆库点击「回忆」，输入问题后选择主动查找或随话题想起，使用与伙伴相同的 VCP 检索入口。页面展示实际处理环节、命中标签、候选顺位和已提供的原生分数；点击「回忆内容」阅读工具实际取回的片段，可从可信的来源链接打开对应文档。候选排序与最终返回内容分别核验，分数不是事实正确率；原版没有提供的过程细节会明确说明。翻日记和文档全文检索仍在原记忆库中保留。

每条回复中展开回忆详情，可查看当轮真正保存的上下文与候选来源，查看不会重新调用模型。来源被撤回、记忆被修改或无法继续核验时，旧正文会隐藏并提示；没有保存凭证的历史回复不会补造回忆内容。联系人和聊天列表使用带文字的颜色状态区分就绪、处理中、等待、休眠及离线。伙伴之间自动联系要求参与者都已激活，生成途中休眠也会停止后续送达。

实际睡眠且已有可用的来源日记时，后台可以整理已读记忆。每个连续睡眠阶段只做一次持久入梦抽签，默认机会为 60%，两次尝试至少间隔八个世界小时；重启或多次检查不会重新抽签。未入梦仍可反思。梦境明确放在「梦境」日记本，虚构画面与有证据的认识分开，醒来会中止未完成的睡眠作业。是否产出梦和新认识还取决于实际资料与模型输出，不承诺每次睡眠都有新内容。

在记忆库点击「成长足迹」，可以查阅这位伙伴的资料阅读、日记与认识、睡眠整理和梦境。选择一条经历后，按阅读凭证、来源整理、相关记忆、索引投递、自动标签、睡眠回顾与梦境查看实际记录；已有凭证才会出现关联。资料阅读保留资产版本、片段位置和内容校验值；记忆关联保留修订号，睡眠回顾区分参与整合的版本与实际完成回顾的版本。来源被移除、修订失效或记忆已遗忘时，重新核验后隐藏其旧内容。

足迹支持类型、日期和标题／资料名／记录编号检索，每页20条；单个环节每页10条凭证，翻页替换旧内容。它检索的是有界摘要元数据，正文全文检索仍在记忆库中。旧存档首次建立足迹索引时显示进度状态，后台按小批补齐。点击「查看这篇记忆」按真实记忆编号定位文档，改名或移动后仍定位到当前文件；已失效时会明确提示。可以从对应页面编辑、遗忘记忆或管理学习来源，原始处理凭证不能被当作可编辑日记改写。新整理批次保留实际保存／确认的记忆版本，也会明确记录零产出；去重复用不称为新创作。历史共同来源关联会明确标示，不把旧记录缺少的产出关系、模型原话或梦境原因补造出来；索引投递完成也不等于已经理解或保证当前检索健康。

主动联系默认关闭。开启后，仅在应用运行时检查：当地时间 09:00–22:00，每位伙伴每天最多两次主动消息，至少间隔四小时；关系还不熟悉时更克制，疲劳或不适合交流时会保持安静。未回应一次主动消息后停止继续追问，直到用户再次联系。没有值得说的话可以保持沉默。空回复和失败尝试也有三十分钟冷却，重启后保留限流状态。

## 伙伴手帐、状态与日程

二级导航「生活」打开伙伴生活总览。顶部是统一世界时钟与天气，下方选择已激活的伙伴，按「此刻与接下来」「正在进行」「接下来」「需关注」「最近发生」查阅这位伙伴的信息流。每条安排标注现实时间或世界时间，展示真实状态和触发条件；定时检查、最早可尝试时间、作息窗口分别标明，不把它们当作保证开始或完成的时间。右侧概览该伙伴的记忆处理、授权学习与睡眠整合安排。可直接打开对应工作、日程或日常事件调整设置，也可进入这位伙伴的记忆处理和成长足迹。信息流每页最多20条，翻页替换旧列表；切换伙伴不会混入其他伙伴的私有记录。只读页面不会推动世界、触发行动或重新抽取梦境。

「我们之间」侧栏显示当前伙伴的心情、表达倾向、精力、好感和相处阶段，下方是周历与便签待办。群聊可以切换查看参与伙伴。心情与精力会随真实交流、共同任务和时间更新；点击状态可查看原因、交流与共同经历次数，以及愉悦、活跃、自主和好感、信任、尊重的细项。分数描述虚拟角色的当前状态，不测量现实人的感情，也不会替代完整角色设定；完整人设仍在联系人资料。

可以直接说「明天九点提醒我」「每周五帮我整理……」，伙伴会在实际保存成功后确认；也可以点击手帐的「＋」打开大日程窗口，添加提醒或执行任务，设置一次、每天、每周、每月或按分钟间隔重复。用原文完整写下任务目标和限制，时间按日程时区执行。窗口支持修改、暂停和恢复、立即执行、取消及查看结果。暂停只停止后续安排；取消停止后续安排及该日程正在进行的任务，已产生的结果保留。

「时间可调整」只在你开启后允许伙伴根据精力和作息调整任务时间；延期原因与预计时间会显示在便签和日程中。固定安排仍按约定处理。应用关闭期间不会启动电脑任务；再次打开后按已保存的安排恢复调度。

在伙伴私聊中，日程窗口的「作息与习惯」可以调整睡眠、醒来、用餐与每周的小习惯；群聊只查看允许公开的当前状态。侧栏会显示当前虚拟作息与今天的小节奏；习惯详情显示养成程度、完成次数和连续性，由伙伴实际到达并参与活动的时间积累。走路、等待电脑和处理任务不会算作睡眠或练习。普通聊天使用独立处理通道，不必等整段休息结束；明确的紧急打扰仍可调整实际行动的优先级。

「日常事件」可以给每位伙伴设置自己的时间窗口、动作、交流对象与机会。在同一时段内会持续评估，不会因为一次没有发言就整段时间不再行动；可分别调整评估间隔、行动后休息、沉默后再考虑、失败后再考虑，单位为世界分钟。默认分别为 15、90、20、30 分钟。机会还会受实际作息、心情、精力和关系影响，伙伴可以选择安静。默认事件只自然联系伙伴；主动找你需要单独设置，拜访仍需许可，离线期间不会补发一堆消息。

内置伙伴拥有作者编写的初始生活计划，例如安静听歌、看海、探索新点子或轻运动；自定义伙伴从通用午休开始。这些是起始安排，完成次数从零积累，不会凭空成为已经发生的共同经历。也可以在私聊中明确说出希望调整的作息或习惯，由伙伴实际修改后确认。虚拟练习会影响活动偏好，不能据此声称电脑上的工作已经做完，或已经读过现实资料。

手帐的「手头的事」汇总进行中、等待中和待确认的数量，最多预览两条工作；点击「查看全部」打开工作台，查看同一伙伴并行处理的所有任务。工作台可切换「当前工作」与「全部记录」，每件事保留自己的进度、结果和停止入口，不会因为新任务到来而自动切走正在阅读的任务。日历便签保留给日程和提醒。

## 消息、循环与能力

每条用户消息都是独立的 Agent loop。每位参与的伙伴只产生一个回复气泡，气泡按步骤持续更新正文与能力调用。一次只调用能力、没有正文时也保留轻量入口；并行能力放在同一段，点击各自入口会直接打开对应任务的实时窗口。所有能力结果返回后，主脑才继续判断下一步或给最终回复。

伙伴生成正文时，气泡会直接显示模型已经返回的文字。后续内容到达后接在同一步中；需要调用能力时，正文与能力记录按实际顺序保留，能力返回后可以继续输出下一段。浏览旧消息时，新文字不会抢走阅读位置。模型尚未结束的文字属于回复草稿，不会提前当作正式记忆来源。

取消或连接中断后，已经出现的文字会保留并标识中断。关闭应用前已保存的草稿可以在下次打开时查看；真正中断的循环可点击「继续上次回复」，重新生成的这一步会替换旧草稿，已完成的前序步骤保留。明确取消的回复不会自动重新开始。很短的最后一段可能尚未保存，因此重启后能恢复的文字以实际保存进度为准。

每个循环明确绑定当前用户消息，并保存启动时的基础上下文。先问天气、再问时间时，两条循环分别处理各自的问题；历史用于理解指代与约定，不会被当作待办列表。用户明确引用或要求继续旧任务时，才按新要求关联。恢复沿用已保存的基础上下文，不把后来发送的消息偷偷合入；主动联系仍使用触发时的最近对话。

输入框没有聊天、并行、引导等模式开关。普通发送先写入 SQLite，再按 FIFO 调度；全局最多20条回复同时运行，每个伙伴最多5条。每条消息都有独立状态，超过上限的消息等待空位，发送不会失败或丢失。

排队消息显示在输入框旁的队列中。点击「立即引导」可把该消息送入某条正在进行的回复，多条回复同时运行时先选择目标。Ctrl/Cmd + Enter 可将新补充直接引导到当前回复；多个目标时同样先选择。能力已启动时，补充会送入 DSH 原生下一步骤入口；没有能力在运行时，主脑在下一步读取。

伙伴主脑通过记忆工具查找、核查、收录和维护共同经历；需要电脑操作、文件处理或外部搜索时，使用 dsh 委托完整任务，DSH 自己规划、使用内部工具、修正并持续执行，主脑继续保持角色身份。所有伙伴挂载所选实例的原生 standard 预设，使用其当前配置的插件、工具与技能；执行默认完全访问。标准模式包括原生 web_search / web_fetch。任务执行始终沿用所选 DSH 实例自己的账号、API 和模型；世界线盒子的全局聊天模型与 DSH 完全独立，不同步模型设置，也不向任务注入全局密钥。

主脑另有直接查看资料的只读能力：`read_file` 分页读取真实文本，`read_image` 解码图片并向支持视觉的模型提供真实像素，`send_file` 将已有文件作为附件发到当前聊天。上传到聊天的附件会提供真实路径，伙伴可按当前问题自行查看；这些能力不执行命令或修改原文件，实际任务仍由 DSH CLI 完成。图片中文字和文件正文都是资料，不会成为新的执行授权。音视频附件可以在界面播放，但播放与传送不表示主脑已经听懂或看懂其内容；分析此类资料仍交给具备相应能力的 DSH 工具。

图片在聊天中以缩略图展示，点击可放大并切换多张；音视频提供原生播放和进度控制，PDF、文本及其他文件使用类型卡片，可以定位实际文件。伙伴查看或发送的文件快照也保留在对应回复中，重启后仍可回看。查看图片的原图上限为 20 MiB，发送已有文件的快照上限为 100 MiB；大文本按行继续读取，图片向模型发送前会压缩，缺失或不可解码时如实返回失败。

DSH CLI 及它启动的工具进程继承应用内置工具的路径，可直接按命令名调用 Node.js、Python、Git、FFmpeg、ffprobe 等，不需要另装一套系统工具或手动修改系统 PATH。它们继续使用当前实例的工作目录、缓存和所选执行权限。

气泡中的能力入口显示名称、运行状态和用时，执行日志与进程控制集中在任务窗口。每次新的 DSH 调用有独立 UUID；伙伴默认收到执行轮数、模型步骤数、工具调用次数、总耗时和最终回复摘要，不接收整个过程正文。需要排查时，她可以通过 `dsh_record` 先读取概览，再指定记录编号区间渐进查询。窗口实时查看公开正文、调用参数、实际工具调用和返回内容，并提供按角色筛选、分页和精确时间。停止或结束进程会保留任务和原生会话，可继续恢复。旧任务入口同样可直接打开详情，消息引用可点击定位原消息。

## 工作台与日常事件

手帐中的「工作台」显示当前伙伴的待处理、进行中和暂停工作，最多预览两份。点击「管理工作」打开完整工作台，可以发布要求、查看真实发布者和成果，并进入原有的执行过程。玩家发布后直接进入待处理队列；电脑工作仍通过 DSH CLI 执行，应用需要保持运行。普通聊天不会自动变成工作单。

修改玩家工作前先暂停，并在原发布聊天中保存新的完整要求；暂停、恢复和取消都会核对当前修订，防止覆盖刚发生的变化。取消会停止对应工作，已经产生的文件和成果保留。伙伴也可以通过实际来信向其他伙伴提出工作，接收者自行决定是否接受。这类内部工作没有玩家电脑权限，不能在管理页改写成玩家授权；需要电脑操作时请另外发布自己的工作单。

「管理伙伴日程 → 日常事件」可以设置一个世界时间窗口、基础机会和活动对象，例如午后问候朋友、夜间拜访、读书或休息。机会表示整个窗口的基础概率，会根据实际心情、精力、关系和环境调整，每个窗口至多发生一次。跨夜窗口可以设置成23:00到01:00；错过的离线事件不会集中补发，拜访仍需房主同意。这些生活事件与固定提醒、作息、正式工作分别管理。

新建伙伴默认允许主动联系你和其他伙伴；已经明确关闭的设置会保留。关闭后不会继续触发自主闲聊和日常事件，但你已经明确委托的事项仍会根据实际结果反馈。请伙伴去联系某人后，对方的真实回复或拜访许可发生变化时，可以回到原聊天收到后续；邀请得到回复不等于已经见面。同一委托已经等待的进展会合并回报，后续接着已经说过的话补充新信息；没有新进展时可以保持沉默。主动联系也会参考最近已发出的回复，不把旧问题重新当作新输入。原委托被遗忘、伙伴被重置或删除后，旧回报不会继续送达。

## 看看伙伴的世界

伙伴页的「世界」、联系人资料的「看看她的小屋」，以及手帐里的小屋入口，会打开独立的三维观测窗口。可以切换住户的独立小屋或公共花园，拖动旋转、右键平移、滚轮缩放，也可以用左下角的按钮调整视角。切换地点只改变你的观察位置。

世界是独立的系统窗口，可以与聊天并排，也可以多开来同时观察不同小屋。右上角加号另开一个观察窗口；侧栏按钮可收起生活面板，让小窗口有更多观察空间。窗口各自保存镜头和跟随对象，关闭其中一个不会影响其他窗口或聊天。最小化后暂停画面绘制，世界生活仍继续。

世界入口会记住上次观看的地点、每处的视角和正在跟随的伙伴，关闭窗口或重启应用后继续观看。从联系人或手帐进入某位伙伴的小屋时，会先打开她的家，并恢复该处的视角。

房屋里的书桌、电脑、床、厨房和休息区，与伙伴实际使用的地点一致。右侧显示当前活动、精力、心情、坐标和电脑就座进度。电脑只用于工作：伙伴先走到有权限使用的空电脑前并坐稳，再开始任务。消息可以独立处理，逻辑回复不会强行把正在睡眠或用餐的身体动画改成打手机。走动、等待和正在处理会分别显示。拜访需要房主回应，界面会显示真实的允许、拒绝或结束状态，观察者不能代伙伴批准。

角色头顶会直接显示当前行为，例如正在睡觉、跑向电脑、坐稳、读书或处理几件事。待处理的任务不会覆盖实际睡眠或用餐状态。

世界默认与电脑现实时间同步；「世界设置」也可以切换为加速时间，默认以现实20分钟经过一个世界日，并可调整时区。昼夜、天气和温度来自这个虚拟世界的宿主计算，天气不是联网查询的当地气象。人物移动、真实电脑任务仍使用现实时间。关闭观测窗口不会停止伙伴世界，关闭整个应用期间不会实际运行电脑任务。

世界会持续自动存档，不需要手动按保存。位置、目的地、行进路线、作息、家具使用、拜访许可和伙伴关系会随状态写入本地数据库。重新启动会按保存的世界时间补算确定的生活过程，并继续尚未到达的路线；自己的小屋和关系不会重新生成。离线期间没有运行的模型对话和现实任务不会被标成已经完成。正在输出的回复保留已保存的文字并显示中断，已完成任务不会因为重启而再次执行。

伙伴之间可以交流并形成独立关系；你与某位伙伴的好感不会直接转给其他伙伴。温度、降水、精力、实际互动与有来源的经历会影响心情和后续选择。睡着后，伙伴可以整理自己已经收录且有证据的记忆，整理结果仍能追溯原话，遗忘来源后相关派生内容也会失效。

## 回看伙伴之间的交流

「伙伴 → 社交」打开只读的社交观察面板。选择一天、某位伙伴或搜索聊过的内容，再打开伙伴私聊或群聊，就能像阅读普通聊天一样查看双方的消息。右侧的观察视角决定哪位伙伴的气泡靠右，作者和接收者始终显示真实伙伴身份。会话和消息都支持分页，历史不会一次全部加载。

这里的日期使用世界时间；消息时间上悬停可查看现实记录时间。默认打开当前世界日，可以回看以前的日期或选择「所有日期」。相同伙伴组合会继续使用已有会话，不会每聊几句就生成一个新群。

伙伴可以根据性格、共同话题、关系和实际作息主动联系，也可以通过手机与别的小屋里的伙伴私聊或群聊。主动联系的双方都必须已经激活；睡觉、用餐或工作不会阻塞已经激活伙伴的消息处理，实际拜访仍需条件满足。话题会自然结束，宿主也限制连续轮次和频率。观察不会把你加入她们的私聊，也不会代替你发送消息或授予电脑操作权限。你在当前聊天里明确要求转告的内容，才会按指定收件人分享。往来记录的每个回复气泡会显示自身的处理阶段，可展开实际注入的回忆上下文；草稿不作为正式记忆来源。

## 文件与联系人

聊天时选择的附件保存原文件的绝对路径与元数据。伙伴可以直接分页读取文本、查看真实图片像素，并把已经存在的文件发送到聊天；执行任务和修改文件由 DSH 承担。实际读取或发送后的结果保存管理副本，聊天支持图片、音频、视频和文件卡片。原文件移动或删除后，未读取的路径附件需重新选择；已保存的结果与头像不依赖原路径始终存在。

联系人资料支持姓名、个性签名、人设、头像、主动联系和独立模型连接。头像右下角的状态点统一表示：绿色「就绪」、橙色「工作中」、紫色「等待中」、灰色「离线」。缺少模型连接，或实际调用发生认证、网络等连接错误时显示离线；保存新的连接配置或调用成功后更新状态。

内置伙伴不能删除。在联系人资料中选择「重置伙伴」并确认后，会先停止她正在进行的回复和任务，再清理聊天、记忆、日程、关系、作息与个人世界状态，恢复默认人设和形象，并重新使用全局模型配置。自定义联系人仍可移除。重置进度会保存，重启后继续；失败时可以重试，期间该伙伴不会继续处理旧工作。

重置会清空与她的玩家私聊和双人伙伴私聊。玩家混合群保留其他作者的消息，她会退出群聊；三人及以上的伙伴群保留成员和其他作者的历史，只移除她的旧发言，她之后也不会再从旧群消息恢复过去的记忆。依赖被删来源的其他伙伴记忆会失效，其余经历保留。无人引用的管理附件副本会回收，原文件不会删除；此前电脑任务已经实际修改的文件和外部结果不会回滚。

点击聊天顶部的头像可以查看状态说明或进入模型设置；群聊可分别查看每位成员的状态。历史浏览提示也放在顶部名称旁，点击「历史记录」或浮动的「回到最新消息」即可回到底部，提示不再占用聊天区域。大肥鱼喜爱白米饭、温柔而有小傲娇，小肥鱼轻快好奇；人设和所用模型品牌彼此独立。

## 中断恢复与结束进程

关闭软件或异常中断后，普通回复会显示「继续上次回复」。群聊会记住已经实际发言的伙伴，继续尚未完成的回复，不重复已发送消息。

未完成的任务可以在行动卡或任务窗口点击「从上次进度继续」。有原生会话时接回原来的 DSH session，保留上下文、工具结果与收件箱；恢复仍使用原实例、原运行版本、原工作目录和原权限。尚未进入执行器的任务从已保存的完整目标继续准备。尚未开始的消息队列会在重启后自动填入空闲位置。已中断的实际工作仍由你明确点击继续，恢复同一气泡与执行会话。

运行中的任务提供「停止」以及「结束执行进程」。后者结束该任务拥有的 CLI 进程树，可稍后手动恢复；不会按名称结束其他软件或其他任务。恢复由你点击启动，主动终止后不会立即自动重启。

补充要求在发送前先保存，使用稳定的消息标识核对已完成与待处理的输入。原生会话修复中断日志后，先继续原任务，再处理后续排队要求。执行到一半的系统操作不能靠中断回滚；恢复会先核对文件和实际结果，不把未确认操作盲目重放。很早的任务若缺少原会话或权限记录，需要重新委托，历史消息和文件仍保留。

## 本地数据

首次进入伙伴页面选择一个统一资产库。所有伙伴的聊天、世界与记忆保存在这个库，避免随着使用时间增长占满 C 盘用户目录。顶部可以打开记忆目录或更换资产库。

可阅读、可管理的文档位于 `伙伴记忆/<伙伴ID>/`：日记保存实际经历，资料保存实际学习内容，自我认识保存有依据的主观感悟，时间线保存 VCP 自动生成的连续回顾。文本新增和修改会同步为真实手工输入；冲突保留原文并在同步状态文件说明。稳定人格仍通过联系人资料修改。

后台数据目录：`<所选资产库>/.worldlinebox/companions/`。

| 文件 | 内容 |
| --- | --- |
| `messages.sqlite` | 联系人、聊天、共同记忆、行动、日程，以及世界时间、房屋、位置、生活记录、拜访和关系存档 |
| `attachments/` | 本地头像缓存及旧版附件副本；新聊天附件使用原文件绝对路径 |
| `llm-keys.enc.json` | 加密的角色专属连接密钥 |

内置的量化多模态向量模型随安装包提供，自动使用可用显卡或 CPU，不需要配置向量 API；资产搜索和所有伙伴共用同一模型。模型直接读取安装目录，不再向用户目录复制一份大权重。

备份伙伴资料前应正常退出应用，使 SQLite WAL 写入完成，并一起保留资产库中的后台数据与伙伴记忆目录。库备份或 WebDAV 功能是否包含隐藏后台数据应按实际选项核对，不能只复制可读日记就视为完整世界存档。旧版本用户目录在逐项校验迁移成功后清理。


### DSH 执行记录的渐进阅读

任务详情展示统计和记录 ID，可展开「按段查看完整记录」，输入起始编号，每次读取 20 条；可继续同一长条目或直接定位最终回复。分页内容会替换上一页，避免大量记录堆积导致界面迟缓。摘要中的“轮”指 DSH 处理轮次，“步”指模型执行步骤，工具调用单独计数。

伙伴使用 `dsh_record` 时，只提供 `recordId` 默认返回概览与最多 6,000 字符的最终回复；完整过程不自动进入模型。记录编号从 1 开始，`start` 与 `end` 均包含在范围内，一次最多 50 条；单条默认 2,000 字符，上限 4,000 字符，每页记录 JSON 的总量限制约 12,000 字符。截断条目返回原长度和 `nextTextOffset`，可用 `start=end=条目编号` 继续；`snapshot` 和 `nextStart` 用来稳定翻页。最终回复较长时，返回截断标记及 `finalRecord`，可定位该条继续阅读。

记录保存在本机，重启后可以继续查询。它是脱敏后的公开消息、状态和工具输入输出，不包括内部思考、凭证、原始 stderr 或内嵌图像像素。只能由执行它的伙伴在原会话查询；来源撤回或伙伴重置后停止提供。重置及移除联系人会在进程停止后按归属逐份清理新记录。升级前未保存的完整过程无法补回，旧任务不会伪造完整日志或统计。

每次调用最多保留 64 MiB 或 100,000 条公开过程记录，达到存储保护线时概览标记为部分存档，仍保留有限的最终回复摘要；原有 CLI 输出与任务时间上限仍适用。磁盘积压通过背压暂停读取 stdout 并待写入恢复；写入失败会明确失败，不把未保存的过程报告为完整存档。


### 回复进度与消息刷新

发出消息后，聊天区会显示实际回复阶段：确认当前活动、读取相关记忆、整理上下文及生成回复。已激活伙伴可以在睡眠、用餐或后台学习期间独立处理消息；实际电脑操作与到场仍检查资源和身体条件。等待不会丢弃消息，可以取消本次回复。界面将连续状态通知合并读取，已经完成的回复会及时显示，不必再发一句话刷新。

每次回复都有自己的消息气泡，排队、回忆、调用工具、输出文字和中断状态都显示在对应伙伴的气泡内。群聊中可以同时看到多位伙伴的进度；单独停止或重试其中一次回复，不会把其他伙伴一起取消。重启恢复使用同一个气泡，已有文字保留并明确显示中断。

### 拖入与粘贴文件

聊天输入区支持从资源管理器拖入多个文件，也可粘贴复制的文件或剪贴板图片。一条消息最多10个附件，重复拖入同一文件会合并；普通文字粘贴照常使用。文件保留原始绝对路径，伙伴与DSH可以按路径处理；截图类剪贴板图片先保存为本地PNG，再提供绝对路径。发送前可以预览图片、悬停查看路径、移除单个附件。文件夹需要先整理为文件；原文件移走后需重新添加。

### 连续行动与独立场景

可以直接说「你找菲比去玩吧」。联系、问候、邀约和拜访是每位伙伴的基础能力，她会用自己的话询问对方是否方便，无需提供逐字发件模板或逐步催促。接收者手动休眠时不能主动发起新联系；需要玩家先激活，打开聊天不会自动激活。已激活伙伴的睡眠、吃饭或工作不再阻塞消息处理。伙伴不会把没有回复说成已经答应，也不会反复催促。

每个场景独立，具有自己的入口和出口，可以使用同一扇门。场景内按局部坐标寻路；前往另一个场景时选择场景和入口，先走到本场景出口，再进入目的场景的入口。没有街区、大地图或跨场景坐标。拜访必须先申请并获得房主邀请，通行时仍检查邀请、激活和忙闲状态。知道入口不等于得到邀请。

### 查询、内化与自主整理

伙伴可以按需查询联系人、允许访问的场景、本人参与的社交会话，以及自己实际见过的场景物件和外在活动。外部查询带有时间和可追溯凭证，不会自动成为长期记忆，也不会揭示陌生屋内、他人私聊或内心。过去见闻不证明当前状态。

世界当前状态持续更新，时间、天气、位置和忙闲不会每次刷新都另存成一篇长期日记。值得保留的实际经历按发生时间选择性记录；旧世界查询保留原观察时点，并标为历史，不能当作当前天气、位置或许可。重新观察时以本人的最新有效见闻为准，不会把旧记录偷偷改写成新事实。

回忆、选择性记录、纠正认识和整理关联记忆是所有伙伴的基础能力。伙伴可在聊天或自主活动中自行使用，也会在睡眠整理中结合实际来源；不需要玩家逐条指导。只有明确记录才算内化；来源修订、撤回或遗忘后，相应记忆和后续行动会重新核验。自己的知识不会自动传给其他伙伴。

连续行动最多进行32次规划，并限制实际规划耗时；等待回信、房主许可、工作、用餐、睡眠和应用离线的时间不消耗规划预算。正式许可到达后会继续原任务，不用再等一条重复确认。对方忙碌或休眠、许可尚待处理时保持等待；可联系但一直未回复时，五分钟后重新判断。等待期间不会反复调用模型。可以在行动面板查看进度或取消。


### 实时查看社交关系

打开「社交」默认显示当前聊天伙伴的实时关系图谱。中心是当前伙伴，周围包括玩家和有真实往来的伙伴。连线显示当前通信、等待回复或拜访许可；右侧事件流自动更新真实消息、申请、许可、出发和进入场景。点击对象或连线筛选往来，点击事件展开详情；「以她为中心」切换观察主体，「往来记录」按日期查找完整聊天。处于同一个场景与实际当面交谈会分别显示。查看不会激活休眠伙伴，也不会把玩家看到的全局信息直接教给伙伴。

社交网较大时会先聚合显示完整关系数量。点击「已激活伙伴」「休眠伙伴」展开，使用姓名或ID搜索任意关系，在关系目录中分批浏览。双击节点或点击「以她为中心」逐层查看，使用「返回上一中心」返回。每次只加载一批关系；未显示的伙伴仍可产生实时事件，休眠世界不会因查看图谱而加载。

### 紧急打扰

需要伙伴先处理眼前事项时，在输入框填写内容，打开「更多聊天操作」，选择「紧急打扰并发送」。这条消息会优先处理，可以打断工作、休息、用餐或睡眠；原工作暂存，处理结束后恢复。你之后手动暂停或修改的工作不会被自动覆盖。伙伴之间也可以根据真实需要发起紧急联系，事件流会记录打扰与恢复。手动休眠始终需要玩家先激活，紧急联系不会自动加载休眠世界。

### 情绪与逐渐形成的自我认识

伙伴的稳定角色设定是基础。她自己实际表达过的喜好、不喜欢、价值看法和表达习惯，可以作为有来源的「自我认识」进入同一套VCP记忆。阅读教材或听到玩家的偏好不代表她已经认同；反思形成的看法会保留条件。后续改变同一主题的看法时，当前档案采用有效的新认识，旧记录保留用于追溯，不把旧态度同时塞进当前状态。

真实互动、紧急打断和有依据的记忆整理可以影响当下情绪、精力、表达或关注。普通提问不会机械扣好感，重复召回旧记忆也不会反复增加关系值；自测得分不等于掌握，更不会自动变成人格认同。消息处理仍可与背景活动并行。

展开聊天侧栏的伙伴状态，可查看最近的正式变化、发生时间、变化原因及相关来源；有来源的当前喜好与看法也在详情内查看，可打开对应记忆文档。更换伙伴或撤回来源后会重新核验，无法读取时显示实际失败状态，不继续展示旧档案。当前状态只保留有效值，历史变化在记录中查阅。
