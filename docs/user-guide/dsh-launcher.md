# DSH 启动器

Windows x64 上，启动器管理官方 DSH 运行版本和原生实例。用户工作台与伙伴任务连接同一个实例的 Web Host。账号、模型、插件、技能和原生会话由 DSH 自己管理。

## 安装与选择

1. 在「运行版本」刷新 GitHub Release 列表，选择一个精确版本安装。启动器下载对应版本的官方 npm Web 制品、Node 和依赖，验证来源摘要与依赖锁后登记。此功能与 DSH 桌面版无关。
2. 创建实例，选择已安装的运行版本。一个版本可以建立多个实例；多个版本的实例可以同时运行。
3. 选择执行实例并打开工作台，在原生 DSH 设置中配置账号和模型。伙伴使用同一份设置，无需再配置伙伴专属执行环境。
4. 默认实例会在应用启动后连接 Web Host。首次初始化需要安装原生 profile 和桥接插件；之后伙伴任务直接创建会话。关闭工作台窗口不会结束 Host，「停止实例」才会停止服务。退出应用会清理受管进程。

官方发布通道可能先更新标签、后补齐依赖。安装失败会保留实际错误，不会偷偷换成另一个版本。已安装版本按制品摘要固定，刷新列表或安装新版本不会改变已有实例。删除版本前必须先处理实例、快照、整合包和正在执行任务的引用。

## 伙伴如何使用

伙伴主脑收到请求后，可查询所选实例的真实工具和技能，再把任务、上下文和交付要求提交给 DSH。启动器通过原生 Session Controller 创建或恢复会话，DSH 自己完成模型、工具、子代理、审批和存档。用户 Web UI 与伙伴看到同一个原生插件生态。

每个任务拥有独立会话与来源记录。任务恢复保持原实例、版本、工作目录和权限，切换默认实例不会把进行中的任务搬走。取消任务只取消它的 Session；其他伙伴和用户的 Host 继续运行。

伙伴默认复用自己的工作目录，DSH 工作区分组使用伙伴当前名称，例如「小肥鱼」，后续任务会话集中在该分组中。改名不移动文件；同名伙伴仍有各自独立的目录。明确指定已有项目目录的任务沿用项目工作区，不替换它的名称。

「正在连接 Web Host」、模型思考和工具执行是不同阶段。Host 已运行时不会每次重新安装依赖、遍历整套程序或启动一个伙伴 CLI。任务完整耗时仍包含伙伴主脑和 DSH 的模型响应时间。

## 插件与技能

在插件市场选择目标实例安装 npm 插件，或在实例管理中输入原生 DSH 支持的 npm、GitHub、本地包 spec。安装、移除与开关交给原生插件管理器。支持热加载的插件可在 Host 运行时生效；需要重启的插件按 DSH 的结果提示，不把失败显示为成功。

技能市场先检查 GitHub 仓库，再选择具体技能。下载固定到检查时的 commit 与归档摘要，安装到实例的原生 `DSH_AGENTS_HOME/skills`，运行中的 Host 可以读取。用户和所有使用这个实例的伙伴都能使用；其他实例独立管理。

安装一个全局 npm 包不等于把它注册为 DSH 插件；原生 DSH 也需要 `dsh plugin add` 或插件管理器登记。使用启动器管理的终端时，命令沿用所选实例的原生 `web` profile。软件保留真实 `USERPROFILE`、`APPDATA`、用户 PATH 和工具环境，插件可正常发现其系统依赖。软件不会改写官方全局 DSH 安装。

## 实例、复制与备份

每个实例分别拥有 DSH Home、agents 目录、默认工作区和浏览器存储。用户与伙伴共用所选实例，实例之间没有额外的共享存档层，也不会合并不同版本的内部文件格式。

复制与升级副本保留原生配置、账号、插件和技能，创建新的会话空间、工作区及浏览器存储。原实例保留，可先在副本中验证新 DSH 的配置和插件兼容性。

快照和完整备份保存停止实例的原生 Home、会话、agents 和工作区，恢复为新实例。快照要求保留匹配的精确运行版本；完整备份额外包含运行制品，可在缺失时校验并导入。实例的插件依赖目录不直接复制，恢复时由原生包管理器安装。浏览器登录存储不导出。备份可能包含模型密钥和私密会话，应放在可信位置。

整合包用于分享配置与技能，不包含账号凭据、会话、工作区、浏览器数据或 `node_modules`。它保存运行版本与插件依赖锁，安装到新实例时恢复原生依赖；启动器桥接插件由当前应用提供。不要把整合包当作个人数据备份。

## 数据位置

正常开发版与安装版均使用 `%APPDATA%/WorldlineBox/dsh`：

- `runtimes.json`、`runtimes/`：固定的官方版本与验证回执。
- `native-instances.json`、`instances/<id>/home`、`agents`、`workspace`：原生实例。
- `native-snapshots.json`、`snapshots/`、`packs/`：快照和整合包。
- `operations/`、`task-records/`：管理操作与伙伴任务公开执行记录。

应用级网络设置位于 `%APPDATA%/WorldlineBox/network`。旧 `dsh-launcher` 目录不再参与读取、迁移或执行。查看实现和实测记录可参考 [开发说明](../developer/dsh-launcher.md) 与 [本次验收](../developer/dsh-native-web-acceptance-2026-10-25.md)。
