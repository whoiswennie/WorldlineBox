# Browser packages

English | [中文](README.zh.md)

The browser domain separates the model-independent `ctx.browserController` contract from the model-facing `browser_control` tool. The desktop Host provides the contract by reusing Worldline's visible conversation-owned Electron tabs.

- [`browser`](browser/README.md) — capability types and stable action vocabulary.
- [`tool-browser`](tool-browser/README.md) — bounded Agent tool, schema, prompt, and output policy.
