# 网易云音乐 Host

[English](README.md) | 中文

本 Host 为用户选择的公开网易云歌单提供权限边界，默认使用 `18322613388`。它验证数字歌单 ID，读取完整且有序的歌曲 ID，分批展开歌曲元数据，并且只为所选歌单内的歌曲解析公开媒体重定向和同步歌词。Client 只接收 JSON 元数据、带时间戳的歌词行和 HTTPS 媒体地址；网易云账号 Cookie 或凭据不会跨越 Host/Client 边界。

## 模型体验

### 歌单网关

#### 模型可见内容

无。`ctx.remote.neteaseMusic` 接口只由全局音乐界面使用。

#### Token 影响

不会增加消息、工具、提示词片段或请求 token。

#### KV 缓存影响

歌单请求不会改变 Agent 请求前缀。

## 已知限制与待办事项

- **上游依赖**：网易云可能修改或停止未公开文档化的公共元数据和媒体接口。
- **仅限已发布免费歌曲**：本包不会登录、解密、解锁或绕过地区、版权与付费内容限制。
