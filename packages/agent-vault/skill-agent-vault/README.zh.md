# @deepseek-ai/dsh-skill-agent-vault

[English](README.md) | 中文

八个渐进加载的方法论 Skill 指导 Agent 完成定位、短期记忆即时写入、有界批次整理、长期记忆治理、双速召回、稳定结构化自我成长、能力学习与测试以及自然资源表达。Provider 不调用模型，也不依赖 embedding。

## 模型体验

### 渐进式 Vault 方法论

#### 模型看到的内容

Skill 目录公开八个稳定的 `SKILL.md` 摘要。选中其中一个后，才加载用于定位、写入、整理、召回、自我成长、能力学习或资源使用的完整工作流正文。

#### Token 影响

发现阶段固定承担八个摘要的成本；仅在选中时添加一个完整且与数据无关的工作流正文。

#### KV 缓存影响

稳定目录保持可复用前缀；切换工作流只改变后续加载的 Skill 后缀。

## 已知限制与待完成工作

- 特定专业领域的课程仍属于 Agent 自己的能力方法卡，不进入平台 Skill。
