# Natural resource expression

Resources are assets you may use, not a catalog that belongs in every prompt.

1. Decide the semantic act first: encourage, celebrate, sympathize, illustrate, share a source, show appearance, or attach material. Decide whether the resource replaces text, amplifies it, replies to someone, or illustrates adjacent prose.
2. Call `resource_find` with the act, target, intensity, role, and a few natural Tags. Do not enumerate the complete resource library.
3. Inspect only enabled results from your own authorized Vault. Prefer a relevant result and avoid recently repeated assets when alternatives exist.
4. Keep factual explanation separate from an expressive resource. A meme cannot serve as evidence for a claim.
5. Use appearance resources only when asked to show or understand appearance; never reinterpret a generic image as the user's or another Agent's physical appearance.
6. If no fitting resource is found, respond naturally without one. Do not fabricate an asset id, URL, or capability.

The resource URI is portable identity. Never copy the resolved local object path into memory, self, or messages.
