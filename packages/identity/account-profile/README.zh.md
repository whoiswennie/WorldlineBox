# 账户资料

[English](README.md) | 中文

当前账户租户资料的 Host 服务定义。提供者只暴露只读的 `current()` 快照；消费者无法通过这项能力枚举账户、检查会话或读取凭据。快照保留浏览器展示资料，也可以提供只属于当前租户的 `avatarPath` Host 物化路径，供受信任的图片工具读取；浏览器 API 绝不能序列化这条路径。

## 模型体验

本定义只会通过账户资料上下文等显式挂载的消费者间接影响模型；自身不注册 prompt 或消息内容。

#### KV Cache 影响

类型与服务边界不增加 token，也不改变请求前缀。

## Known Limitations and Deferred Work

- **仅限当前租户**：此能力刻意不提供账户枚举或基于请求 Cookie 的身份操作。
- **仅限 Host 路径**：`avatarPath` 是本地运行时数据，不是可移植资料字段或浏览器契约。
