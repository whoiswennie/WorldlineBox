# @deepseek-ai/dsh-client-ui-browser

[English](README.md) | 中文

桌面产品的对话浏览器视图。它注册 `browser` 对话席位，把 HTTP(S) 与工作区本地页面链接路由到 Host，并通过 `/worldline-browser` 端点控制归属对话的标签页。

从设置或其他功能页面打开链接时，会先返回当前对话页面，再选中该对话的“浏览器”标签，避免 Electron 原生网页错误覆盖在无关页面上。

组件按顺序上报可见边界，使 Electron 放置原生视图时不会采用过期的尺寸更新，轮询 Host 快照获取标题、历史状态和标签页变化，并在客户端无法接收 Electron 原生覆盖层时渲染同一原生标签页的有界实时栅格预览。预览上的鼠标、滚轮和键盘输入会归一化后转发给 Chromium，因此任意网站无需允许 `iframe` 也能显示和交互。关闭最后一个标签页后会保留明确的空浏览器状态。

## 模型体验

### 用户浏览器视图

#### 模型看到什么

什么也看不到：`BrowserSnapshot` 值、地址和用户导航操作都属于产品 UI 状态。

#### Token 影响

打开或导航标签页不会增加 Agent prompt、工具 schema 或工具结果 token。

#### KV Cache 影响

用户浏览器状态与模型请求相互独立，不会改变可复用前缀。

## 已知限制与暂缓事项

- **需要桌面桥接**：普通 Web 部署可以渲染不可用状态，但无法承载原生浏览器标签页。
- **轮询快照**：标签页元数据每秒刷新一次，因此标题和历史控件可能短暂落后于原生页面。
- **栅格回退**：Electron 所有者窗口以外的客户端接收压缩实时帧而不是第二份 DOM；无障碍树、原生文本选择和高帧率视频仍只由原生视图提供。
