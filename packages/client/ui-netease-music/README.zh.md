# 内置网易云音乐界面

[English](README.md) | 中文

此 Client 插件在全局顶部工具区提供常驻且完整的网易云音乐歌单。不同于官方外链 iframe，自有 React/audio 播放器通过受限 Host Remote 读取所有有序歌曲，因此默认歌单 `18322613388` 不再被截断为嵌入播放器中的前 10 首。通用设置页可保存、命名和删除多个公开歌单，并可在设置页或播放器内立即切换；内置的“默认”歌单不可删除，且可随时一键恢复。所有自定义歌单与当前选择都会跨重启保存。

关闭面板或切换世界线的对话与功能页时，audio 元素仍保持挂载。账户隔离的浏览器状态会记录当前歌曲、播放时间点、音量和自动播放偏好。自动播放默认开启；应用重启后，播放器会先恢复已保存的歌曲与时间点，再继续播放。可滚动列表和搜索框展示完整歌单，也不会产生 iframe 的大块空白区域。

播放器还提供上一首、下一首、快退 10 秒、快进 10 秒和进度跳转，并提供可随时打开或关闭且不会中断播放的同步歌词界面。当前歌词会跟随播放自动滚动；存在翻译时会同时显示，点击任意歌词也可跳转到对应时间点。播放模式默认为列表循环，也可在控制区切换为单曲循环或随机播放，所选模式会跨应用重启保存。

如果歌曲因 VIP、版权、地区限制或公开地址失效而无法播放，播放器会记录本次失败并自动尝试下一首。只有当前一轮中的全部歌曲均不可用时才会停止并显示可操作提示。

## 模型体验

### 全局播放器

#### 模型可见内容

无：播放和偏好只保留在 `worldline.topbar.trailing` Client 插槽中。

#### Token 影响

播放器不会增加消息、工具、提示词片段或请求 token。

#### KV 缓存影响

播放及其持久化状态不会改变 Agent 请求前缀。

## 已知限制与待办事项

- **浏览器策略**：即使保存了自动播放偏好，普通浏览器仍可能要求用户主动点击一次播放；Desktop Profile 已允许启动时自动播放。
- **服务可用性**：元数据和播放取决于网易云音乐可用性、地区策略以及歌单所有者已经公开的免费内容。
