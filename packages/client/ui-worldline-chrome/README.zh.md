# @deepseek-ai/dsh-client-ui-worldline-chrome

[English](README.md) | 中文

世界线自有的桌面框架，包含工作区、终端会话、运行时日志、工具链状态、产品状态栏和桌面更新界面。它填充稳定 UI Slot，并把每项特权操作委托给经过认证的 Host Remote 或沙箱化 Electron preload。

工作区浏览器与编辑器共享 workspace-tree 能力，终端和运行时日志工作台使用 Host API carrier。文件浏览器提供桌面式的新建文件、文件夹、导入、选中、键盘剪贴板、重命名、删除和拖拽移动操作。外部拖入和导入直接发送原始字节流，不再使用 `FileReader`／Base64，因此电影大小的文件不会继承浏览器内存上限。媒体预览使用不透明的同源 URL 与原生 HTTP Range 定位，不再把内容装进 Base64 RPC，因而可播放电影大小的音视频。该包只包含呈现与 Client 协调；它不会直接读取文件系统或启动进程。

在打包的 Windows 应用中，产品状态席位会监听桌面更新桥。GitHub 清单出现更高版本时会打开含发布说明的弹窗；暂不更新后，底栏会保留黄色入口以便再次打开。界面展示实时下载进度，而哈希校验、安装包持久缓存、提权和安装均由 Electron 主进程负责。

## 模型体验

### 产品工作台

#### 模型看到什么

什么也看不到：工作区预览、`TerminalRawReadResult` 值和运行时日志记录留在 Client 工作台中，除非用户另行提交其内容。

#### Token 影响

打开或操作产品工作台不会增加模型请求 token。

#### KV Cache 影响

框架状态与 Host 轮询独立于模型前缀，不会使 cache 复用失效。

## 已知限制与暂缓事项

- **由 Host 支撑的席位**：工作区、终端、浏览器和运行时日志控件需要对应的已认证 Host 服务；该包不提供纯浏览器回退实现。
- **桌面更新**：更新检查与安装仅用于打包后的 Windows 应用；浏览器和源码开发版本保留普通版本标识。
