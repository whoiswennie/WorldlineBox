# 世界线工作室界面

[English](README.md) | 中文

本包渲染中文优先的世界线创作、编译、演算与文字游玩工作室。它组合既有 Client 插槽，不替换知识库或虚拟伙伴界面。

## 契约

工作室通过类型化服务编辑项目正典、地图、机制、角色、构建诊断、演算和文字游玩投影。归档导入与导出始终打开共享的用户路径选择器；界面不包含默认归档目标，也不包含动画运行时。

## 模型体验

无直接影响，因为这个浏览器展示包不注册提示词、工具模式或模型请求内容。

#### KV 缓存影响

本包不直接产生模型请求，因此不会使可复用的模型前缀失效。

## 已知限制与后续工作

- **桌面路径能力** — 原生路径选择依赖桌面 Host；纯浏览器部署通过同一插槽契约使用有界的浏览选择器。
