# Worldline Studio UI

English | [中文](README.zh.md)

This package renders the Chinese-first Worldline authoring, compilation, simulation, and text-play studio. It composes existing Client slots without replacing the knowledge-base or virtual-companion surfaces.

## Contract

The studio edits project Canon, maps, mechanisms, characters, build diagnostics, Runs, and text-play projections through typed services. Archive imports and exports always open the shared user-controlled path picker; the UI contains no archive destination default and no motion runtime.

## Model Experience

None, as this browser presentation package registers no prompt, tool schema, or model request content.

#### KV Cache effect

No direct model request is produced, so the package cannot invalidate a reusable model prefix.

## Known Limitations and Deferred Work

- **Desktop path capabilities** — native path selection depends on the desktop Host; browser-only deployments use the bounded browse picker exposed by the same slot contract.
