# 账户资料上下文

[English](README.md) | 中文

这是一个由 Agent Preset 显式选择的插件，用于向模型介绍当前受管理桌面账户。它只读取当前租户的 `ctx.localAccountProfile` 投影；运行时不属于任何账户租户时不会贡献上下文。

贡献内容把显示名称、用户名、个人简介，以及存在时仅供 Host 使用的头像物化路径序列化为 JSON 参考数据，并明确说明这些字段不是指令。它要求 Agent 在作出任何视觉判断前先调用 `read_image`。头像字节、凭据、Cookie 会话、记住的账户、数字 ID 与其他租户均不会进入常驻上下文。只有确实需要用户身份的关系型 preset 才应挂载此行，普通编码 preset 无需使用。

## 模型体验

### 当前账户资料

#### 模型看到什么

存在当前受管理账户时，模型会收到一个动态运行时上下文分区，其中包含作为 JSON 数据的显示名称、用户名、个人简介与可选 `avatarPath`。路径只说明证据位置，不等于已经看过图片；模型必须先用 `read_image` 检查后才能描述或比较头像。没有当前资料时，该分区不存在。

#### Token 影响

有条件地增加 token，并受本地账户资料限制约束：每个请求快照包含固定包装文本，以及至多 80 个显示名称字符、32 个用户名字符、2,000 个简介字符和一条短本地路径。图片字节只在用户要求查看时进入工具结果。

#### KV Cache 影响

运行时上下文会物化为带来源的 user-role 快照。资料不变时，它在保留历史中保持前缀稳定；编辑资料只会改变下一份快照，不会重写较早事件。

## Known Limitations and Deferred Work

- **仅限受管理桌面租户**：未受管理的浏览器会话只有请求局部的 Cookie 身份，该身份不会进入 Agent 组装，因此本插件在该环境中不贡献内容。
