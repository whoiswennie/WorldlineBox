# 本地世界线项目

[English](README.md) | 中文

本包是世界线项目服务的持久化本地文件系统提供器，负责根目录绑定、索引、乐观写入、历史、回收站、冻结构建存储、逻辑演算引用和流式归档。

## 契约

所有解析路径都必须位于用户选择的项目库或显式归档路径内；信任边界拒绝符号链接；持久写入使用临时文件和原子发布。可恢复的项目回收站仍位于该项目库内，永久清空是独立的显式操作。归档预检会在解压前约束条目、大小、路径穿越、清单和内容摘要。

## 模型体验

间接影响，由世界线工具和上下文消费者读取提供器中的项目范围记录。

#### KV 缓存影响

提供器本身不发起模型请求；来源修订改变只影响后续由消费者选择的上下文。

## 已知限制与后续工作

- **单机项目库** — 文件锁与持久重命名语义面向单台本地设备；共享网络文件系统需要具有明确并发模型的独立提供器。
