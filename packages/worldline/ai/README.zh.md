# 世界线 AI

[English](README.md) | 中文

本包为世界线演算提供模型路由、有界上下文组装、角色决策、可恢复的流式文本生成和持久用量遥测。

## 契约

请求限定在一个项目与演算内，按照当前可选行动校验，并受所选模型真实上下文窗口约束。提供商判定为暂时性的失败按该路由的重试与 `Retry-After` 策略恢复；每次尝试都会留存调用证据，失败尝试的残缺输出不会进入正文。用量与估算成本只用于诊断，绝不会暂停故事。AI 输出记录意图与调用证据，但不能直接改变权威状态。

## 模型体验

### 有界世界线请求

#### 模型看到的内容

模型只看到选定的 `ContextPack` 段落、请求用途、允许选项或叙事指令，不会看到绑定范围以外的项目记录。

#### Token 影响

输入受路由模型窗口与包级上下文上限约束；输出受请求策略限制。这些是协议有效性边界，不是用户额度。

#### KV 缓存影响

稳定系统指令和未变化的正典段落保持顺序；新的快照、记忆选择、选项集合或叙事指令会替换请求专属后缀。

## 已知限制与后续工作

- **价格仅供诊断** — 估算成本依赖维护过的提供商与模型价格行；未知路由使用显式回退价格，不会静默按零成本记录。
