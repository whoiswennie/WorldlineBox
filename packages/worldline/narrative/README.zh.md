# 世界线叙事

[English](README.md) | 中文

本包把权威演算状态投影为文字游玩和可替换的故事舞台渲染器，同时不授予叙事直接修改状态的权限。

## 契约

打开、叙述、选项、自由输入、改写、存档点、分支与重试都依据持久演算记录解析。自由文本必须先映射为已验证行动才能改变状态；重试和改写会追加叙事记录，不重写历史。

## 模型体验

### 文字游玩叙述

#### 模型看到的内容

模型看到有界的 `SceneFrame`、最近叙事节拍、可见选项、风格设置以及当前叙述或自由输入任务。

#### Token 影响

每次叙述请求都有独立上限；发送前会按照包级上下文策略截断最近节拍与场景数据。

#### KV 缓存影响

稳定叙事指令保持前缀稳定；场景状态、最近节拍和当前用户行动会替换请求后缀。

## 已知限制与后续工作

- **以文字为核心** — 富故事舞台渲染器可消费结构化场景和媒体提示，但素材生成与音视频播放仍由独立扩展负责。
