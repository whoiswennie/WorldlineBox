# 世界线叙事

[English](README.md) | 中文

本包把权威演算状态投影为视觉互动小说和可替换的视觉演绎器，同时不授予叙事直接修改状态的权限。

## 契约

打开、叙述、选项、自由输入、改写、存档点、分支与重试都依据持久演算记录解析。每个故事阶段的顺序固定为：正文模型先保存完整的结构化故事块，创意状态导演再原子提交符合 schema 的软状态、记忆与剧情证据，界面完整呈现该段正文，最后才由创意选项导演实时生成恰好三个不同的场景化行动。三个方向分别承载主线推进、人物深化和有意义的偏航，但都必须绑定当前 Runtime 合法能力；不得从剧情点复制选项，也不得用静态文案补齐。

自由文本由同一创意导演映射到当前合法能力后才可改变状态。时间与位置只由 Runtime 推进。重试和改写只追加记录，不重写历史；呈现游标会阻止切页后重复播放已读正文。

## 模型体验

### 文字游玩叙述

#### 模型看到的内容

正文模型看到有界的 `SceneFrame`、最近且符合视角权限的叙事节拍、风格设置与当前叙述任务。创意路由分别接收状态/记忆判定和最终选项生成所需的独立有界上下文。自定义角色与世界状态按照作者声明的 schema 投影，不依赖产品写死的字段白名单。

#### Token 影响

每次正文或创意请求都有独立上限；发送前会按照包级上下文策略截断最近节拍与场景数据。

#### KV 缓存影响

各阶段的稳定指令保持前缀稳定；场景状态、最近节拍和当前用户行动会替换请求后缀。

## 已知限制与后续工作

- **带原生生成标记的文本优先核心** — 视觉演绎器消费已授权的场景与媒体提示。真实资源不存在、而画面或声音自然属于正文某一瞬间时，正文模型会在同一个有序演出序列的准确位置创作一等 `media-intent` 块，而不是事后追加元数据。其中明确 `image`/`audio` 类型、受约束用途、可直接交给生成器的提示词以及必填的文字替代。后续图片或音频提供方可直接消费这个判别联合块；未接入生成器时，互动小说会在相同演出顺序中内联显示文字替代。资源生成和播放仍由独立扩展负责。
