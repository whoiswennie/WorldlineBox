# 世界线演算服务

[English](README.md) | 中文

本包定义面向 Host 的演算生命周期、控制、观察、检查点、分支、回放和干预服务。

## 契约

每个演算都从冻结世界蓝图创建，并通过已验证行动与确定性事件顺序推进。服务把权威状态与 AI 意图、调用遥测、观察及叙事节拍分离，同时保留全部记录用于解释和回放。

## 模型体验

间接影响，由世界线工具和叙事消费者呈现有界的演算视图与记录。

#### KV 缓存影响

服务本身不发起模型请求；上下文选择与稳定前缀复用由消费者负责。

## 已知限制与后续工作

- **逻辑时间演算** — 墙钟时间与多人网络不是权威输入；外部实时系统必须通过适配器提交已验证行动。
