# 世界线工具

[English](README.md) | 中文

本包注册世界线创作、查询、编辑、链接、地图、构建、演算、解释和传输所用的项目范围模型工具。

## 契约

每次执行都会解析调用方作者会话绑定。变更操作必须携带相关稳定标识、来源、乐观修订、试运行或显式确认；通用文件系统或 Shell 工具绝不是项目数据的替代权限来源。

## 模型体验

### 项目范围工具界面

#### 模型看到的内容

模型看到生成的[工具目录](../../../docs/tool-catalog.md#deepseek-ai-dsh-tool-worldline)中记录的九个 `worldline_*` 模式，以及一条把这些工具指定为世界线唯一变更权限的稳定系统规则。

#### Token 影响

预设挂载期间，工具模式和简短系统规则保持固定；每个 JSON 结果受对应项目或演算查询上限约束。

#### KV 缓存影响

固定工具模式与系统规则形成稳定前缀；只有工具调用及其项目范围结果追加请求专属内容。

## 已知限制与后续工作

- **需要作者会话** — 大多数操作会有意拒绝缺少明确项目绑定的执行，因此通用未绑定聊天会话不能修改世界线状态。
