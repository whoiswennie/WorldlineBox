# 世界线演算工作线程

[English](README.md) | 中文

本包监管隔离的工作线程；每个线程运行确定性离散事件世界线内核，并独占一个演算数据库。

## 契约

Host 监管器施加内存与请求时限，把线程故障映射为明确的运行时错误，移除失效句柄，并可重新打开持久化逻辑演算。工作线程串行处理命令，校验每次状态变化，并在发布结果前提交状态及其记录。

## 模型体验

间接影响，由演算、世界线工具和叙事消费者读取工作线程产生的状态。

#### KV 缓存影响

工作线程本身不发起模型请求；后续消费者独立选择有界快照与记录。

## 已知限制与后续工作

- **每个打开演算一个线程** — 超大并发项目库受 Host 资源策略约束，应关闭不活跃句柄，而不是长期保留所有演算工作线程。
