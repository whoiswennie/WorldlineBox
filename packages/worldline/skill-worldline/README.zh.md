# 世界线作者技能

[English](README.md) | 中文

本包提供七项渐进加载技能，覆盖正典创作、角色、地图、机制、场景、构建审计和演算分析。

## 契约

提供器按稳定技能名称暴露不可变包资源。技能内容教授有界的世界线服务与工具工作流，绝不会指示模型绕过项目权限或直接编辑不可变产物。

## 模型体验

### 已选择的创作技能

#### 模型看到的内容

只有请求的技能正文（例如 `worldline-authoring`）及其与任务相关的引用资源会加载到作者会话。

#### Token 影响

技能内容按需条件加载；未选择的技能正文不会占用请求 Token。

#### KV 缓存影响

不可变技能文本在持续保留时跨请求稳定；选择不同技能会增加或替换技能专属上下文段。

## 已知限制与后续工作

- **仓库自有方法论** — 内置技能面向当前世界线契约，不是脱离本产品的通用世界构建课程。
