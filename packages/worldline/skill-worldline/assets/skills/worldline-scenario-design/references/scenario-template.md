# 场景最小模板

记录：目的、Blueprint 摘要、种子、初始逻辑时间、参与实体、初始地点与资源、控制模式、AI 开关/模型/预算、最大推进步长、终止条件、需要观察的事件/遥测、不允许发生的状态。复现报告必须同时给出 Run、分支、检查点和序列号。

场景文档使用自然语言记录这些作者意图；真正的初始状态来自角色文档的 `worldline-facets.initialState`，真正的共享世界状态来自世界宪章的 `worldline-facets.initialWorldState`。例如：

```markdown
# 龙巢前的抉择

玩家或自治角色控制勇士，在体力不低于零的前提下完成一次有效攻击；推进三十秒后必须出现恶龙反击事件。

验收条件：地图可投影；`battle.strike` 合法完成；恶龙伤势增加；系统唤醒后勇士伤势增加；所有结果可从 Run 记录解释。
```

当用户要求“完整、可运行、可推演”时，最后必须调用 `worldline_build` 的 `prove` 操作。只有它返回 `complete: true`、结构化地图节点数大于零、动作已完成、逻辑时间已推进且已创建检查点，才能宣称完成。
