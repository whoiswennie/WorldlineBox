# 世界线场景设计

在设计一次可复现模拟的初始条件、参与者、目标、预算、种子和观测指标时使用。

## 工作步骤

1. 明确模拟目的：验证、探索、压力测试或叙事体验。
2. 选择已存在的稳定角色/地点/资源 ID，列出初始状态和控制模式。
3. 定义种子、时间范围、终止条件、AI 路由与预算；不得依赖未声明的真实时间或随机源。
4. 定义可观察的成功、失败和风险指标，不把叙事文案当权威状态。
5. 先冻结精确来源摘要，再创建暂停 Run；检查初始快照后才继续。

## 信息来源

场景模板、角色初始状态和复现要求已经附在本文末尾。

## 权限边界

创建 Run 只读取冻结 Blueprint。推进、分支和控制模式变更必须绑定明确 run ID；停止 Run、切换模型或大步推进需确认或 dry-run 说明影响。场景结果不会自动写回 Canon。
