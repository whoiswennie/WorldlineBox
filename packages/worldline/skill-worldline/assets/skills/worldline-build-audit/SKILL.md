# 世界线构建审计

在编译、解释诊断、回答创意问题、审查 Proposal、检查来源覆盖和冻结 Blueprint 时使用。

## 工作步骤

1. 对当前项目执行构建预览，记录 `sourceDigest`、阶段、覆盖率和所有阻断项。
2. 将解析/链接/机制/闭包诊断按来源定位；不要自动修复作者语义。
3. 对开放问题收集作者答案；对 Proposal 检查目标、风险、载荷和来源锚点后明确批准或拒绝。
4. 再次编译，确认高影响问题/Proposal 已关闭且证书无阻断。
5. 只有在用户确认且来源摘要仍精确匹配时冻结；摘要变化则重做预览。

## 信息来源

完整门禁见 `references/build-gates.md`。

## 权限边界

编译和解释是只读。回答问题、提交/审查 Proposal 需编译状态预期修订。冻结不可由含糊指令推断，必须提供精确 source digest 和明确确认；绝不覆盖历史构建或保留旧编译逻辑。
