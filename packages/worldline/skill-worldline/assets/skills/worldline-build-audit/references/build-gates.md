# 构建门禁

冻结前必须同时满足：来源快照未变化；无 blocking 诊断；闭包证书无 blocking 结果；无开放的高影响问题；无待审的高风险 Proposal；所有可执行对象具有来源；稳定 ID 可解析；地图拓扑闭合；动作/系统/不变量语义完备。冻结结果是新的不可变构建，不覆盖已有构建目录。

对“完整、可运行、可推演”的交付，冻结仍不是终点。必须使用 `worldline_build(operation="prove")` 原子执行当前来源的编译、冻结、Run 创建、合法动作、逻辑时间推进、地图投影、事件检查和检查点创建。`complete: false` 是返工指令，不是可忽略的警告；不得用文档数量或自然语言自评替代该证据。
