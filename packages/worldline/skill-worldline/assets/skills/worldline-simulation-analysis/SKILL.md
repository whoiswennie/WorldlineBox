# 世界线模拟分析

在解释 Run 状态、事件因果、动作决策、进程、资源预约、异常恢复、AI 成本或分支差异时使用。

## 工作步骤

1. 绑定明确的项目、Run、分支和当前序列；先读取健康状态与所需的有界事件页。
2. 从目标事件向决策、进程、预约和遥测追溯，区分因果证据与分析推断。
3. 检查等待时间、未来队列、无进展步数、死锁/活锁、公平干预和 Worker/SQLite 健康。
4. 检查 AI 调用的模型路由、上下文来源、token/成本、预算和降级结果。
5. 需要试验反事实时从显式检查点创建分支，绝不回写原 Run；比较时报告种子与分叉序列。

## 信息来源

诊断顺序见 `references/run-diagnostics.md`。

## 权限边界

查看和解释可直接执行。推进、动作提交、控制/AI/模型切换和分支必须携带 run ID、actor ID 或序列等稳定上下文；大步推进、停止和高影响动作需确认。叙事文本不能作为状态证据。
