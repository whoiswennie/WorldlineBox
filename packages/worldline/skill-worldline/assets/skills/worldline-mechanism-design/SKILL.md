# 世界线机制设计

在把自然语言规则转换为动作、系统、不变量、预算、资源竞争和恢复策略时使用。

## 工作步骤

1. 提取作者原文中的主体、触发、前置条件、持续时间、成本、效果与失败情况。
2. 把持续行为建模为 Process，把互斥占用建模为 Reservation，把时间推进交给未来事件队列。
3. 明确并发冲突、排序、公平性、死锁/活锁检测和确定性恢复规则。
4. 为每条机制连接来源锚点；模型新增的解释先进入 Proposal。
5. 用构建闭包和最小反例场景验证，不允许“常识兜底”隐藏未定义语义。

## 权限边界

高影响机制、伤害、资源再分配和不变量变化必须由作者批准。禁止直接编辑 Blueprint、SQLite 或 Worker 状态；写源文件需预期修订，运行控制需显式 run ID 与序列。
