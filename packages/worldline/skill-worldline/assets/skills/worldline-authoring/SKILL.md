# 世界线设定编写

在创建或修改世界观、地点、角色、组织、物件、关系等 Canon 来源时使用。本技能只处理当前 WWS 语义，不生成旧格式或兼容分支。

## 工作步骤

1. 先读取项目树、目标文档、相关反向链接和必要历史，确认已有稳定 ID 与作者事实。
2. 区分事实、推测与待决定项；不确定但影响大的内容写成创意问题或 Proposal，不擅自补全。
3. 使用稳定 ID 建立引用；显示名可以改变，身份不可随重命名改变。
4. 通过带 `expected_revision` 的补丁写入，保留来源锚点；冲突时重新读取，不覆盖并发编辑。
5. 重新搜索断链并执行构建预览；将阻断诊断交还作者决定。

## 信息来源

作者项目文档和已批准 Proposal 高于模型猜测；运行记录不能反向改写 Canon。对象和来源规则已经附在本文末尾。

## 权限边界

查询可直接执行。写入必须限定项目、路径、稳定 ID 和预期修订；批量移动、删除、根目录变更和冻结需明确确认。绝不通过通用文件工具绕过项目服务，绝不修改远程仓库。
