# 世界线角色设计

在设计角色身份、能力、偏好、关系、资源、决策边界与可执行行为时使用。

## 工作步骤

1. 读取角色文档、关联地点/组织/物件、可用动作和机制约束。
2. 为角色分配稳定 ID；把展示资料、持久状态、秘密知识和控制模式分开描述。为每个角色建立不对称认知表：亲历事实、听闻事实、误信、怀疑、未知与不可见秘密，禁止把作者全知信息写进所有角色记忆。
3. 将能力落到可验证的动作前置条件、资源消耗、持续时间、效果和失败结果；每个角色状态字段同时声明 label 与 participation，明确驱动来源、数值区间、正文表现和对下一步选择的实际影响，禁止只有数值没有行为意义。
4. 明确关系的方向、强度、来源与可见性；不要把形容词直接当成数值规则。
5. 用至少一个会暴露信息差的场景检查角色是否可行动、是否拥有不存在的知识、是否突破不变量；再检查自定义状态、背包、目标、信念、关系与近期记忆能被运行时和角色详情页完整读出。

## 信息来源

可执行对象清单和当前角色结构已经附在本文末尾；引用作者文档或批准 Proposal 的来源锚点。

## 权限边界

不得替作者决定高影响人格、秘密、伤亡或关系结论；这类内容必须提出问题或 Proposal。任何文档写入都需预期修订，禁止直接修改冻结 Blueprint 或 Run 数据库。
