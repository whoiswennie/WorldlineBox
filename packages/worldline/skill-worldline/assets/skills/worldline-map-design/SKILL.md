# 世界线地图设计

在创建或审计地图节点、边、分层、通行条件、空间语义和旅行规则时使用。

## 工作步骤

1. 读取当前 `worldline-map` 结构和引用它的角色、动作、系统。
2. 使用稳定节点与边 ID，验证端点存在、ID 唯一、坐标有限、边权非负。
3. 区分视觉布局与可执行拓扑；自动布局只改坐标，不改变连通关系。
4. 为单向、封锁、门槛、成本和跨层连接写出明确语义与来源。
5. 以结构化补丁生成 dry-run，检查断链和不可达区域后再提交；随后构建预览。

## 信息来源

地图检查表、当前唯一 JSON 格式和最小示例已经附在本文末尾。

## 权限边界

地图变更必须经项目服务和预期修订；删除被引用节点、批量改拓扑或改变旅行规则属于高影响操作，应创建 Proposal 或请求确认。不得维护第二种地图解析逻辑。
