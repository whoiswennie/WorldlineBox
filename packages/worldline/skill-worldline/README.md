# Worldline author skills

English | [中文](README.zh.md)

This package bundles seven progressively loaded skills for Canon authoring, character, map, mechanism, scenario, build-audit, and simulation-analysis work.

## Contract

The provider exposes immutable package resources by stable skill name. Each selected body includes its one current-format reference inline, so a Worldline-only Agent never receives an unreadable physical path or falls back to Agent Vault. Skill prose teaches bounded Worldline service and tool workflows and never instructs a model to bypass project authority or edit immutable artifacts directly.

## Model Experience

### Selected authoring skill

#### What the model sees

Only the requested skill body such as `worldline-authoring` and its directly associated current-format reference are loaded into the author Session as one self-contained result.

#### Token effect

Skill content is conditional and loaded on demand; unselected skill bodies contribute zero request tokens.

#### KV Cache effect

Immutable skill text is stable across requests that retain it, while selecting a different skill adds or replaces the skill-specific context segment.

## Known Limitations and Deferred Work

- **Repository-owned methodology** — the bundled skills target the current Worldline contracts and are not a general-purpose worldbuilding curriculum independent of this product.
