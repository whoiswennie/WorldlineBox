# 世界线项目服务

[English](README.md) | 中文

本包定义世界线项目库可替换的 Host 能力与自动生成的 Remote 接口。文件系统策略、索引、历史记录和归档流由本地提供器负责。

## 契约

服务负责项目库操作、可恢复的项目回收站与显式永久清空、项目范围内的文档变更、冻结构建引用、逻辑演算存储引用以及可取消的传输任务。调用方使用稳定项目标识与乐观修订号，不直接访问文件系统。

## 模型体验

间接影响，由世界线工具和会话上下文消费者选择项目记录并放入模型请求。

#### KV 缓存影响

服务本身不发起模型请求；消费者依据所选项目修订决定前缀稳定性。

## 已知限制与后续工作

- **以本地提供器为主** — 当前实现绑定一个由用户选择的本地项目库根目录；远程或协作提供器必须实现同一服务契约且不得削弱项目隔离。
