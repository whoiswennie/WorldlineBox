# 世界线会话上下文

[English](README.md) | 中文

本包把一个作者会话绑定到单个项目、世界线、来源修订和可选演算，并把这条持久权限边界发布到作用域系统提示词。

## 契约

绑定归会话所有，拒绝跨项目歧义，并携带作者工具使用的准确来源修订。释放绑定会移除作用域提示内容，不改变项目数据。

## 模型体验

### 作者绑定

#### 模型看到的内容

一个紧凑的 `Worldline author binding` 区块，列出获准访问的项目、世界线、来源修订与可选演算标识。

#### Token 影响

每个已绑定作者会话只增加一段固定大小的简短系统上下文。

#### KV 缓存影响

绑定不变时该区块保持稳定；重新绑定会替换这段系统上下文，并使其后方的复用失效。

## 已知限制与后续工作

- **每个会话一个活动绑定** — 跨项目比较需要独立会话，或另行设计明确只读的比较消费者。
