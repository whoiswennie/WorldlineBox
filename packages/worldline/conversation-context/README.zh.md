# 世界线会话上下文

[English](README.md) | 中文

本包为世界线 OC 作者会话维护一个可切换的活动项目、世界线、来源修订和可选演算，并把当前上下文发布到作用域系统提示词。

## 契约

活动项目归会话所有。新建项目或明确使用另一个项目时会自动切换；每一次工具操作仍只作用于一个项目，并携带准确来源修订。会话销毁不改变项目数据。

## 模型体验

### 作者绑定

#### 模型看到的内容

一个紧凑的活动项目区块，列出当前项目、世界线、来源修订与可选演算标识。

#### Token 影响

每个已选择项目的作者会话只增加一段固定大小的简短系统上下文。

#### KV 缓存影响

活动项目不变时该区块保持稳定；切换项目会替换这段系统上下文，并使其后方的复用失效。

## 已知限制与后续工作

- **同一时刻一个活动项目** — 会话可随用户意图切换项目，但单次变更不会混写多个项目。
