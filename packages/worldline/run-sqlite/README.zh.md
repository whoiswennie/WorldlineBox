# 世界线演算 SQLite 存储

[English](README.md) | 中文

本包使用预写日志，把一个演算的权威快照、有序数据流、检查点和元数据保存在单写入者 SQLite 数据库中。

## 契约

一个演算工作线程在其生命周期内独占可写连接。每次提交在同一事务中更新快照并追加有序记录；回放、检查点查询、完整性检查与只读归档访问都保持该顺序。

## 模型体验

间接影响，由演算和叙事消费者选择有界的演算记录。

#### KV 缓存影响

数据库本身不发起模型请求；由消费者决定哪个单调记录前缀进入上下文。

## 已知限制与后续工作

- **刻意保持单写入者** — 契约不支持多个并发可写连接；扩展方式是每个逻辑演算使用独立数据库，而不是共享写入者。
