# 世界线编译器

[English](README.md) | 中文

本包把固定修订的正典快照编译为保留来源的世界蓝图，并拒绝冻结不完整或自相矛盾的世界。

## 契约

编译会产生诊断、创作问题、可审查提案、语义解释和闭包证书。只有当前来源与目标用途的闭包检查成功后，显式冻结操作才写入不可变世界蓝图。

## 模型体验

间接影响，由世界线工具呈现编译诊断、提案和冻结构建摘要。

#### KV 缓存影响

编译器本身不发起模型请求；模型上下文是否替换由调用工具或作者工作流负责。

## 已知限制与后续工作

- **有界表达式语言** — 可执行机制使用仓库封闭的表达式与效果词汇；世界蓝图有意排除任意脚本。
