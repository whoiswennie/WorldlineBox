# Worldline compiler

English | [中文](README.zh.md)

This package compiles a revision-pinned Canon snapshot into a provenance-preserving Blueprint and refuses to freeze an incomplete or inconsistent world.

## Contract

Compilation produces diagnostics, creative questions, reviewable proposals, semantic explanations, and closure certificates. Freezing is explicit and writes an immutable Blueprint only after current-source provenance and purpose-specific closure checks succeed.

## Model Experience

Indirectly, through Worldline tools that render compiler diagnostics, proposals, and frozen build summaries.

#### KV Cache effect

The compiler sends no model request; the calling tool or author workflow owns any model-context replacement.

## Known Limitations and Deferred Work

- **Bounded expression language** — executable mechanisms use the repository's closed expression and effect vocabulary; arbitrary scripts are intentionally excluded from Blueprints.
