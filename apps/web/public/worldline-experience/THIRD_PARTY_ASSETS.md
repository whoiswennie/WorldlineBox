# Third-party character artwork

The directory includes three character portraits from *Cosmic Princess Kaguya!*
(`超かぐや姫！`, distributed in Chinese as `超时空辉夜姬！`):

- `companion.png` depicts 月見ヤチヨ / Yachiyo Runami. The repository copy is a
  1080×1724 portrait export; its exact upstream file was not recorded when it was added.
- `iroha-sakayori.png` depicts 酒寄彩葉 / Iroha Sakayori. It was supplied by the
  Worldline operator for the built-in companion profile.
- `kaguya.png` depicts かぐや / Kaguya. It was supplied by the Worldline operator for
  the built-in companion profile.
