# 验证基准与最终验收

## 验收原则

本次重构只在功能、数据、权限、召回、规模、上下文、UI、移植和工程质量全部通过时验收。单元测试通过、页面能打开或少量对话表现良好都不构成最终完成。

## 测试层级

- 契约测试：服务类型、URI、错误码、权限、revision 和事件。
- Provider 测试：本地 VFS、SQLite 派生索引、监听、原子写入和导入导出。
- 工具测试：域隔离、参数预算、冻结、错误结果和模型可见内容。
- Skill 场景测试：记住、整理、晋升、召回、自我修改、能力发现和资源使用。
- Client 测试：印象卡、统一工作台、编辑器、画廊、表格、开关、历史和导入导出。
- Runtime 测试：伙伴独立会话、上下文注入、房间权限、资源晚绑定和恢复。
- CLI/Desktop 测试：数据根目录、不同路径导入、Range 媒体、打包运行和 Windows 路径。
- 性能与规模测试：大文档、大量短期记录、大量资源、冷启动、增量更新和并发读写。
- 迁移测试：旧资源真实结构副本、损坏数据、缺失 blob、重复哈希和回滚。

## 必备夹具

至少准备：

- 10、1,000、10,000 和 100,000 条短期记忆。
- 100、10,000 和 100,000 个页面/章节卡，包含中文、英文、日文和混合文本。
- 多层目录、同名页面、别名、断链、循环 Wiki 链接和超大目录。
- “八千代/朧月夜”“画漫画/连环漫画设计”等语义近邻但非同名查询集。
- 身份、人设和普通知识共享相同词项的隔离用例。
- 10、1,000 和 10,000 项图片/GIF/音频/视频/PDF 资源元数据。
- 同日同名相同内容、同日同名不同内容和跨日版本文件。
- 冻结、修改需确认、用户锁和 stale revision 冲突。
- 完整迁移包、可分享包、损坏包、路径穿越包和压缩炸弹模拟包。

## 召回指标

在固定测试集上记录：

- `Recall@3` 目录命中率。
- `Recall@5` 页面命中率。
- `Recall@5` 章节命中率。
- 能力别名/Tag 查询命中率。
- 短期新写入即时召回率。
- 负面查询的误召回率。
- `self`/`memory`/`procedure`/`resource` 跨域泄漏数。
- 公共和伙伴私有跨作用域泄漏数。

最低目标：

- 精确实体、别名、中文连续子串和明确 Tag 查询 `Recall@3 ≥ 95%`。
- 标准能力同义查询 `Recall@5 ≥ 90%`。
- 已保存短期记忆在保存完成后的下一次召回中命中率为 100%。
- 域泄漏和权限泄漏为 0。

实际阈值由基准硬件重复测量后固化到测试配置，不能只靠主观对话评价。

## 延迟与上下文预算

基准硬件目标：

- 已热索引快速召回 p95 小于 50 ms，目标值 30 ms。
- 单文件用户保存后的最小召回卡同步可见，后台全文索引不阻塞正常编辑。
- 快速召回默认最多 5 张方向卡，自动感知默认最多注入 3 张。
- 深度探索严格遵守请求预算并返回 continuation。
- 资源列表首屏只加载可见缩略图，10,000 项资源不会一次解码所有媒体。
- 编译印象具有明确 token 上限；全部 Tag 和全部能力不会随规模线性进入上下文。

## 整理与恢复指标

- 100,000 条短期记忆能够通过元数据普查产生分批任务，不出现单文档加载。
- 任意批次中断后可从检查点继续，已经提交的条目不重复合并。
- 重复执行同一任务不改变结果或产生重复页面。
- 一个批次超出预算时自动拆分，不继续扩大上下文。
- 只更新命中子树和必要祖先；不因单条知识触发全库重写。
- 长期晋升失败不会损坏中期版本或丢失来源。

## 权限和人格安全

必须证明：

- `knowledge` 工具无法读取和写入 `self`。
- `procedure` 工具不能把一般知识标记为认证能力。
- 一个伙伴无法访问或修改另一个伙伴的私有 Vault。
- AI 只读模式拒绝全部语义写入，索引仍可重建。
- 稳定人设模式允许记忆成长但拒绝 self 写入。
- 用户锁定条目不能被自治修改。
- 单次情绪事件不会修改核心身份或人格。
- 实体没有头像时不会虚构外貌，头像为 symbolic 时不会断言真实长相。

## 资源迁移验收

- 旧资源记录成功映射率 100%，否则必须有阻断性失败报告。
- 所有 blob 哈希和字节数一致。
- 公共、伙伴私有、启用、禁用、内置和用户自定义数量分别一致。
- 旧 Tag 原值可追溯，规范化后仍能通过原标签召回。
- 每类 MIME 可以在新 UI 查看或安全回退为附件。
- 旧表情包可以被新版 `express` 使用，近期去重仍有效。
- 旧数据目录和独立备份在用户确认前保留。

## 导入导出验收

- 完整 Vault 往返导出导入后语义文件和资源校验和一致。
- 将包导入完全不同的绝对路径后，内部链接、头像、资源、检索和能力卡正常。
- 复制为新伙伴后内部 `vault://` 链接无需改写。
- 可分享包不包含用户私密关系、私人来源、临时情绪、账号令牌或绝对路径。
- 缺少工具依赖时能力显示降级，不伪装可用。
- 恶意路径、符号链接逃逸、损坏校验和和异常压缩比被拒绝，正式目录不产生部分安装。

## UI 验收

- 统一入口包含总览、文档、记忆、能力经验、资源、Tag 与关系。
- 不再出现作为两个独立产品的“知识文档/引用知识库”结构。
- 文档、印象、能力和资源使用各自适合的视图。
- 现有资源画廊视觉体验不退化，支持大图、GIF、音视频、Tag、启禁用和新增。
- 大规模资源支持表格、批量操作、分页和虚拟渲染。
- 伙伴页能够查看和编辑结构化印象、形象、状态、关系、能力和冻结策略。
- 用户关闭情绪“参与对话”后数据仍保留，伙伴下一轮不受该模块影响。
- 保存冲突、迁移失败、冻结拒绝和缺失资源都有清晰可恢复反馈。

## 工程质量门槛

至少执行并通过：

```text
pnpm run typecheck
pnpm run test:runtime
pnpm run test:client
pnpm run test:cli
pnpm run test:desktop
pnpm run build
```

同时运行新增的迁移、性能、导入导出、安全、召回和 Skill 场景套件。更新相关架构文档、包 README、Preset、生成目录和产品说明。生成物、旧兼容分支、调试开关和临时双写不得残留。

## 最终验收报告

最终报告必须包含：

- 完成的包和用户功能。
- 已删除的旧逻辑。
- 旧资源迁移统计与哈希核验。
- 召回准确率、延迟和上下文预算。
- 大规模整理耗时、批次数、中断恢复和幂等结果。
- 权限、冻结和域隔离结果。
- 导入导出、不同路径和依赖降级结果。
- 全部验证命令及结果。
- 已知限制；任何违反本计划核心不变量的限制都属于未完成，不能带病验收。
