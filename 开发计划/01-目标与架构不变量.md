# 目标与架构不变量

## 产品定义

Agent Vault 是一个 Agent 的完整可迁移心智档案，而不是单纯的文档知识库。它包含：

- 自我：身份、形象、人格、语气、世界观、兴趣、情绪、状态、关系和常用认知。
- 记忆：短期印象、中期整理、长期稳定知识和经历。
- 能力：方法、经验、工具路线、限制和能力测试。
- 资源：图片、表情包、音视频、PDF、Office 文件、文本和未来媒体类型。
- 导航：目录地图、Tag、别名、实体、Wiki 链接和检索测试。
- 治理：变更队列、冲突、历史、冻结策略、审计和恢复点。

虚拟伙伴是 Agent Vault 的一个消费场景。通用 Agent、工具型 Agent 和未来的其他角色也应通过同一能力接入，不能让核心 Vault 服务永久隶属于 `ui-virtual-companion`。

## 四类内容域

| 域 | 回答的问题 | 真源形式 | 默认检索工具 |
| --- | --- | --- | --- |
| `self` | 我是谁、现在怎样、与谁是什么关系 | 结构化 Markdown | `self.inspect` |
| `memory` | 我知道和经历过什么 | Markdown、分段短期记录 | `knowledge.recall`、`knowledge.explore` |
| `procedure` | 我会怎样做、做过什么、边界是什么 | 能力卡、方法和经验 Markdown | `procedure.recall` |
| `resource` | 我拥有哪些原始材料和可调用资产 | 结构化记录、二进制对象 | `resource.find`、`express` |

领域边界先于相关性评分。普通知识召回即使与人设词项完全一致，也不能返回 `self`；能力检索不能把某篇一般知识误认为已认证能力；表达资源检索不能把 PDF 来源误当表情包。

## 存储与派生不变量

- Vault 内的 Markdown、结构化记录、清单和二进制对象是唯一可迁移真源。
- FTS5、缩略图、波形、OCR 缓存、文件解析缓存和技术热缓存位于 `.system/`，可随时删除并由真源重建。
- 派生索引不能保存正文中不存在的独占事实，不能反向覆盖真源。
- 文档、资源和关系均有稳定 ID、revision、来源和历史；路径是位置，不是永久身份。
- 保存操作采用原子发布和 revision 守卫，禁止静默覆盖用户或另一个 Agent 的新版本。
- 所有持久链接使用 Vault URI、稳定 ID 或受管相对 Wiki 链接，禁止保存主机绝对路径。

## 权限与冻结不变量

每个 Vault 提供总策略和分域策略：

```yaml
ai_write_mode: autonomous
domains:
  self: proposal
  memory: autonomous
  procedure: proposal
  resource: readonly
user_editable: true
```

支持以下预设：

- 完全自主：允许按 Skill 和 Host 规则自治更新。
- 稳定人设：`self` 只读，记忆可以成长。
- 仅记忆成长：只允许短期记忆写入与受管整理。
- 修改需确认：所有语义变更先形成提案。
- AI 只读：Agent 只能检索，用户仍可编辑。
- 完全冻结：Agent 与普通用户编辑都只读，解除冻结后才能修改。

冻结由 Host 注册的工具守卫执行，不能只依靠提示词。索引重建和技术缓存更新不属于语义写入，但必须保证不能借此改变 Vault 内容。

## 人格稳定不变量

- 技术缓存可以频繁替换，认知常用记忆只能分阶段晋升和淡化。
- 短期事件可以立即改变受限的当前情绪或状态，但不能立即改写核心身份、人格、价值观或长期关系。
- 普通知识写入工具不能触达 `self/`。
- 自我改变必须经过专用工具、目标维度授权、证据、阶段规则和 revision 检查。
- 身份与形象默认由用户控制；Agent 可以读取和提出补充，不能把推测自动写成确定事实。
- 情绪可以影响表达方式，不得降低事实准确性、绕过安全约束或进行惩罚性拒绝。

## 召回不变量

- 每轮只注入有严格 token 上限的编译印象快照、最近重要短期修订和当前激活结果。
- 不注入完整资源 Tag 目录、完整能力清单或全库文档目录。
- 快速召回返回方向卡和命中原因，不返回大量正文。
- 深度探索从已经定位的目录、页面或实体出发，使用有界半径、页面数、章节数和 token 预算。
- 任何“全库扫描”只能是确定性的离线索引或元数据审计，不能把全库正文送入 LLM 上下文。

## UI 不变量

- 伙伴管理页和 Vault 工作台读取同一套真源。
- 统一管理不等于统一渲染；文档使用编辑器，资源使用画廊或表格，印象使用结构化卡片，关系使用关系视图。
- 用户管理界面允许全 Vault 联合搜索并按类型分组；Agent 工具不提供无边界 `search_everything`。
- 每个可注入印象模块都显示参与对话开关、自治开关、用户锁定、状态、变化原因和历史。
- 资源画廊保留现有大图预览、GIF、音视频、Tag 胶囊、启用状态和作用域体验。

## 工程边界

- Agent Vault 抽象服务属于独立能力域；本地文件实现、SQLite 派生索引、工具、Skill 和 Client UI 分包实现。
- Host 拥有文件、索引、导入导出、权限、二进制和迁移；Client 只通过 Remote/API 使用能力。
- 虚拟伙伴运行时负责伙伴会话、房间身份和 Vault 授权，不继续拥有通用知识引擎。
- 系统 Skill 提供方法论；伙伴自己学到的方法和经验写入该伙伴的 `procedures/`，不能污染平台 Skill。
