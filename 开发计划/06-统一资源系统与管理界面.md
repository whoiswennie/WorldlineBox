# 统一资源系统与管理界面

## 领域定义

“引用”是资源的使用动作，不是独立知识库。新架构删除产品层的独立 Reference Vault，把图片、表情包、音视频、PDF、Office 文件、文本和未来媒体纳入 Agent Vault 的 `resource` 域。

一个资源可以具有多个用途：

```yaml
id: asset-yachiyo-celebrate-01
kind: asset
title: 八千代开心庆祝
asset: resource://sha256/abc123
mime_type: image/gif
roles: [expression, character-related]
tags: [八千代, 开心, 庆祝, 二次元]
enabled: true
scope: private
```

常见 role：

- `expression`：可通过 `express` 自然发送。
- `source`：知识和记忆的原始来源。
- `learning-material`：等待或已经用于学习。
- `appearance`：实体形象。
- `example`：知识或方法示例。
- `artifact`：Agent 任务产物。

同一对象只存一份二进制和一份资源身份，多个用途通过 role 和链接表达。

## 表达流程

每轮不再注入全部资源 Tag。编译印象只说明伙伴拥有的表达能力、稳定风格和工具路线：

```text
伙伴决定要表达“庆祝”
→ 调用 express(intent, query, preferred_tags)
→ Host 在 role=expression、enabled=true、授权 scope 内查询
→ 排除近期重复资源
→ 晚绑定一个实际资源
```

高频的是表达风格和 Tag 簇，不是某一张具体表情包。资源选择兼顾匹配度、禁用条件、场景、近期重复和多样性。

## 统一 Vault 工作台

知识页面重构为一个统一工作台：

```text
总览 | 文档 | 记忆 | 能力经验 | 资源 | Tag 与关系
```

### 总览

显示 Vault 名称、伙伴形象、冻结状态、索引状态、短中长期数量、待整理任务、资源数量、能力数量、冲突、最近修改和健康检查。

### 文档

保留文件树、标签页、CodeMirror 编辑、Markdown 预览、页面信息、Wiki 链接、历史和冲突恢复。

### 记忆

提供短期、中期、长期、未整理、冲突、修订、来源和时间筛选。短期可按批次查看处理进度；中长期可进入 Wiki 文档视图。

### 能力经验

采用能力卡和列表，展示别名、Tag、熟练度、验证状态、依赖、最近测试、方法和经验链接。

### 资源

保留现有截图中的视觉语言：大图/GIF 预览、卡片式布局、彩色 Tag、MIME、启用状态、内置状态和新增入口。增加画廊与数据表格两种模式。

### Tag 与关系

显示 Canonical Tag、别名、父子、相关、冲突候选，以及它连接的文档、记忆、能力、资源和印象。系统属性作为过滤器显示，不混入语义 Tag 图。

## 资源画廊

画廊模式支持：

- 图片和 GIF 可视预览。
- 视频封面和按需播放。
- 音频播放器和可重建波形。
- PDF 首页缩略图。
- 文本和链接安全预览。
- MIME 渲染器注册表与未知类型附件回退。
- 虚拟列表、分页和可见区懒加载。
- GIF/视频默认不在大列表自动全部播放。

卡片显示标题、简短说明、语义 Tag、系统属性、启用状态和快捷操作。编辑打开结构化抽屉：左侧预览，右侧标题、用途、Tag、使用/避免场景、来源、权限、版本和关联知识。

## 数据表格与批量操作

表格模式支持：

- 标题、MIME、大小、role、Tag、scope、enabled、来源、导入日期和重复状态。
- 多选启用/禁用、修改 Tag、移动集合、修改 role、导出和删除到可恢复回收区。
- 大规模筛选、排序和分页，不一次渲染所有媒体。
- 相同哈希、同名不同内容和疑似重复分组。

## 联合搜索与 Agent 检索

用户管理界面允许全 Vault 搜索，结果按 `self`、`memory`、`procedure`、`resource` 分组。Agent 不获得无域联合搜索；Agent 使用专用工具并由 impression route 选择域。

资源 FTS5 只索引标题、别名、说明、语义 Tag、使用条件、转写、OCR 和原始文件名，不尝试把二进制全部送入上下文。

## 冻结与权限

资源域遵循 Vault 策略：

- `readonly` 时 Agent 不能新增、修改、禁用或删除资源。
- 用户编辑后资源记录和索引立即更新。
- `express` 在只读状态仍可使用已启用资源；使用记录写入技术运行数据，不改变资源语义。
- 不同 Agent 只能访问公共资源和自己的私有资源。

## 导入导出

资源记录、日期导入清单和二进制对象属于 Agent Package。缩略图、波形、FTS5 和浏览器缓存不导出。导入后先验证对象哈希，再重建媒体派生物和索引。
