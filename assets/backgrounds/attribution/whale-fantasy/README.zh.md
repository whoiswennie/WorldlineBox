# 鲸鱼娘 · 未至之境 (Whale Girl · The Unreached)

[English](README.md) | 中文

暗色专用皮肤，建在**一段背景视频**上：赛博奇幻的夜里，蓝发少女的眼里淌着代码，下着青色的数据雨。
界面画成**一块悬浮在夜里的全息仪表盘** —— 每一块面都是薄玻璃、背后永远是正在流动的画面，
结构是 1px 冷蓝细线，青色只给状态。

## 构成

- **纯资产**：`skin.json`（v2 清单）+ `skin.css`（完整重映射 `--dsw-alias-*`）
  + `patches.css`（L3 自由选择器）+ 一段视频。没有 package.json、没有构建步骤、没有 hooks。
- **本仓库第一支以视频为背景的皮肤**（`backgroundMedia.type = "video"`）。
  其余带画的皮肤发的都是静态图或 webp，所以视频这条路径在这里第一次被跑通。
- **暗色专用**：浅色与深色声明同一套暗色值，系统无论要哪一套，渲染出来都相同。

## 配色

每一支都是从画面里量出来的，不是另配的：

| 角色 | 色值 | 从画面哪里取 |

## 背景视频

源片 26.67s / 1920x1080 / 24fps / 10.4 Mbps，**上下各有 46px 纯黑**。
不处理就进包的话，`object-fit: cover` 会把那两条黑边一起铺到视口上，所以先烘焙：

| 步骤 | 做法 |
| --- | --- |
| 裁黑边 | `crop=1920:988:0:46` —— 两条黑边去掉（用 `cropdetect` 量的） |
| 降规格 | 1664 宽（856 高）/ 24fps / CRF 28 / preset slow / yuv420p / +faststart |
| 分级 | `eq=contrast=1.05:saturation=1.06` —— **亮度一点不碰** |
| 无缝循环 | 尾部 1.2s 与头部 1.2s 交叉淡入：进来 640 帧，出去 **611 帧 / 25.46s / 6.63 MB** |

交叉淡入让回接处是「真的」而不是近似：输出末帧在源片里的下一个画面，正是输出首帧。
自检拿回接差与帧间差的**p95** 比（实测 2.00 对 5.46），不是拿均差 —— 淡入那一段是两帧叠影，
相邻差被人为压低了。

`scrim` 只压最底下一条窄带（输入卡坐在那儿），顶上一点都不压：早期版本顶上有一条渐变，
被用户点名就是「壁纸上方这个黑色背景」。

## 画面被合成器吃掉多少

半透明的皮肤会悄悄把自己的背景压暗，而这件事用眼睛看不出来。量法是：把解码出来的视频帧
与同一帧的上屏截图，在一块纯画面区域上做最小二乘回归 —— **斜率**是还剩多少对比度，
**相关系数**是空间上有没有被抹开。

| | 斜率 | 相关 |
| --- | --- | --- |
| 这套皮 | **0.397** | **0.997** |

相关 0.997 就是没有糊。全套皮**一个 `backdrop-filter` 都没有**：早期版本用过磨砂玻璃，
同一帧的相关性掉到 0.87 —— 那就是「背景看起来是糊的」在数字上的样子。

## 全息层

除了 token 重映射，`patches.css` 里那些规则才是把壳体自带的界面变成上面那块仪表的：
每一条都是量出来的，不是猜类名猜出来的。

- **面** —— 引擎的地面、三处全局压暗、阅读纱全部归零，画面就是地面。面板、菜单、输入卡、
  工具提示、审批卡、设置弹窗、右栏停靠面板全部变成「玻璃 + 1px 细线」；
  四角青色括号只出现在入口与浮层上。
- **图标** —— 壳的图标本来就是 1px 线稿（`fill: none` + `stroke: currentColor`），
  而每一处描边都落在壳自己的五支板岩蓝上。现在静息是电光蓝、悬停／展开／当前转青。
  右栏文件浏览器里的文件类型徽章是全皮唯一一处彩色图标：写死十六进制的那批直接重填，
  走 `--dsw-static-neutral-*` 的那批改那几个 token。
- **文字** —— 层级由生成器掌管（`label-primary/secondary/tertiary/dimmed/caption`）；
  壳在输入卡与会话头部里又另下了一遍，这两处也重新指回同一套，
  免得同一个语义层级在两处亮度不同。
- **字体** —— 机壳与读数走 Cascadia Mono，中文走等线 DengXian，显示层走 Bahnschrift；
  正文散文留在比例字体。等宽是给读数用的，这也是这套皮的设计语言。
- **代码** —— 代码块与行内代码收进皮肤自己的等宽。壳给代码写死的栈头一个是 `SF Mono`，
  这个字体在 Windows 上不存在，一直静默回退到 Consolas。

## 可读性

对比度按**合成之后**的底实测（视频 + scrim + 玻璃 + 面板都在）：把文字那一层藏掉、
截图取底色，再与声明的字色比：

| 元素 | 中位 | 最亮 5% 处 |
| --- | --- | --- |
| 输入卡占位符 | 10.81:1 | 2.92:1 |
| 新会话文字 | 14.82:1 | 13.73:1 |
| 模型 pill | 9.78:1 | 5.81:1 |
| 用量小卡 | 16.05:1 | 13.67:1 |

唯一可能掉到 4.5:1 以下的是输入卡占位符，而且只在它背后那段画面最亮的地方。
它本来就该是暗的（占位符），但如果画作或面板不透明度再动，这里是第一个要复查的点。
